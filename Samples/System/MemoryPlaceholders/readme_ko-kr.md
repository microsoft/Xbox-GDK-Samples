#   메모리 자리 표시자 샘플

*이 샘플은 2021년 4월 GXDK 버전과 호환됩니다. 2022년 3월 GXDK 버전에도
처리된 특정 변경 내용이 있습니다.*

# 

# 설명

이 샘플에서는 가상 주소 공간을 미리 예약하는 방법인 메모리 자리 표시자를
사용하는 방법을 보여 줍니다. 이러한 방식으로 가상 주소 범위를 예약하면
두 가지 주요 이점이 있습니다.

-   주요 이점은 범위 내에서 커밋된 메모리의 캐시 동작 플래그 및 페이지
    크기를 변경할 수 있다는 것입니다.

-   부가적인 이점은 기본 가상 주소 범위가 이미 있으므로 더 빠른 메모리
    할당이 가능하다는 것입니다.

그러나 한 가지 중요한 점은 그래픽 할당에 범위를 사용하는 경우 GPU가
처리할 수 있는 주소 범위에서 만들어지도록 XMEM_GRAPHICS 플래그와 함께
만들어야 한다는 것입니다.

이 샘플은 D3D 장치를 만든 직후 그래픽 할당을 처리할 수 있는 자리
표시자를 만듭니다.

# 샘플 빌드

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을
Gaming.Xbox.XboxOne.x64로 설정합니다.

Project Scarlett를 사용하는 경우 활성 솔루션 플랫폼을
Gaming.Xbox.Scarlett.x64로 설정합니다.

*자세한 내용은 GDK 설명서에서* 샘플 실행을 *참조하세요.*

# 구현 참고 사항

**자리 표시자 할당**

자리 표시자 영역을 처리하는 할당자에 대한 구현이 포함되어 있으므로
타이틀에서 자유롭게 사용할 수 있습니다. 참고: 타이틀에서 이 구현을 직접
사용하는 경우 요구 사항에 맞게 추가 오류 검색을 만드는 것이 좋습니다.

PlaceholderRegion 클래스 및 해당 동작에 대한 기본 함수:

-   SetupRegion

    -   XMemVirtualAlloc 및 MEM_RESERVE_PLACEHOLDER 플래그를 사용하여
        초기 자리 표시자 영역을 예약합니다.

-   FindOpenSpace

    -   사용된 지역 및 사용 가능한 지역 목록이 유지됩니다. 이 함수는
        할당을 충족하기 위해 열린 지점을 찾는 목록을 안내합니다.

-   할당

    -   자리 표시자 영역의 요청된 위치에 할당하거나 페이지 크기 및 할당
        크기를 충족할 수 있는 열린 공간을 찾습니다.

    -   자리 표시자를 분할하여 MEM_REPLACE_PLACEHOLDER 플래그를 사용하여
        자리 표시자에서 새로 할당된 블록을 제거합니다.

    -   요청된 경우 메모리를 커밋합니다. 호출은 나중에 기존 메서드를
        사용하여 메모리를 커밋할 수 있습니다.

-   릴리스

    -   MEM_PRESERVE_PLACEHOLDER 플래그를 사용하여 메모리 커밋 취소

    -   자리 표시자 내에 여유 공간이 있는 인접 지역이 있는지 여부를
        확인합니다. 그렇다면 MEM_COALESCE_PLACEHOLDERS 플래그를 사용하여
        병합합니다.

**타이틀 예약 메모리**

GXDK의 메모리 시스템은 타이틀 할당을 위해 4TB-8TB 가상 주소 범위를
예약했습니다. XMemVirtualAlloc, VirtualAlloc, XMemAlloc 등 함수는
타이틀에서 명시적으로 요청하지 않는 한 이 범위의 어떤 것도 할당하지
않습니다. 이 예약된 주소 범위의 이점은 타이틀이 한 실행에서 다음
실행까지 동일한 고정 메모리 주소를 사용할 수 있고 나중에 다시 사용할 수
있도록 디스크에 저장할 수도 있다는 것입니다. 2022년 3월 GXDK 이전에는 이
지역이 타이틀 시작 시 바로 사용 가능하도록 보장되었으므로 이 범위에서
나중에 할당이 발생할 가능성이 있었습니다.

2022년 3월 GXDK부터 이 지역은 자리 표시자 예약으로 할당됩니다. 이렇게
하면 수명 동안 타이틀에서 범위를 사용할 수 있습니다. 할당은 타이틀에서
명시적으로 요청한 경우에만 이 범위에서 발생합니다.

이 샘플은 2022년 3월 GXDK와 이전 GXDK 릴리스 간의 차이를 처리합니다.
2022년 3월 GXDK 릴리스 이전 GXDK 릴리스의 경우 할당/릴리스 기능은
XMemVirtualAlloc/VirtualFree로 직접 라우팅됩니다.

2022년 3월 GXDK에서는 타이틀 예약 가상 주소 범위가 자리 표시자로
할당되므로 샘플은 샘플에 제공된 PlaceHolderRegion 클래스를 사용하여
지역을 관리합니다.
