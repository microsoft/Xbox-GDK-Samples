# RawDevice 示例

*此示例与 Microsoft 游戏开发工具包（2021 年 4 月）兼容*

# 说明

此示例演示如何使用 GameInput 读取和写入原始设备消息

![](./media/image1.png)

# 生成示例

如果使用 Xbox One 开发工具包，请将活动解决方案平台设置为 `Gaming.Xbox.XboxOne.x64`。

如果使用 Project Scarlett，请将可用解决方案平台设置为 `Gaming.Xbox.Scarlett.x64`。

*有关详细信息，请参阅* *GDK 文档中的*__运行示例__。&nbsp;

# 使用示例

连接 Xbox 兼容赛车轮以查看读数。 按&ldquo;菜单&rdquo;按钮将请求发送到车轮统计信息报表报表的车轮，并查看显示的读数。

# 实现说明

此示例演示如何使用 GameInput API 从支持原始设备消息的设备读取和写入消息。
