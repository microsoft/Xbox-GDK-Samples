# RawDevice 샘플

*이 샘플은 Microsoft 게임 개발 키트(2021년 4월)와 호환됩니다.*

# 설명

이 샘플은 GameInput을 사용하여 원시 장치 메시지를 읽고 쓰는 방법을 보여줍니다.

![](./media/image1.png)

# 샘플 빌드

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.XboxOne.x64`(으)로 설정합니다.

Project Scarlett을 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.Scarlett.x64`(으)로 설정합니다.

*GDK 설명서의* __샘플 실행__에서 *자세한 내용을 알아보세요.*

# 샘플 사용

Xbox 호환 레이싱 휠을 연결하여 판독값을 확인합니다. 메뉴 단추를 눌러 휠 정적 구성 보고서에 대한 요청을 휠로 전송하고 표시되는 판독값을 확인합니다.

# 구현 참고 사항

이 샘플은 GameInput API를 사용하여 원시 장치 메시지를 지원하는 장치에서 메시지를 읽고 쓰는 방법을 보여줍니다.
