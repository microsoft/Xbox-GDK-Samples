# メモリ統計のサンプル

# 説明

このサンプルでは、Xbox ゲームの実行時にメモリ使用量を照会する方法を示します。 使用されるプライマリ API は、ゲームで使用されるリソースのスナップショットを取得するための XMemGetWorkingSetStatistics です。 このサンプルでは、現在のメモリ使用量のスナップショットを取得する方法、または個々の関数のスナップショットの前後を比較して、それらのコンポーネントによって使用されるメモリを決定する方法を示します。

# サンプルのビルド

サンプルは Visual Studio 2017 プロジェクトですが、より新しいバージョンの開発環境でも読み込んで使用できます。

Xbox One開発キットを使用している場合は、*Gaming.Xbox.XboxOne.x64* 構成を使用する必要があります。

Project Scarlett 開発キットを使用している場合は、*Gaming.Xbox.Scarlett.x64* 構成を使用してサンプルをネイティブ モードで実行する必要があります。 または、*Gaming.Xbox.XboxOne.x64* 構成を使用して、サンプルをバック 互換モードで実行することもできます。

# サンプルの使用方法

このサンプルでは、サンプルのメモリ使用量に関する情報を表示します。 最初は 3D 空間に 1 つのモデルが表示されます。 より多くのモデルを実行時に作成して、それらがリソースの使用状況にどのように影響するかを確認できます。

![](./media/image3.png)

| 操作 | ゲームパッド | キーボード |
|---|---|---|
| ティーポットの数を増やす | 方向パッド 右 | 右矢印 |
| ティーポットの数を減らす | 方向パッド 左 | 左矢印 |
| 実行時のリソース使用率と初期化直後の比較に関する情報を表示します。 | Y button | P |
| Exit | ビュー ボタン | Esc |

ゲームプレイ中に Y ボタン/P キーによって表示されるリソース使用量が一貫して増加する場合、メモリ リークや非効率的なリソース管理を示している可能性があります。

# 実装メモ

このサンプルでは、**XMemGetWorkingSetStatistics** API を使用してメモリ情報を追跡する 3 つの方法を示します。

- **Initialize** 関数の最後にあるリソース使用量のキャプチャを取得し、実行時のリソース使用量といつでも比較します。

- 新しいティーポトを作成する前後にキャプチャを行い、1 回の操作に必要なメモリの量を決定します。

- また、表示する合計メモリ使用量も追跡されます。

# プライバシーにかんするせいめい

サンプルをコンパイルして実行する場合、サンプルの使用状況を追跡するために、サンプルの実行可能ファイルのファイル名が Microsoft に送信されます。 このデータ コレクションからオプトアウトするには、Main.cpp の "サンプル使用状況テレメトリ" というラベルの付いたコードのブロックを削除します。

Microsoft のプライバシー ポリシー全般の詳細については、「[Microsoft のプライバシーに関する声明](https://privacy.microsoft.com/en-us/privacystatement/)」を参照してください。
