# 메모리 통계 샘플

# 설명

이 샘플에서는 Xbox 게임에서 런타임에 메모리 사용량을 쿼리하는 방법을 보여 줍니다. 사용되는 기본 API는 게임에서 사용하는 리소스의 스냅샷을 캡처하는 XMemGetWorkingSetStatistics입니다. 이 샘플에서는 현재 메모리 사용량의 스냅샷을 캡처하거나 개별 함수의 스냅샷 전후를 비교하여 해당 구성 요소에서 사용하는 메모리를 확인하는 방법을 보여 줍니다.

# 샘플 빌드

샘플은 Visual Studio 2017 프로젝트이지만 최신 버전의 개발 환경에서 로드하고 사용할 수도 있습니다.

Xbox One 개발 키트를 사용하는 경우 *Gaming.Xbox.XboxOne.x64* 구성을 사용해야 합니다.

Project Scarlett 개발 키트로 작업하는 경우 *Gaming.Xbox.Scarlett.x64* 구성을 사용하여 기본 모드에서 샘플을 실행해야 합니다. 또는 *Gaming.Xbox.XboxOne.x64* 구성을 사용하여 샘플을 이전 버전과의 호환 모드로 실행할 수 있습니다.

# 샘플 사용

이 샘플에서는 샘플의 메모리 사용량에 대한 정보를 표시합니다. 처음에는 단일 모델을 3D 공간에 표시합니다. 런타임에 더 많은 모델을 만들어 리소스 사용량에 미치는 영향을 확인할 수 있습니다.

![](./media/image3.png)

| 동작 | Gamepad | 키보드 |
|---|---|---|
| 티폿 횟수 늘리기 | DPad 오른쪽 | 오른쪽 화살표 |
| 티폿 횟수 줄이기 | dPad 왼쪽 | 왼쪽 화살표 |
| 런타임 중에 리소스 사용량이 초기화 직후와 비교되는 방법에 대한 정보를 표시합니다. | Y 버튼 | p |
| 끝내기 | 보기 버튼 | Esc |

게임 플레이 중에 Y 단추/P 키로 표시되는 리소스 사용량이 지속적으로 증가하는 경우 메모리 누수 또는 비효율적인 리소스 관리를 나타낼 수 있습니다.

# 구현 참고 사항

이 샘플에서는 **XMemGetWorkingSetStatistics** API를 사용하여 메모리 정보를 추적하는 세 가지 방법을 보여 줍니다.

- **Initialize** 함수가 끝날 때 리소스 사용량을 캡처하여 런타임 시 리소스 사용량과 언제든지 비교합니다.

- 단일 작업에 필요한 메모리양을 결정하기 위해 새 찻주전자를 만들기 전과 후에 캡처합니다.

- 또한 볼 총 메모리 사용량을 추적합니다.
