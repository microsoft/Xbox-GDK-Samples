# SimpleMDU サンプル

# 説明

このサンプルでは、メモリ展開ユニット (MDU) の基本的なプロパティを示します。

GDK ドキュメントの *「圧縮コンテンツの最適化」* トピックの説明のとおり、DirectStorage API またはメモリ内ソースからの I/O 要求の一部として、MDU を使用してデータ ストリームを圧縮解除できます。 このサンプルでは、一連のデータ ストリームを生成し、2 つの DirectStorage キューを使用して、メモリおよび\\またはストレージからのストリームを継続的に展開します。 データ ストリームのプロパティを変更して、MDU のスループット特性を確認できます。

# サンプルのビルド

このサンプルでは、Xbox One またはデスクトップはサポートされていません。 DirectStorage は、Gaming.Xbox.Scarlett.x64 構成でのみサポートされます。

*詳細については、* *GDK ドキュメント*の「__サンプルの実行__」を参照してください。

# サンプルの使用方法

読み込み時に、サンプルによって 1 つのデータ ストリームが生成され、ディスクに永続化されます。 そのストリームは、メモリ内キューとストレージからのキューの両方で使用されます。 次のコントロールを使用して、データ ストリームを生成\\変更できます。

| Dpad L eft\\Right | 大きなデータ ストリーム内の個別に圧縮された "チャンク" のサイズを調整する |
|---|---|
| Dpad Up\\Down | データ ストリームの圧縮性を調整する |
| LB\\RB | データ ストリームのメモリ アライメントを調整する (16 バイトまたは 4KiB) |
| Y | メモリ内圧縮解除を有効にする\\無効にする |
| B | ストレージからの展開を有効にする\\無効にする |
| ビュー | サンプルを終了する |

# 実装メモ

GDK ドキュメントの *圧縮コンテンツの最適化* に関するトピックでは、MDU 展開オプションについて詳しく説明します。 MDU は 2 つの異なる圧縮戦略 (zlib & bcpack) をサポートしており、個別に適用することも、特定のデータ ストリームに連続して適用することもできます。

データ ストリームは通常、MDU 展開ハードウェアにオフロードできる事前に定義されたサイズに分割され、サイズの上限は個別に圧縮されたチャンクごとに 32MiB です。 テクスチャ圧縮に XBTC を使用する場合、これらの個別に圧縮されたストリームのサイズは、テクスチャのインポート時に使用されるオプションによって決まります。 コンテンツを個別に圧縮する場合、開発者は有効な "チャンク" サイズを選択できますが、サイズが小さいか大きい場合はパフォーマンスに関する考慮事項があります (詳細についてはドキュメントを参照してください)。

コンテンツとエンコードの種類、および非損失圧縮と非損失圧縮のどちらを使用するかに応じて、一般的な圧縮率は
1.5:1 から 4:1 まで。 これをモデル化するために、サンプルダウンロードのサイズを最小限に抑えながら、コントローラーを介して選択可能なさまざまな圧縮性範囲でデータを生成します。 任意のデータ生成の性質により、さまざまな圧縮率を実現するため、サンプルでは zlib 圧縮戦略のみを使用するため、有効な BC エンコードテクスチャ ストリームを生成する必要がなくなります。

ストリームが選択されると、DSQueueHandler の内部ループは単にキューを要求で占有したままにしようとします。 各バッチは 32MiB のデータ要求で構成され、3 つのバッチを常に処理中に保持しようとします。 これにより、タイトルによって読み込まれる一般的なデータに基づいて、MDU スループット特性を簡単に判断できます。

BCPack 圧縮の使用方法の例については、「TextureCompression サンプル」を参照してください。

zlib ライブラリ (バージョン 1.2.11) には、次のライセンスが適用されます。 <http://zlib.net/zlib_license.html>

# プライバシーにかんするせいめい

サンプルをコンパイルして実行する場合、サンプルの使用状況を追跡するために、サンプルの実行可能ファイルのファイル名が Microsoft に送信されます。 このデータ コレクションからオプトアウトするには、Main.cpp の "サンプル使用状況テレメトリ" というラベルの付いたコードのブロックを削除します。

Microsoft のプライバシー ポリシー全般の詳細については、「[Microsoft のプライバシーに関する声明](https://privacy.microsoft.com/en-us/privacystatement/)」を参照してください。
