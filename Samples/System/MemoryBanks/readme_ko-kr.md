# 메모리 뱅크 샘플

이 샘플은 Microsoft 게임 개발 키트 미리 보기와 호환됩니다(2019년 11월).

# 

# 설명

이 샘플은 메모리 뱅크를 관리하는 데 사용할 수 있는 몇 가지 방법을
설명합니다.

-   임의 - VirtualAlloc를 통해 할당되는 기준 메모리 뱅크입니다.

-   고정 -- 특정 메모리 주소에서 메모리를 할당하는 방법을 설명합니다.

-   읽기 전용 -- 메모리를 읽기 전용으로 변환하는 방법을 설명합니다.

-   뱅크 전환 -- 회전할 수 있는 메모리 뱅크 체인을 만드는 방법을
    설명합니다.

-   공유 -- 동일한 물리적 위치를 공유하는 여러 메모리 뱅크를 만드는
    방법을 설명합니다.

# 샘플 빌드하기

Project Scarlett을 사용하는 경우에는 프로젝트에 Gaming.Xbox.Scarlett.x64
플랫폼 구성을 추가해야 합니다. *Configuration Manager*를 통해 이 작업을
수행할 수 있습니다. "활성 솔루션 플랫폼"에서 "Configuration Manager"
옵션을 선택하고 "새로 만들기\..."를 선택합니다. "새 플랫폼 입력 또는
선택"을 Gaming.Xbox.Scarlett.x64로 설정하고 "다음에서 설정 복사"를
Gaming.Xbox.XboxOne.x64로 설정합니다. 그런 다음, 확인을 선택합니다.

자세한 내용은 GDK 문서에서 샘플 실행하기를 참조하세요.

각 데모를 보려면 컨트롤러에서 해당 단추를 누릅니다. 성공 또는 실패로

# 구현 참고 사항

## 임의

이 데모는 다른 데모의 기준 역할을 합니다. VirtualAlloc를 사용하여 메모리
뱅크를 할당한 다음 디스크에서 메모리 뱅크로 이진 트리를 읽어 줍니다.
디스크의 데이터를 수정해야 합니다. 내부적으로 이진 트리는 할당된 메모리
뱅크에 인덱스를 저장합니다. 프로그램의 실행 사이에 기본 주소가 변경된 후
인덱스를 기준으로 이진 트리의 모든 내부 포인터를 업데이트해야 합니다.

## 고정

이 데모는 임의 주소 데모와 동일하게 작동합니다. 주요 차이점은 기본
주소가 데이터 파일에 저장된다는 점입니다. 이렇게 하면 각 프로그램을
실행하는 경우 프로그램이 동일한 메모리 위치에서 동일한 뱅크를 다시 만들
수 있습니다. 따라서 내부 인덱스는 필요하지 않으며 포인터를 수정하지
않아도 됩니다. CPU 오버헤드가 거의 발생하지 않고 데이터를 디스크에서 더
빠르게 로드할 수 있습니다.

## 뱅크 전환

이 데모는 백업 물리적 블록을 바꿀 수 있는 여러 메모리 뱅크를 만드는
방법을 설명합니다. 이렇게 하면 실제 메모리의 블록 2개의 가상 주소가
바뀝니다. 3개 이상의 메모리 뱅크를 사용하여 회전할 수 있습니다. 로깅
데이터, 리플레이를 저장하는 데 사용하는 프레임 데이터, 버퍼 간 메모리가
이동하는 공간을 만들 때 사용합니다. 이렇게 하면 메모리 이동 작업을
제거할 수 있으며 성능이 크게 개선됩니다.

## 공유

이 데모는 모두 동일한 물리적 블록을 가리키는 여러 메모리 뱅크를 만드는
방법을 설명합니다. 가상 뱅크 2개를 서로 인접하게 만든 경우, 경계 복사를
위한 여러 메모리 복사 작업을 요구하지 않는 링 버퍼를 사용할 수 있습니다.
데이터가 첫 번째 가상 뱅크의 마지막에 작성되므로 물리적 블록의 시작
부분으로 자동으로 줄이 바뀝니다.

읽기-쓰기 및 읽기 전용 등의 서로 다른 권한을 가진 여러 개의 가상
포인터를 만들 때 사용하기도 합니다. 그러나 캐시 사용을 조정하는 혼합
권한은 허용되지 않습니다. 예: 쓰기 혼합 및 캐시 가능.

## 읽기 전용

이 데모는 읽기-쓰기 및 읽기 전용 페이지가 혼합된 페이지를 만드는 방법을
보여 줍니다. 뱅크 하나가 읽기-쓰기로 표시되고 다른 뱅크 하나가 읽기
전용으로 표시된 공유 데모를 사용합니다. 이 패턴은 임의 메모리 손상을
추적하는 데 주로 사용됩니다. 예: 제목에 사용되는 정적 데이터. 파일 로딩
시스템이 데이터를 만들기 위해 읽기-쓰기 주소를 사용할 수 있습니다.
제목의 나머지 부분은 읽기 전용 포인터를 사용하여 액세스합니다. 메모리
손상 문제가 발생하는 경우 문제를 야기한 소스의 정확한 위치에서 예외가
발생합니다.
