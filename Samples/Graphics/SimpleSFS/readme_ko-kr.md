# SimpleSFS 샘플

*이 샘플은 Microsoft 게임 개발 키트(2022년 3월)와 호환됩니다.*

# 설명

샘플러 피드백은 렌더링 중에 텍스처 샘플링 정보 및 위치를 캡처하고 기록하기 위한 Direct3D 기능입니다. 샘플러 피드백을 타일식 텍스처와 결합하면 텍스처 스트리밍을 위해 부분적으로 상주하는 텍스처(PRT)를 구현할 때 타일 상주를 손쉽게 관리할 수 있습니다. 이 샘플에서는 SFS(스트리밍용 샘플러 피드백)의 단순한 구현을 통해 MinMip 맵과 SamplerFeedback 맵을 함께 사용하는 방법을 소개합니다. DirectStorage는 타일을 그래픽 메모리에 직접 로드하고 하드웨어를 통해 압축을 푸는 데 사용됩니다.

샘플에서는 매우 간단한 풍경처럼 쿼드 위로 이동할 수 있는 카메라를 사용하여 쿼드에 타일식 텍스처를 렌더링합니다. 카메라가 움직이면 UI는 메모리에 상주하도록 요청된 타일과 현재 메모리에 상주하는 타일을 나타냅니다.

# 구현 참고 사항

다음 다이어그램은 SFS 구현의 데이터 흐름을 보여 줍니다. *MinMip 맵*은 최소 밉 수준( 즉, 현재 상주하는 가장 높은 세부 정보가 있는 밉)에 대한 정보를 보유하는 맵입니다. 스트리밍 시스템은 타일을 로드하거나 언로드할 때 CPU에서 MinMip 맵을 업데이트합니다. *피드백 맵*은 장면 렌더링 중에 상주하도록 요청된 최소 밉 수준에 대한 정보를 포함하는 맵입니다. 피드백 맵은 장면 렌더링 중에 GPU에서 업데이트되며, 스트리밍 시스템은 이 정보를 기반으로 새 스트리밍 요청을 생성할 수 있습니다. 자세한 내용은 GDK 설명서 및 Xfest 2019 프레젠테이션 "Scarlett의 텍스처 스트리밍"을 참조하세요.

**타일식 텍스처**

이 샘플에 사용된 타일식 텍스처는 GDK에 포함된 xbtc.exe 도구를 사용하여 만들어졌습니다. 이 도구는 DDS 파일을 입력으로 사용하고 압축된 파일을 생성합니다. "-tilemode SFS" 옵션을 사용하는 경우 압축된 파일에는 바둑판식 텍스처에 대한 64KB 타일이 포함됩니다. TiledTexture.cpp`TiledTexture::Create()`의 메서드는 .xbtc 파일을 사용하는 방법을 보여줍니다. 이 파일을 로드한 후 각 타일에 디스크에서 데이터가 로드되어야 하는 위치와 로드된 후 메모리 힙에 상주하는 위치에 대한 정보를 포함하는 타일 목록이 만들어집니다. PIX는 커밋된 타일과 예약된 타일을 보여 주는 타일식 텍스처를 시각화할 수 있습니다.

**피드백 맵**

피드백 맵의 형식에는 MinMip과 RegionUsed의 두 가지가 있습니다. 이 샘플에서는 MinMip 피드백(예: `DXGI_FORMAT_SAMPLER_FEEDBACK_MIN_MIP_OPAQUE`을 사용하여 생성됨)을 구현합니다. 피드백 맵에 대한 UAV를 만들려면 API `CreateSamplerFeedbackUnorderedAccessView()`사용합니다. 장면 렌더링 전에 피드백 맵을 지워야 합니다. 값 0으로 지우면 밉 수준 0이 장면 렌더링 중에 요청되었음을 의미하므로 이렇게 할 수는 없습니다. 따라서 샘플에서는 맵을 값 -1로 지우는데, 이는 밉이 요청되지 않았음을 나타냅니다. CPU의 값을 읽으려면 먼저 플래그가 있는 `ResolveSubresourceRegion()` 사용하여 텍스처를 트랜스코딩해야 합니다.
피드백 맵의 고정 지점은 5.3입니다. 이 샘플에서는 피드백 값과 밉 값 `MipValueToFeedbackValue()`, `FeedbackValueToMipValue()` 및 `DecodeFeedbackMapValue()` 간에 값을 변환하는 세 가지 함수를 구현합니다. 스트리밍 요청은 피드백 값의 소수 부분을 기준으로 정렬됩니다. PIX는 피드백 맵을 시각화할 수 있습니다. **MinMip 맵**
| | |
|---|---|
|`D3D12_RESOLVE_MODE_DECODE_SAMPLER_FEEDBACK`. Xbox 시리즈 X|S의 경우 값|


MinMip 맵은 R8 형식의 배치된 텍스처로 만들어집니다. UAV를 만들려면 API `CreateMinMipShaderResourceViewX()`을(를) 사용합니다. MinMip 맵의 값은 5.3 고정 지점으로 인코딩되어야 합니다. 즉, 스트리밍 시스템이 밉 2에서 로드되는 경우 맵에 값(2 \<\< 3)이 포함되어야 합니다. Pix는 MinMip 맵을 시각화할 수 있습니다.

**스트리밍**

이 샘플은 간단한 샘플이므로 스트리밍은 단순한 스트리밍 논리를 사용하여 동기적으로 구현됩니다. 장면 렌더링 후 피드백 맵 값은 GenerateStreamingRequests() 함수에서 스트리밍 요청을 생성하는 데 사용됩니다. ProcessStreamingRequests() 함수는 DirectStorage를 사용하여 요청된 타일을 그래픽 메모리로 직접 로드하고 압축을 푸는 스트리밍 요청을 처리합니다.
