# SimpleSFS サンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

サンプラー フィードバックは、レンダリング中にテクスチャ サンプリング情報と場所をキャプチャおよび記録するための Direct3D 機能です。 サンプラー フィードバックとタイル テクスチャを組み合わせると、テクスチャ ストリーミング用に部分的に常駐するテクスチャ (PRT) を実装するときに、タイルの常駐を管理する簡単なメカニズムが得られます。 このサンプルでは、SamplerFeedback マップを MinMip マップと共に使用する方法を示す、ストリーミング用サンプラー フィードバック (SFS) の簡単な実装を示します。 DirectStorage は、タイルをグラフィック メモリに直接ロードしてハードウェア展開するために使用されます。

このサンプルでは、非常に単純なランドスケープのように四角形上を移動できるカメラを備えた四角形にタイル テクスチャをレンダリングします。 カメラが動き回ると、UI には、メモリ内に常駐するように要求されたタイルと、現在メモリに常駐しているタイルが示されます。

# 実装メモ

次の図は、SFS 実装のデータ フローを示しています。 *MinMip マップ* は、最小ミップ レベル (つまり、現在常駐している最も詳細なミップ) に関する情報を保持するマップです。 ストリーミング システムはタイルの読み込みまたはアンロードを行うと、CPU 上の MinMip マップを更新します。 *フィードバック マップ* は、シーンのレンダリング中に常駐するように要求された最小ミップ レベルに関する情報を保持するマップです。 フィードバック マップはシーンレンダリング中に GPU で更新され、ストリーミング システムはこの情報に基づいて新しいストリーミング要求を生成できます。 詳細については、GDK ドキュメントと Xfest 2019 プレゼンテーション「Scarlett でのテクスチャ ストリーミング」を参照してください。

![](./media/image4.png)

**タイル テクスチャ**

このサンプルで使用されるタイル テクスチャでは、GDK に含まれている using xbtc.exe ツールが作成されました。 このツールは DDS ファイルを入力として受け取り、圧縮ファイルを生成します。 オプション "-tilemode SFS" を使用する場合、圧縮ファイルにはタイル テクスチャの 64 KB タイルが含まれます。 TiledTexture.cpp のメソッド `TiledTexture::Create()` は、.xbtc ファイルを使用する方法を示しています。 このファイルを読み込んだ後、タイルのリストが作成されます。各タイルには、データを読み込む必要があるディスク上の場所と、それが存在するメモリ ヒープ内の一度読み込まれる場所に関する情報が保持されます。 PIX では、タイル化されたテクスチャを視覚化し、コミットされているタイルと予約されているタイルを示すことができます。

**フィードバック マップ**

フィードバック マップには、MinMip と RegionUsed という 2 つの形式があります。 このサンプルでは、MinMip フィードバックを実装します。つまり、`DXGI_FORMAT_SAMPLER_FEEDBACK_MIN_MIP_OPAQUE` を使用して作成されます。フィードバック マップの UAV を作成するには、API `CreateSamplerFeedbackUnorderedAccessView()` を使用します。シーンのレンダリングの前に、フィードバック マップをクリアする必要があります。 これは、シーンのレンダリング中にミップ レベル 0 が要求されたことを意味するため、値 0 にクリアできません。 したがって、このサンプルでは、ミップが要求されなかったことを示す -1 の値へのマップがクリアされます。 CPU 上の値を読み取るには、最初にフラグの付いた `ResolveSubresourceRegion()` を使用してテクスチャをトランスコードする必要があります
フィードバック マップの 5.3 固定小数点です。 このサンプルでは、フィードバック値とミップ値 (`MipValueToFeedbackValue()`、`FeedbackValueToMipValue()`、`DecodeFeedbackMapValue()`) の間で値を変換する 3 つの関数が実装されています。ストリーミング要求は、フィードバック値の小数部に基づいて並べ替えられます。 PIX はフィードバック マップを視覚化できます。 **MinMip マップ**

|---|---|
|`D3D12_RESOLVE_MODE_DECODE_SAMPLER_FEEDBACK`。Xbox Series X|S の場合、値|


MinMip マップは、R8 形式の配置済みテクスチャとして作成されます。 UAV を作成するには、API `CreateMinMipShaderResourceViewX()` を使用します。MinMip マップの値は、5.3 固定小数点としてエンコードされる必要があります。つまり、ストリーミング システムがミップ 2 で読み込まれる場合、マップには (2 \<\< 3) の値が含まれている必要があります。 Pix は MinMip マップを視覚化できます

**ストリーミング**

これは単純なサンプルであるため、ストリーミングは同期的に単純なストリーミング ロジックで行われるように実装されます。 シーンレンダリングの後、フィードバック マップ値を使用して、GenerateStreamingRequests() 関数でストリーミング要求を生成します。関数 ProcessStreamingRequests() は、DirectStorage を使用してストリーミング要求を処理し、要求されたタイルをグラフィックス メモリに直接読み込んで展開します。
