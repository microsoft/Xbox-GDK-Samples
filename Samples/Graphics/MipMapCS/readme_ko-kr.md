# 설명

이 샘플에서는 스레드 로컬 저장소를 사용하지 않고 컴퓨팅 셰이더를
사용하여 텍스처의 mip를 만드는 방법을 보여줍니다.

![](./media/image3.png)

# 샘플 빌드

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을
Gaming.Xbox.XboxOne.x64로 설정합니다.

Xbox Series X|S 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을
Gaming.Xbox.Scarlett.x64로 설정합니다.

*자세한 내용은 GDK 설명서에서* 샘플 실행을 *참조하세요.*

# 샘플 사용

| 작업                        |  게임 패드                              |
|-----------------------------|----------------------------------------|
| 밉과 단일 디스플레이 토글   |  A 버튼                                 |
| 이전 또는 다음 밉 수준      |  방향 패드를 아래 또는 위로             |
| 카메라 이동                 |  오른쪽 스틱                            |
| 확대/축소                   |  왼쪽 또는 오른쪽 트리거                |
| 끝내기                      |  보기 단추                              |

# 구현 참고 사항

셰이더는 한 디스패치에서 4밉을 생성할 수 있습니다. 생성된 밉의 차원이
홀수인 경우(1 제외) 해당 밉을 사용하여 새 디스패치를 시작하는 것이
좋습니다. 그렇지 않으면 밉을 생성하는 동안 모든 값을 고려하지 않습니다.
홀수 크기의 텍스처의 경우 처음 생성된 밉은 언더샘플이 발생하지 않도록
여러 개의 샘플을 고려합니다.

# 알려진 문제

셰이더는 Xbox 내장 함수를 사용하여 구현되지만 셰이더 모델 6과 함께
WaveIntrinics를 사용하도록 업데이트해야 합니다(최소한 일부 데스크톱
시스템에서 작동해야 함).
