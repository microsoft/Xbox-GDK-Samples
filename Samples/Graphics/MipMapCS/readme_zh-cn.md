#   MipMapCS 示例

*此示例兼容于 Microsoft 游戏开发工具包（2020 年 6 月）*

# 

# 说明

此示例演示了如何使用计算着色器为纹理创建 mip，避免线程本地存储。

![](./media/image3.png)

# 生成示例

如果使用 Xbox One 开发工具包，请将活动解决方案平台设置为
Gaming.Xbox.XboxOne.x64。

如果使用 Xbox Series X|S 开发工具包，请将活动解决方案平台设置为
Gaming.Xbox.Scarlett.x64。

*有关详细信息，请参阅 GDK 文档中的*运行示例*。*

# 实现说明

着色器可在一个调度中生成 4 个 mips。如果生成的 mip
在任何方向上都有奇数维度（1 除外），则最好使用该 mip
启动新的调度，否则在生成 mip
时不会将所有值考虑在内。对于奇数大小的纹理，生成的第一个 mip
会考虑到多个样本，以免发生采样不足的情况。

# 已知问题

与着色器模型 6 配合使用（它应至少适用于一部分桌面系统）。
