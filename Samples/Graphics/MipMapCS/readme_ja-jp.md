#   MipMapCS サンプル

*このサンプルは Microsoft Game Development Kit (2020 年 6 月)
と互換性があります。*

# 

# 説明

このサンプルでは、スレッド ローカル ストレージを回避するコンピュート
シェーダーを使用してテクスチャのミップを作成する方法を示します。

![](./media/image3.png)

# サンプルのビルド

Xbox One 開発キットを使用している場合、アクティブ ソリューション
プラットフォームを Gaming.Xbox.XboxOne.x64 に設定します。

Xbox Series X|S 開発キットを使用している場合、アクティブ ソリューション
プラットフォームを Gaming.Xbox.Scarlett.x64 に設定します。

*詳細については、GDK
のドキュメントの*「サンプルの実行」*を参照してください。*

# サンプルの使用方法

| 操作                        |  ゲームパッド                           |
|-----------------------------|----------------------------------------|
| ミップと 単一ディスプレイの切り替え |  A ボタン |
| 前または次のミップ レベル   |  方向パッド (下または上)                |
| カメラを移動する            |  右スティック                           |
| 拡大または縮小する          |  左または右トリガー                     |
| 終了                        |  ビュー ボタン                          |

# 実装上の注意

シェーダーは、1 回のディスパッチで 4
ミップを生成できます。生成されたミップの次元が任意の方向に奇数 (1
を除く)
である場合は、そのミップを使用して新しいディスパッチを開始することをお勧めします。それ以外の場合は、ミップの生成中にすべての値が考慮されません。奇数サイズのテクスチャの場合、最初に生成されるミップでは、複数のサンプルを考慮して、アンダーサンプリングが発生しないようにします。

# 既知の問題

シェーダーは Xbox 組み込み関数を使用して実装されますが、シェーダー
モデル 6 で WaveIntrinsics を使用するように更新する必要があります
(少なくともデスクトップ システムのサブセットで動作する必要があります)。
