# ShadowMap 示例

*此示例可用于 Microsoft 游戏开发工具包 (2022 年 3 月)*

# 说明

此示例演示各种阴影映射方法。

![](./media/image2.png)

# 生成示例

如果使用 Xbox One 开发工具包，请将活动解决方案平台设置为 `Gaming.Xbox.XboxOne.x64`。

如果使用 Xbox Series X|S，请将活动解决方案平台设置为 `Gaming.Xbox.Scarlett.x64`。

如果在电脑上运行，请将活动解决方案平台设置为 `Gaming.Xbox.Desktop.x64`。

*有关详细信息，请参阅*__运行示例__，详见*GDK 文档。*

# 实现说明

此示例演示了以下阴影映射技术：

- 百分比更近的筛选 （PCF）

- Variance

- 指数

- 指数方差

为简单起见，该示例仅支持单个&ldquo;级联&rdquo;或阴影向量。 对于同一场景中的多个距离刻度，大型世界阴影地图通常必须实现多个级联。

对于 D3D12 硬件，PCF 与其他技术具有内置的性能优势，因为 HLSL 支持 SampleCmp 和 GatherCmp，后者检索四个卷影映射点击，价格为 1。

其他阴影映射技术可以分组到&ldquo;可筛选&rdquo;阴影映射类别下。 在某些情况下，它们比 PCF 更适合，例如当阴影映射是静态的并且因此可以脱机预筛选时。

此示例演示了 PCF 的三种不同实现，它们产生等效的结果，但具有不同的成本：

- **SampleCmp 步骤 1：** 着色器使用 SampleCmp HLSL 方法。 阴影图示例相隔一个纹素。 *通常不建议*使用此方法，因为样本数量不必要地高。

- **SampleCmp 步骤 2：** 着色器使用 SampleCmp HLSL 方法。 阴影图示例是两个相隔的纹素。 为了实现所需的样本权重，纹理坐标会受到干扰。

- **GatherCmp：** 着色器使用 GatherCmp HLSL 方法。 阴影图示例是两个相隔的纹素。 这些示例在 HLSL 代码中加权并手动组合。

不同的阴影映射方法对剔除和深度偏差有不同的要求。 值得注意的是，PCF 可以处理前面剔除，这通常比后台剔除更便宜，因为几何图形往往朝向光源，而不是远离光源。

屏幕菜单允许混合和匹配不同的选项。 一个灰显且文本为&ldquo;-&rdquo;的选项在上下文中不适用（例如，在不可筛选的阴影图上使用筛选模式）。 一个选项，该选项在具有错误值后显示为红色，且单词为&ldquo;invalid&rdquo;（例如，当需要正深度偏差时，深度偏差设置为 0）。
