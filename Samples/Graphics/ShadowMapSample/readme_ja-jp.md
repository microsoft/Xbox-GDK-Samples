# ShadowMap サンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

このサンプルでは、シャドウ マッピングのさまざまな方法を示します。

![](./media/image2.png)

# サンプルのビルド

Xbox One 開発キットを使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.XboxOne.x64` に設定します。

Xbox Series X|Sを使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.Scarlett.x64` に設定します。

PC で実行している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.Desktop.x64` に設定します。

*詳細については、* GDK ドキュメントの「__サンプルの実行__」* を参照してください。*

# Controls

|---|---|

# 実装メモ

このサンプルでは、次のシャドウ マップ手法を示します:

- Percentage Closer Filtering (PCF)

- variance

- 指数

- 指数分散

わかりやすくするために、サンプルでは 1 つの "カスケード" またはシャドウ錐台のみがサポートされています。 大きな世界のシャドウ マップでは、通常、同じシーン内の複数の距離スケールに対して、複数のカスケードを実装する必要があります。

D3D12 ハードウェアの場合、PCF には他の手法よりもパフォーマンス上の利点が組み込まれています。SampleCmp と GatherCmp の HLSL サポートにより、1 つの価格で 4 つのシャドウ マップ タップが取得されます。

その他のシャドウ マップ手法は、"フィルター可能な" シャドウ マップのカテゴリにグループ化できます。 シャドウ マップが静的であり、オフラインで事前にフィルター処理できる場合など、状況によっては PCF に適しています。

このサンプルでは、PCF の 3 つの異なる実装を示します。これにより、同等の結果が得られますが、コストは異なります。

- **SampleCmp ステップ バイ 1:** シェーダーは SampleCmp HLSL メソッドを使用します。 シャドウ マップのサンプルは、1 つのテクセルで分離されています。 サンプルの数が不必要に多いため、この方法は*一般的には推奨されません*。

- **SampleCmp ステップ バイ 2:** シェーダーは SampleCmp HLSL メソッドを使用します。 シャドウ マップのサンプルは、2 つのテクセルが離れています。 目的のサンプルの重みを実現するために、テクスチャ座標が動かされます。

- **GatherCmp:** シェーダーは GatherCmp HLSL メソッドを使用します。 シャドウ マップのサンプルは、2 つのテクセルが離れています。 サンプルは、HLSL コードで手動で重み付けおよび結合されます。

シャドウ マップの方法によって、カリングと深度バイアスの要件が異なります。 PCF は特に、前面カリングを使用できます。これは、多くの場合、背面カリングよりも安価です。これは、より多くのジオメトリが光源に向かって向かう傾向があるためです。

画面上のメニューでは、さまざまなオプションを組み合わせて使用できます。 灰色表示され、テキスト "-" を含むオプションは、コンテキスト内では適用できません (フィルター処理できないシャドウ マップのフィルター モードなど)。 正しくない値の後に "invalid" という単語を含む赤色で表示されるオプション (たとえば、正の深度バイアスが必要な場合、深度バイアスは 0 に設定されます)。

# プライバシーに関する声明

サンプルをコンパイルして実行する場合、サンプルの使用状況を追跡するために、サンプルの実行可能ファイルのファイル名が Microsoft に送信されます。 このデータ コレクションからオプトアウトするには、Main.cpp の "サンプル使用状況テレメトリ" というラベルの付いたコードのブロックを削除します。

Microsoft のプライバシー ポリシー全般の詳細については、「[Microsoft のプライバシーに関する声明](https://privacy.microsoft.com/en-us/privacystatement/)」を参照してください。
