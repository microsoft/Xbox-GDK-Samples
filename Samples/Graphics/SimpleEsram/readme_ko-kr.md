# 간단한 ESRAM 샘플

*이 샘플은 Microsoft 게임 개발 키트(2022년 3월)와 호환됩니다.*

# 설명

이 샘플에서는 DirectX 12에서 ESRAM을 활용하는 기본적인 방법을 보여 줍니다. XG 및 XGMemory API를 활용하여 가상 리소스 메모리를 예약한 다음 DRAM 및 ESRAM에 매핑합니다. 몇 가지 페이지 매핑 구성표를 통해 XGMemory 라이브러리를 사용하여 DRAM & ESRAM 간에 리소스 레이아웃을 사용자 지정할 수 있는 방법을 예시합니다.

XG 라이브러리는 DirectX에서 사용할 수 있는 다양한 리소스 종류에 대한 페이지 수를 계산하기 위한 간단한 인터페이스를 제공합니다. DirectX 리소스의 실제 크기, 레이아웃, 맞춤 및 메타데이터 구조는 내부적으로 계산되므로 리소스 크기를 정확하게 결정하는 데 필요한 단계이며, 이를 사용하여 페이지 수를 계산할 수 있습니다. 그런 다음 이 페이지 수를 사용하여 페이지 단위로 ESRAM/DRAM 매핑을 수행할 수 있습니다.

XGMemory 라이브러리는 리소스 페이지를 ESRAM 메모리에 매핑하는 데 권장되는 방법입니다. 이 API는 가상 주소 공간을 할당하고 해당 페이지를 물리적 메모리에 커밋하는 하위 수준의 세부 사항을 숨기면서도 개발자가 주소 공간의 각 페이지를 DRAM 또는 ESRAM에 매핑할지 여부를 완전히 제어할 수 있도록 해줍니다. 또한 안전한 무료 목록 페이지 할당 체계를 활용하고 잠재적으로 위험한 리소스 앨리어싱을 명시적으로 수행하도록 하여 매핑된 페이지의 일관성을 내부적으로 관리합니다.

샘플의 메모리 매핑 체계에 대한 간략한 개요는 다음과 같습니다.

> *단순 매핑 --* 지정된 수의 리소스 페이지를 ESRAM에 매핑하고
> 나머지 페이지를 DRAM에 매핑합니다. 이 방법의 장점은
> 개발자가 한 번의 함수 호출로 최소한의 작업만 수행하면 되지만
> 사용자 지정 동작을 제공하지 않는다는 점입니다.
>
> *분할 매핑 --* 리소스를 시작 DRAM 섹션
> 중간 ESRAM 섹션, 종료 DRAM 섹션으로 분할합니다. 분할 매핑은
> 활용도가 낮은 영역과 높은 영역이 모두 있는
> 렌더링 타깃에 유용할 수 있습니다. 예를 들어, 실외 장면 렌더링 중
> skybox는 일반적으로 프레임의 상단 부분을 채웁니다. This
> 이렇게 하면 해당 픽셀에 대한 드로우 콜이 한 번만 발생하므로 해당 픽셀에 대한 드로우 콜이 한 번만 발생하여
> 이미지의 나머지 부분보다 ESRAM 잔류로 인한 이점이 적어
> 오버드로가 훨씬 더 많이 발생할 수 있습니다.
>
> *메타데이터 매핑 --* 색상 및 깊이 메타데이터 텍스처만
> ESRAM에 매핑합니다. 이는 지우기 및 확인과 같은 메타데이터 가속 연산을 최적화하면서
> 최소한의 ESRAM을 사용하므로 유용합니다.
>
> *임의 매핑 --* 지정된 확률에 따라 페이지당 무작위로
> DRAM 또는 ESRAM을 선택합니다. 이 매핑 체계에는 특별한 이점이 있는 것이 아니라
> 제공된 API를 고유한 방식으로 활용하는 방법을
> 보여줄 뿐입니다.

XG 및 XGMemory 라이브러리에 대한 자세한 정보 및 전체 API 사양은 XDK 문서에서 확인할 수 있습니다.

참고: Xbox One X에는 ESRAM이 없는 대신 더 빠른 DRAM이 내장되어 있습니다. 이 콘솔에서 샘플은 모든 ESRAM 옵션과 시각화가 비활성화된 상태로 장면을 렌더링합니다.

# 샘플 빌드

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.XboxOne.x64`(으)로 설정합니다.

이 샘플에서는 ESRAM이 사용되지 않고 Gaming.Xbox.XboxOne.x64와만 호환되므로
Gaming.Xbox.Scarlett.x64는 지원하지 않습니다. 에뮬레이션을 사용하여 devkit에서 실행됩니다. *GDK 설명서의* __샘플 실행__에서 *자세한 내용을 참고하세요.*&nbsp;

# 샘플 사용

이 샘플에는 매핑 체계 간에 동적으로 전환하는 기능을 포함하여 프로그램의 모든 상태에 공통으로 적용되는 컨트롤이 있습니다. 각 매핑 체계에는 게임 패드 범퍼와 트리거를 통해 수정할 수 있는 자체 매핑 관련 파라미터도 있습니다. 이러한 컨트롤은 해당되는 경우 화면에도 표시됩니다.
