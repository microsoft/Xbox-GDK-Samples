# TextureCompression 샘플

*이 샘플은 Microsoft 게임 개발 키트(2021년 6월)와 호환됩니다.*

# 설명

이 샘플은 스칼렛 플랫폼에서 사용할 수 있는 새 하드웨어 압축 해제 장치를 텍스처 데이터에 사용하는 방법을 보여줍니다.

# 샘플 빌드

Project Scarlett을 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.Scarlett.x64`(으)로 설정합니다.

이 샘플은 Xbox One을 지원하지 않습니다.

*GDK 설명서의* __샘플 실행__에서 *자세한 내용을 참조하세요.*

# 샘플 사용

![자동으로 생성된 로고 설명의 클로즈업](./media/image3.png)

이 샘플에는 다양한 BCn 인코딩을 보관할 수 있는 압축 비율의 종류를 설명하는 몇 가지 예시 텍스처가 포함되어 있습니다. 컨트롤러를 사용하여 텍스처 및 밉 수준을 대칭 이동할 수 있습니다.

| 동작 | Gamepad |
|---|---|

| 끝내기 | 보기 버튼 |

# 구현 참고 사항

하드웨어 압축 해제 장치는 Direct Storage API를 사용하여 NVMe 컨트롤러와 파이프라인으로 연결됩니다. 요청 시 압축 해제를 활성화하면 NVMe 드라이브에서 스트리밍된 데이터가 메모리에 기록되기 전에 압축 해제 장치를 통해 자동으로 파이프됩니다. 이를 위해 프로그램에서 중간 버퍼 또는 동기화가 필요하지 않습니다. GDK 설명서의 Direct Storage 개요에서 더 자세한 정보를 알아보세요.

샘플에 포함된 .xbtc 텍스처는 GDK의 새로운 XBTC 압축 도구를 사용하여 오프라인으로 압축되었습니다. 이 도구는 DDS 파일을 사용하여 Deflate(즉, Zlib) 알고리즘과 BCn 인코딩 텍스처 데이터를 위해 특별히 설계된 독점적인 BCPack 알고리즘을 모두 사용하여 추가 압축을 실행합니다. GDK 설명서의 Xbox 텍스처 압축기 개요에서 더 자세한 정보를 알아보세요.

# 알려진 문제

현재 xbtc 파일이 출력할 수 있는 PRT 타일 형식은 지원되지 않습니다(XBTC.exe 도구의 --tilemode 옵션 참조).

XG 라이브러리의 버그로 인해 샘플 xbtc 파일이 표준 타일 모드(\_S)로 압축되었습니다. 이후 버전의 샘플에서는 네이티브(\_D) 타일 모드를 지원할 예정입니다(XBTC.exe 도구의 --tilemode 참조).

모든 XBTC 압축은 현재 비파괴적입니다. XBTC 로드맵 문서에 설명된 대로, 향후 GDK 릴리스에서 품질에 따라 크기를 맞바꾸는 옵션을 도입할 예정입니다.
