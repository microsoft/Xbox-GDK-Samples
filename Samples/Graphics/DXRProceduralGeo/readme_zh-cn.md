# 程序化几何图形

*此示例与 Microsoft 游戏开发工具包（2023 年 3 月）和 Windows 10（1903 版）2019 年 5 月更新版兼容*

# 说明

此示例演示了不同类型的过程生成几何图形（以及具有平面的基于三角形的地理位置）的简单 DirectX 光线跟踪 （DXR） 绘制。

# 生成示例

如果使用 Project Scarlett，请将活动解决方案平台设置为 `Gaming.Xbox.Scarlett.x64`。

如果使用具有适当硬件和 Windows 10 版本的个人电脑，请将活动解决方案平台设置为 `Gaming.Deskop.x64`。

此示例不支持 Xbox One。

# 使用示例

此示例允许使用免费摄像头四处移动（可以使用游戏板上的左右摇杆进行控制，也可以使用方向键 + 鼠标进行控制）。 按下按钮/C 键（游戏板/键盘）可切换几何图形动画。 几何图形的默认设置是进行动画处理。 按 B 按钮/V 键可切换阴影投射光动画。 光动画的默认值为关闭。

# 实现说明

此示例演示三角形和过程生成的几何图形的 DXR 使用情况。 第一种情况是，底层加速结构 （BLAS） 将包含符合几何图形的三角形，并且每当光线与加速结构叶相交时，就会注册命中。 遍历后，将执行未命中的着色器或最接近的着色器，具体取决于光线是否相交任何几何图形。

对于过程生成的几何图形，BLAS 不包含几何图形。 而是包含 AABB （D3D12_RAYTRACING_AABB） 的定义。 每当光线再次相交 AABB 时，一个具有自定义逻辑的交集着色器，用于确定光线是否与几何图形相交。 遍历结束时，还会运行最接近或未命中的着色器，具体取决于是否已注册命中。

若要确定要运行的着色器（取决于光线与哪几何图形相交），请使用着色器表，其中包含着色器表记录。 其中包括一个 32 字节着色器缩进器和一组本地根参数，这些参数将本地绑定。 稍后，在调用 traceRay 时，dispathRays 调用中包含的信息将使用 traceRay 调用和几何图形（来自 BLAS）为表中的正确条目编制索引。 对于此示例，我们定义了一个光线代着色器表（包含一个条目）、一个未命中着色器表（有两个条目，一个用于着色，一个用于阴影未命中）和一个命中着色器表（有 22 个条目，每个光线类型每个基元类型一个）。

有两个底层加速结构 （BLAS），一个包含三角形几何图形（平面平面，由 2 个三角形组成），另一个包含所有轴对齐的边界框 （AABB）。 TLAS 将为每个 BLASes 保存一个实例。 TLAS 和 BLAS 是在此示例的帧开头生成的，不会更新。

为错过每个光线并将黑色写入 UAV 的每条光线调用未命中着色器（这代替了在 DispatchRays 调用之前将 UAV 预先清除为黑色）。

Raygen 着色器将使用透视投影将每个像素一条光线投射到场景中。 注册命中时，将再投射两条光线。 一个用于测试阴影（将朝阴影投射场景光的方向），另一个用于根据传入光线和交集点几何图形的法线计算反射特征。 阴影光线将确定是否遮挡此点，而反射光线将根据场景的几何图形检查反射贡献。 在停止之前，反射和阴影的限制为 3 次弹跳（递归限制）。

最接近的着色器将根据基元材料信息、点是否处于阴影中、环境光信息以及是否存在来自其他几何图形的任何反射贡献来负责着色。
