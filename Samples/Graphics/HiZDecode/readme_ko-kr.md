# HiZDecode 샘플

*이 샘플은 Microsoft 게임 개발 키트와 호환됩니다(2022년 3월).*

# 설명

# 이 샘플은 htile 서페이스에서 hi z 값을 추출하는 방법을 보여줍니다.

# 샘플 빌드

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.XboxOne.x64`(으)로 설정합니다.

Xbox Series X|S 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.Scarlett.x64`(으)로 설정합니다.

# 구현 참고 사항

htile 표면은 깊이 스텐실 버퍼와 연결된 메타데이터 표면입니다. 깊이 스텐실 버퍼의 각 8x8 타일에는 연결된 32비트 htile 항목이 있습니다. htile 항목에는 다음 정보가 포함됩니다.

- 보수적인 최소 및 최대 깊이를 인코딩하는 타일에 대한 hi z 정보

- 타일의 모든 픽셀이 스텐실에 대한 특정 팩트에 동의하는지 여부를 기록하는 타일에 대한 hi stencil 정보입니다.

- 타일에 지우기, 압축 또는 확장된 깊이가 포함되어 있는지 여부를 인코딩하는 깊이 압축 메타데이터

- 타일에 지우기, 압축 또는 확장된 스텐실 값이 포함되어 있는지 여부를 인코딩하는 스텐실 압축 메타데이터

이 샘플에서는 htile의 hi z 및 hi 스텐실 부분을 텍스처로 디코딩하는 방법을 보여 줍니다. 이러한 텍스처는 다음을 비롯한 다양한 용도로 사용할 수 있습니다.

- 장면의 컬링 가속화

- 조명에 대한 타일 분류

(이러한 애플리케이션은 여기에서 설명되지 않습니다.)

| | |
|---|---|
| 샘플은 디코딩된 hi z 및 hi 스텐실 텍스처를 축소판 그림 보기에 표시합니다. hi z 축소판 그림에는 빨간색 및 파란색 채널의 최소 깊이와 녹색 채널의 최대 깊이가 있습니다. 채널 선택으로 인해 깊이 범위가 더 큰 타일은 더 녹색으로 표시됩니다. hi stencil thumbnail은 빨간색 채널의 hi stencil test 0 값과 녹색 채널의 hi stencil test 1 값을 표시합니다. Xbox Series X | S 녹색 채널은 항상 htile 형식으로 인해 0으로 설정됩니다. |

Htile 인코딩은 스텐실이 연결된 깊이 버퍼에 있는지 여부에 따라 달라집니다. 스텐실이 없는 경우 최소 및 최대 깊이는 모두 명시적인 14비트 고정 소수점 값입니다. 스텐실이 있는 경우 깊이 범위의 한쪽 끝은 명시적 14비트 고정 소수점 값이고 다른 쪽 끝은 암시적으로 6비트 델타 값에 의해 지정됩니다. 델타는 셰이더 주석에 설명된 사용자 지정 인코딩을 사용합니다.

최대 2개의 hi 스텐실 테스트가 있으며 각 테스트에는 다음과 같은 세 가지 가능한 결과가 있습니다.

1. 타일에 테스트를 만족하는 픽셀이 없습니다.

2. 타일의 모든 픽셀이 테스트를 충족합니다.

3. 일부 픽셀은 테스트를 충족하고 일부 픽셀은 그렇지 않습니다(또는 값이 최신이 아님).

드라이버는 2015년 2월 XDK를 기준으로 스텐실 상태를 자동으로 선택합니다. 레지스터에서 PIX GPU 상태 보기에서 hi stencil 상태를 읽을 수 있습니다.

| | |
|---|---|
| `Context - DB - DB_SRESULTS_COMPARE_STATE\<0|1>` |

이 샘플은 "다시 요약" 패스를 수행하는 옵션을 제공합니다. 이 패스는 약 50us가 소요며, 최신 깊이 데이터에 해당하도록 모든 htile 값을 업데이트합니다. 다시 요약 패스가 없으면 htile은 여전히 유효하지만 일부 hi z 범위는 필요한 것보다 더 넓고 일부 hi stencil 값에는 다른 코드 중 하나가 정확하더라도 "모르는" 코드가 포함됩니다.

다시 합계 비용은 기존 압축 풀기 작업과 결합하여 분할 상환될 수 있습니다. 압축 해제는 일반적으로 다시 시작 여부에 관계없이 거의 동일한 시간이 걸립니다.

# 알려진 문제

이 샘플은 향후 변경될 수 있는 특정 드라이버 선택에 따라 달라집니다.

- htile 표면이 바둑판식 또는 선형으로 만들어지는지 여부

- htile 화면에 대해 선택된 타일링 모드

드라이버 제한으로 인해 샘플은 압축되지 않은 스텐실 버퍼에서 hi 스텐실 사용을 지원하지 않습니다.
