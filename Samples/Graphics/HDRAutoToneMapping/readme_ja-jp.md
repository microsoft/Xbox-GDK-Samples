# HDR 自動のトーン マッピングのサンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

このサンプルは、SDR イメージ自体をレンダリングするタイトルに対して、GameDVR の SDR イメージを生成するため、D3D ドライバーによる自動トーン マッピングを HDR ゲームで使用する方法を示しています。 タイトルでは、既定の自動トーン マッパーを使用したり、3D ルックアップ テーブルとして独自のトーン マッパーを提供することができます。

# サンプルのビルド

Xbox One 開発キットを使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.XboxOne.x64` に設定します。

Xbox Series X|S を使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.Scarlett.x64` に設定します。

*詳細については、* *GDK ドキュメント*の「__サンプルの実行__」を参照してください。

# Xbox One の実装に関する注意事項

Xbox One の HDR ゲームでは、2 つのスワップ チェーンを出力する必要があります。1 つは HDR TV に表示される 10 ビットの HDR10 値のスワップ チェーンで、もう 1 つは GameDVR、スクリーンショット、ストリーミング、配信に使用できる SDR イメージのスワップ チェーンです。 SDR イメージはゲーム側でレンダリングできます。または、自動トーン マッピングが有効な場合にスワップ チェーン作成フラグ D3D12XBOX_RESOURCE_FLAG_ALLOW_AUTOMATIC_GAMEDVR_TONE_MAP を使用して D3D ドライバーによって自動的にレンダリングすることもできます。 既定の自動トーン マッパーでは適切な SDR イメージが生成されますが、ほとんどの場合にはゲーム自体で SDR イメージにマップされたトーンと同じにはなりません。 API SetHDRToneMapperX() では、ゲームにそれ自体のトーン マッパーを提供できるので、D3D ドライバーによる自動トーン マッピングがゲーム自体の SDR イメージと同様のイメージを生成できます。 API フレームごとに呼び出すのが安全です。それにより、ゲームは実行時に 3D LUT を生成し、さまざまなシーンに関してトーン マッパーを動的に調整できます。

SDR イメージを生成するには、次の 3 つの方法があります:

1) ゲームは SDR イメージをレンダリングします。 最適な画質と GPU パフォーマンスが得られますので、これは推奨される方法です。 欠点は、レンダリング パイプラインに余分な複雑さ (つまり、実装と保守のための余分なエンジニアリング時間) が追加され、クロスプラットフォーム ゲームでは望ましくない可能性があることです。 この方法では、ゲームは 2 つのスワップ チェーンを割り当て、HDR イメージと SDR イメージをレンダリングした後、PresentX を使用して両方のイメージを表示します。

2) D3D ドライバーによる既定の自動トーン マッピング。 このメソッドを実装するのが最も簡単です。 タイトルは GameDVR イメージについては認識しません。D3D ドライバーがすべての追加作業を行います。 レンダリング パイプラインに余分な複雑さはありませんが、生成されるイメージは、ゲームの SDR イメージと同じようには見えない可能性が最も高くなります。 この方法では、ゲームは 1 つのスワップ チェーンのみを割り当て、HDR イメージのみをレンダリングしますが、引き続き 1 つのスワップ チェーンで PresentX を使用します。 D3D ドライバーは、タイトル メモリから余分なスワップ チェーンを割り当て、Present 呼び出し中にコンピューティング シェーダーを挿入して SDR イメージを生成します。

3) ゲームのトーン マッパーを使用した自動トーン マッピング。 このメソッドは前の方法と似ていますが、ゲームでは、D3D ドライバーが自動トーン マッピング中に使用する独自のトーン マッパーを指定できます。 このメソッドは両方の世界を最大限に引き出し、レンダリング パイプラインに余分な複雑さはなく、ゲームは引き続き SDR イメージの外観を制御できます。

HDR 自動トーン マッピングを有効にするために、サンプルではスワップ チェーン バッファーの作成時に `D3D12XBOX_RESOURCE_FLAG_ALLOW_AUTOMATIC_GAMEDVR_TONE_MAP` リソース作成フラグを使用します。

サンプルの目的は、HDR イメージではなく、自動トーン マップされた SDR イメージを表示することであるため、サンプルはテレビを HDR モードに切り替えることなく起動します。 X ボタンを押すと、テレビが HDR モードに切り替わります。

サンプルでは、ゲームのトーン マッパーを使用して 3D LUT を動的にレンダリングする方法、それを .DDS ファイルとして保存し、再度ロードする方法を示します。 Y ボタンを押すと、現在のトーン マッパーがタイトル スクラッチ フォルダーに保存され、ここにアクセスできます。

ホワイト ペーパー「[HDR on Xbox One](http://aka.ms/hdr-on-xbox-one)」と Xfest 2018 プレゼンテーション「Xbox One Enhancement for Display Output」を参照してください。

# Xbox Series X の実装に関する注意事項

Xbox Series X のディスプレイ出力ハードウェアには、ハードウェア 3D LUT が含まれています。 これは、タイトルが SDR イメージを生成するための GPU または帯域幅のコストがないことを意味します。 タイトルは引き続き、GPU でコンピューティング シェーダーを使用する従来の Xbox One 自動トーン マッピングの使用をオプトインできます。

Xbox Series X ハードウェア 3D LUT を使用してシステム自動トーン マッパーを使用するには、タイトルは HDR10 スワップ バッファーをレンダリングするだけであり、フラグを指定する必要は*ありません*。 従来の Xbox One 自動トーン マッピングを使用するには、タイトルでフラグ `D3D12XBOX_RESOURCE_FLAG_ALLOW_AUTOMATIC_GAMEDVR_TONE_MAP` を指定する*必要があります*。DeviceResources.cpp のコードを参照してください。
