# HDR 자동 톤 매핑 샘플

*이 샘플은 Microsoft 게임 개발 키트(2022년 3월)와 호환됩니다.*

# 설명

이 샘플에서는 SDR 이미지 자체에 대한 타이틀 렌더링과는 반대로 HDR 게임에서 D3D 드라이버를 통한 자동 톤 매핑을 사용하여 GameDVR을 위한 SDR 이미지를 생성하는 방법을 보여줍니다. 타이틀은 기본 자동 톤 매퍼를 사용하거나 자체 톤 매퍼를 3D 조회 테이블로 제공할 수 있습니다.

# 샘플 빌드

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.XboxOne.x64`(으)로 설정합니다.

Xbox Series X|S를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.Scarlett.x64`(으)로 설정합니다.

*자세한 내용은* *GDK 설명서의* __샘플 실행을__ 참조하세요.&nbsp;

# 샘플 사용

이 샘플에서는 다음 컨트롤을 사용합니다.

| 동작 | Gamepad |
|---|---|
| 자동 톤 맵 방법 변경 | A button |
| TV를 HDR 모드로 전환 | X 버튼 |
| 톤 매퍼를 .DDS 파일로 저장합니다. | Y 버튼 |

# Xbox One에 대한 구현 정보

Xbox One HDR 게임은 HDR TV에 제공되는 10비트 HDR10 값과 GameDVR, 스크린샷, 스트리밍 및 브로드캐스팅에 사용할 수 있는 SDR 이미지가 있는 두 개의 스왑 체인을 출력하는 데 필요합니다. SDR 이미지는 게임에서 렌더링하거나 스왑 체인 생성 플래그 D3D12XBOX_RESOURCE_FLAG_ALLOW_AUTOMATIC_GAMEDVR_TONE_MAP을 사용하여 자동 톤 매핑을 사용하도록 설정한 경우 D3D 드라이버에서 자동으로 렌더링할 수 있습니다. 기본 자동 톤 매퍼는 좋은 SDR 이미지를 생성하지만, 게임의 자체 톤 매핑 SDR 이미지와 같은 모양이 아닐 가능성이 큽니다. API SetHDRToneMapperX()는 D3D 드라이버의 자동 톤 매핑이 게임 고유의 SDR 이미지와 유사한 이미지를 생성할 수 있도록 게임에 고유한 톤 매퍼를 제공할 수 있는 기회를 제공합니다. 모든 프레임마다 API를 호출하여 게임이 런타임에 3D LUT를 생성하여 다른 장면에 대해 동적으로 톤 매퍼를 조정할 수 있습니다.

SDR 이미지를 생성하는 방법에는 세 가지가 있습니다.

1) 게임은 SDR 이미지를 렌더링합니다. 이 방법을 사용하면 최상의 이미지 품질과 GPU 성능을 얻을 수 있으므로 이 방법을 권장합니다. 단점은 렌더링 파이프라인에 복잡성을 더하고, 즉 구현 및 유지 관리하기 위한 추가 엔지니어링 시간을 추가하고, 플랫폼 간 게임에 바람직하지 않을 수 있다는 점입니다. 이 방법을 사용하면 게임에서 두 개의 스왑 체인을 할당하고 HDR 및 SDR 이미지를 렌더링한 다음 PresentX를 사용하여 두 이미지를 모두 표시합니다.

2) D3D 드라이버의 기본 자동 톤 매핑입니다. 이 메서드는 구현하기 가장 쉽습니다. 타이틀은 GameDVR 이미지에 대해 알지 못합니다. D3D 드라이버는 모든 추가 작업을 수행합니다. 렌더링 파이프라인의 복잡성은 더 높지 않지만 생성된 이미지는 게임의 SDR 이미지와 동일하지 않을 가능성이 높습니다. 이 방법을 사용하면 게임에서 스왑 체인을 하나만 할당하고 HDR 이미지만 렌더링하지만 여전히 하나의 스왑 체인과 함께 PresentX를 사용합니다. D3D 드라이버는 타이틀 메모리에서 추가 스왑 체인을 할당하고 Present 호출 중에 컴퓨팅 셰이더를 삽입하여 SDR 이미지를 생성합니다.

3) 게임의 톤 매퍼를 사용한 자동 톤 매핑입니다. 이 메서드는 이전 메서드와 유사하지만 게임은 자동 톤 매핑 중에 D3D 드라이버가 사용할 자체 톤 매퍼를 지정할 수 있습니다. 이 메서드는 두 세계의 최상의 기능을 제공하며, 렌더링 파이프라인에 복잡성이 더 이상 없으며, 게임에서 SDR 이미지의 모양을 제어할 수 있습니다.

HDR 자동 톤 매핑을 사용하도록 설정하기 위해 샘플은 스왑 체인 버퍼를 만들 때 `D3D12XBOX_RESOURCE_FLAG_ALLOW_AUTOMATIC_GAMEDVR_TONE_MAP` 리소스 생성 플래그를 사용합니다.

샘플의 목표는 HDR 이미지가 아닌 자동 톤 매핑 SDR 이미지를 표시하는 것이므로 샘플은 TV를 HDR 모드로 전환하지 않고 시작됩니다. X 단추를 누르면 TV가 HDR 모드로 전환됩니다.

이 샘플에서는 게임의 톤 매퍼를 사용하여 3D LUT를 동적으로 렌더링하는 방법, 으로 저장하는 방법을 보여 줍니다. DDS 파일을 다시 로드합니다. Y 단추를 누르면 현재 톤 매퍼가 타이틀 스크래치 폴더에 저장되고 여기에서 액세스할 수 있습니다.

백서 "[Xbox OneHDR](http://aka.ms/hdr-on-xbox-one)" 및 Xfest 2018 프레젠테이션 "Xbox One 디스플레이 출력 향상"을 참조하세요.

# Xbox Series X에 대한 구현 정보

Xbox Series X의 디스플레이 출력 하드웨어에는 하드웨어 3D LUT가 포함되어 있습니다. 즉, SDR 이미지를 생성하기 위해 타이틀에 GPU나 대역폭 비용이 들지 않습니다. 타이틀은 여전히 GPU에서 컴퓨팅 셰이더를 사용하는 레거시 Xbox One 자동 톤 매핑을 사용할 수 있습니다.

Xbox Series X 하드웨어 3D LUT를 사용하여 시스템 자동 톤 매퍼를 사용하기 위해 타이틀은 단순히 HDR10 스왑 버퍼를 렌더링하므로 플래그를 지정해서는 *안 됩니다*. 레거시 Xbox One 자동 톤 매핑을 사용하려면 타이틀에서 `D3D12XBOX_RESOURCE_FLAG_ALLOW_AUTOMATIC_GAMEDVR_TONE_MAP`플래그를 지정*해야 합니다*. DeviceResources.cpp의 코드를 참조하세요.
