# GpuBench サンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

GpuBench は、ATG の内部で開発された GPU ベンチマーク ツールです。 サンプルでは、ピーク時の GPU の使用率を達成する、または GPU ペナルティを明らかにするように設計されたモジュラー テストを実行します。 GpuBench は Xbox One ファミリのデバイスのすべてのハードウェアで動作します。

# サンプルのビルド

Xbox Series X|S を使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.Scarlett.x64` に設定します。

Xbox One 開発キットを使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.XboxOne.x64` に設定します。

*詳細については、* *GDK ドキュメント*の「__サンプルの実行__」を参照してください。

サンプルでは、次のコマンド ライン引数もサポートされています (無人操作の場合):

- "all" -- すべてのベンチマークを実行する

- "バッファー コンピューティング テクスチャ" などの一覧 -- 指定したベンチマークを実行する

ATG では、ユーザーが独自のベンチマークをサンプルに追加することをお勧めします。 新しいベンチマークを追加するには、新しい .cpp ファイルを Visual Studio プロジェクトに追加するだけです。 新しいファイルには、ベンチマークとテストから派生し、必要な仮想メソッドを実装するクラスが含まれている必要があります。 既存のベンチマークをモデルとして使用します。 必要な HLSL ファイルもプロジェクトに追加してください。

# 実装メモ

各ベンチマークは、一連のテストで構成されます。 サンプルでは、GPU タイムスタンプを使用して期間を測定し、いくつかの GPU ハードウェア カウンター値を取得するために、各テスト実行を複数回実行します。 サンプルでは、完全同期の一時停止とキャッシュ フラッシュを使用して、各テスト実行を適切に分離します。

ベンチマークでは、次の出力が生成されます:

- 構成可能な列のセット、ヘッダー行、およびテストごとに 1 つの結果行を含むテキスト テーブル。 テーブルが出力されます:

   - 画面の表示

   - 標準デバッガー出力へ

   - GpuBench.txt というタイトル スクラッチ ドライブ内のテキスト ファイルへ (例: xbdir /x/title xd:\\GpuBench.txt)

- ベンチマーク名に従って名前が付けられたタイトル永続ストレージ ドライブ内の PIX GPU キャプチャ。各テストの 1 回の実行を含みます (例: xbdir /x/title xr:\\Compute.pix3)

ベンチマークでは、GPU カウンターを使用して、意図に従って実際に GPU を実行したことを検証します。 たとえば、コンピューティング ベンチマークは SQ_PERF_SEL_INSTS_VALU カウンターを使用して、実行されたハードウェア算術演算の数を検証し、その数値が予想と比較してチェックされます。 サンプルでは、文字列 "API" と "GPU" ("Bytes API" と "Bytes GPU" など) を使用して列に名前を付ける規則を採用して、さまざまな数量の予想値と実際の値を指定します。

GpuBench には、GpuCounterSet クラスとサポート クラスでの GPU ハードウェア カウンター取得用のラッパーが用意されています。 これらのクラスは、基礎となる D3D11.X GPU カウンター API のスタンドアロンの使用例としても役立つ場合があります。 GPU カウンターは PIX で取得することもできますが、ランタイム取得ではイテレーションの方が高速です。 また、サンプルでは、PIX に実装されていない特定の機能がサポートされています:

- シェーダー ステージ別にカウンターを制限する (たとえば、頂点シェーダーではなくピクセル シェーダーでのみテクスチャ フェッチをカウントする)

- 既定以外の方法でカウンターを集計する (たとえば、ハードウェア インスタンス間の合計ではなく標準偏差を見つける)

タイトルは開発ビルドでのみ GPU カウンターを取得でき、出荷ビルドではそれに依存しないでください。

# 既知の問題

一部のベンチマークでは、Scorpio クラス (およびそれ以降) のハードウェアでのみ使用できる GPU カウンターまたはハードウェア機能が必要です。 これらのベンチマークは、以前のハードウェアで実行されますが、後のハードウェアに関する詳細情報を提供します。
