# GpuBench 示例

*此示例可用于 Microsoft 游戏开发工具包 (2022 年 3 月)*

# 说明

GpuBench 是 ATG 内部开发的 GPU 基准测试工具。 该示例运行的模块化测试旨在实现峰值 GPU 速率或照亮 GPU 处罚。 GpuBench 可在 Xbox One 系列设备的所有硬件上运行。

# 生成示例

如果使用 Xbox Series X|S，请将活动解决方案平台设置为 `Gaming.Xbox.Scarlett.x64`。

如果使用 Xbox One 开发工具包，请将活动解决方案平台设置为 `Gaming.Xbox.XboxOne.x64`。

*有关详细信息，请参阅*__运行示例__，详见 *GDK 文档中。*

# 实现说明

每个基准由一系列测试组成。 该样本多次运行每个测试运行，以便使用 GPU 时间戳测量持续时间，并检索一定数量的 GPU 硬件计数器值。 该样本负责通过完全同步暂停和缓存刷新来正确隔离每个测试运行。

基准生成以下输出：

- 一个文本表，其中包含一组可配置的列、一个标题行以及每个测试一个结果行。 已打印该表：

   - 在屏幕上

   - 到标准调试程序输出

   - 到游戏暂存驱动器中名为 GpuBench.txt 的文本文件（例如 xbdir /x/title xd:\\GpuBench.txt）

- 根据基准名称命名的游戏持久存储驱动器中的 PIX GPU 捕获，其中包含每个测试的一次运行（例如 xbdir /x/title xr:\\Compute.pix3）

该基准使用 GPU 计数器来验证它们是否已根据自己的意图实际使用了 GPU。 例如，计算基准使用 SQ_PERF_SEL_INSTS_VALU 计数器来验证已执行多少硬件算术运算，并根据预期检查该数字。 该样本采用使用字符串&ldquo;API&rdquo;和&ldquo;GPU&rdquo;命名列的约定（例如&ldquo;字节 API&rdquo;与&ldquo;字节 GPU&rdquo;）来指定各种数量的预期值与实际值。

GpuBench 为 GpuCounterSet 类中的 GPU 硬件计数器检索和支持类提供包装器。 这些类还可能用作基础 D3D11.X GPU 计数器 API 的独立示例用法。 也可以在 PIX 中检索 GPU 计数器，但运行时检索的迭代速度更快。 此外，该样本还支持 PIX 中未实现的某些功能：

- 通过着色器演示区域限制计数器（例如，仅在像素着色器中提取纹理计数，而不在顶点着色器中获取）

- 以非默认方式聚合计数器（例如，查找标准偏差，而不是硬件实例的总和）

游戏只能在开发版本中检索 GPU 计数器，不应在交付版本时依赖它们。

# 已知问题

某些基准测试需要 GPU 计数器或硬件功能，这些功能仅在 Scorpio 类硬件（及以上）中提供。 这些基准测试在早期版本硬件上运行，但提供有关更高版本硬件的详细信息。
