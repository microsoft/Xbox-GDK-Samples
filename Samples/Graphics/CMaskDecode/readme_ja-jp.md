# CMaskDecode サンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

# このサンプルは、cmask サーフェイスから高速クリア値を抽出する方法を示します。

# サンプルのビルド

Xbox One 開発キットを使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.XboxOne.x64` に設定します。

Xbox Series X|S を使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.Scarlett.x64` に設定します。

*詳細については、* *GDK ドキュメント*の「__サンプルの実行__」を参照してください。

# 実装メモ

cmask サーフェスは、レンダー ターゲットに関連付けられたメタデータ サーフェスです。 レンダー ターゲットの各 8x8 タイルには、4 ビットの cmask エントリが関連付けられています。 cmask エントリには、次の情報が含まれています:

• MSAA が有効になっていない場合、cmask の各ビットは、1 つの 16 ピクセル サブタイルの "クリア" 状態を表します (サブタイルの形状はデータ形式によって異なります。マイクロタイリング モード
[CMask デコード](https://developer.microsoft.com/en-us/games/xbox/docs/gdk/cmask-decoding) による) • MSAA が有効になっている場合、2 つの上位ビットの cmask はそれぞれ 1 つの 32 ピクセル サブタイルの "クリア" 状態を表します (正確なサブタイルの形状については、[CMask デコード](https://developer.microsoft.com/en-us/games/xbox/docs/gdk/cmask-decoding)のドキュメントを参照してください)。 2 つの下位ビットには fmask メタデータが含まれています。
| | |
|---|---|
|Xbox One と Xbox Series X|S のスウィズリング モードについては、ドキュメントの詳細を参照してください|


このサンプルでは、cmask をテクスチャにデコードする方法と、高速クリア ビットを解釈する方法を示します。 この情報は、基になるサーフェスのクリアな領域の検出を高速化するために使用できます。 (ここでは示されていない) 1 つのアプリケーションは、ほとんど空のテクスチャの高速クリア除去をスキップするかもしれません。

このサンプルでは、デコードされた高速クリア情報が、メイン シーン上の赤/緑のオーバーレイとして表示されます。 緑色のピクセルは、完全にクリアされたタイル (またはサブタイル) に属します。 赤いピクセルは、部分的に書き込まれるタイル (またはサブタイル) に属します。

このサンプルは、DirectX 12.X を使用して実装されています。 同じシェーダー (ColorDecompressUtility.hlsli/ CMaskDecodeCS.hlsl) は、ルート署名を削除した場合に DirectX 11.X 実装に使用できます。

Microsoft のプライバシー ポリシー全般の詳細については、「[Microsoft のプライバシーに関する声明](https://privacy.microsoft.com/en-us/privacystatement/)」を参照してください。
