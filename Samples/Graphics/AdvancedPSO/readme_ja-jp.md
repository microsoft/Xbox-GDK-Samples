# AdvancedPSO Sample

*このサンプルは March 2022 GDK と互換性があります*

# 説明

このサンプルでは、ストック DirectX 12 メソッド (CreateGraphicsPipelineState) に対するメモリ使用率とランタイムのパフォーマンスを向上する Xbox 固有パイプライン状態オブジェクト (PSO) の生成メソッドを示します。 このサンプルは、PC で実行される PSOGen と Xbox で実行される AdvancedPSO の 2 つの Visual Studio ソリューションとして構成されています。

PSOGen ソリューションは、オフライン PSO の生成を示しています。 これは PC 上で実行され、特定のシェーダーの組み合わせに対してシリアル化された PSO コンポーネントのセットを生成します。 ソース コードは、PSO シリアル化 API の使用方法を示しています。 (SerializeGraphicsPipelineStateX)

AdvancedPSO ソリューションはコンソールで実行されます。 PSO セットは実行時にオンデマンドで読み込まれ、逆シリアル化されます (DeserializeGraphicsPipelineStateX)。 このセットは、重複除去と呼ばれるプロセスを使用して、すべての組み合わせに必要な最小限のデータ量です。

AdvancedPSO サンプルでは、PSO の *派生* も示されています。 これは、API によって定義された特定の属性 (CreateDerivedGraphicsPipelineState) によって異なる新しい PSO を作成するための、非常にパフォーマンスとメモリ効率に優れた方法です。

# サンプルの構築

AdvancedPSO プロジェクトは、PSOGen によって生成されたプリコンパイル済み PSO マイクロコードを使用します。 シェーダー コンパイラは GDK バージョン間で変更される可能性があるため、出力も変更されます。 このため、AdvancedPSO プロジェクトでは、プリコンパイル済み PSO とそのビルド環境の間の GDK バージョンが一致する必要があります。

サンプルでバージョン管理エラーが検出されると、ランタイム エラーが生成されます。 別の GDK に対してコンパイルする場合は、PSOGen ツールをビルドして実行し、逆シリアル化された PSO を更新してから、AdvancedPSO サンプルを再実行します。

ソリューションをビルドして実行すると、Visual Studioは

- PSOGen プロジェクトをビルドする
- PC で PSOGen プロジェクトを実行してオフライン PSO を生成する
- AdvancedPSO プロジェクトをビルドする
- 本体で AdvancedPSO 実行可能ファイルを実行してオフラインの PSO を使用する

# サンプルの使用方法

このサンプルを使用するには、AdvancedPSO サンプルを実行するだけです。 各 PSO 作成方法のメトリックが画面に表示されます。 異なるシェーダーの組み合わせを生成したり、シェーダー ソースを編集したりするには、PSOGen 実行可能ファイルを再実行してから、AdvancedPSO サンプルを実行します。

# 実装メモ

PSOGen プロジェクトは、PC、d3d12_x\[s\].h、.lib、および .dll 用にビルドされた D3D12.x\[s\] UMD ドライバーのカスタム バージョンとリンクする必要があります。 これは、GDK インストール ディレクトリ (`<GDK root\>\bin\XboxOne` または `<GDK root\>\bin\Scarlett`) 内にあります。 このライブラリは、そのディレクトリ内の他のいくつかのカスタムビルド ライブラリとリンクします。 これらは、正常に返されるように **D3D12CreateDevice** のパス上にある必要があります。 PSOGen プロジェクトは、これらのライブラリをプロジェクト ディレクトリに複製するためのカスタム ビルド ステップで構成されます。 異なるセットがあることに注意してください

|---|---|
|Xbox One 用ライブラリ & Xbox Series X\|S.|

| Xbox One | Scarlett (Xbox Series X\|S) |
|---|---|---|
| d3d12_x.dll | d3d12_xs.dll |
| xgs12_pc_x.dll | xgs12_pc_xs.dll |
| xg.dll | xg_xs.dll |
| dxcompiler_x.dll | dxcompiler_xs.dll |
| sc_dll.dll | xbsc_xs.dll |
| scdxil.dll | newbe_xs.dll |

プリコンパイル済みシェーダー BLOB とシリアル化されたパイプライン状態パケットは次のとおりです。
コンパイルされた PSO をプロジェクト構成によって設定されたプラットフォーム固有のディレクトリに出力します。このディレクトリは、AdvancedPSO プロジェクトによって対応するターゲット プラットフォームにデプロイされます。 PSOSet クラスは、PSO コンポーネントのセットを生成して読み込むのに使用されます。 この実装は、必要な手順の最も重要なデモンストレーションであるため、特に最適ではありません。 コンポーネントは個々のファイルとして格納されます。実際には、通常は BLOB ストレージにアーカイブされます。 また、シェーダーの組み合わせを事前に読み込んだり、シリアル化またはシリアル化解除にマルチスレッドを使用したりすることはありません。
| | |
|---|---|
|Xbox One と Xbox Series X|S の間では交換できません。 PSOGen |


このサンプルでは、(Minitracker クラスの) XMemAlloc フックを使用して、さまざまな作成方法のドライバー メモリ使用量を測定します。 ドライバーは、最初の PSO の作成時に余分な内部ストレージを事前に割り当てます。 このサンプルでは、ObjectId 属性を使用して、これらの割り当てを統計から除外します。 ObjectId 属性のセマンティクスはパブリック ヘッダーに公開されず、変更される可能性があります。 これらは将来の GDK リリースでエクスポートされる可能性があります。
