#   VRS 및 스파스 조명 샘플

*이 샘플은 Microsoft 게임 개발 키트(2020년 8월)와 호환됨*

# 

# 설명

이 샘플에는 이전 VRS 샘플보다 VRS 음영 비율 이미지를 생성하기 위해 더
최적화된 셰이더가 포함되어 있습니다.

이 샘플은 스파스 지연 조명을 구현합니다. VRS로 g 버퍼를 렌더링합니다.
그런 다음 동일한 삼각형과 동일한 g-버퍼 값으로 인접한 픽셀을 조명하는
중복을 방지하여 조명에 대한 픽셀 버퍼를 만듭니다. 이 픽셀 하위 집합이
켜져 있고 값이 가로, 세로 또는 대각선으로 복사됩니다. 이 샘플은 VRS와
스파스 조명 모두에서 상당한 GPU 절감 효과를 보여줍니다.

샘플은 압축된 깊이 평면 수식을 사용하거나 SV_Coverage 및
SV_ShadingRate를 사용하여 빛에 대한 픽셀 하위 집합을 계산하는 두 가지
다른 방법을 제공합니다. 이 후자의 방법은 4비트의 g-버퍼 공간이 필요하며
\'확장\' 깊이 타일 또는 PC에 필요합니다.

샘플은 지연된 조명 패스에 필요한 총 웨이브 수를 줄이는 것을 보여줍니다.
그 중 상당한 비용은 소프트 섀도를 따라가는 것입니다. 스파스 SSR, SSAO,
SSGI, 화면 공간 섀도 마스크, 안개 등을 포함하여 동일한 기술과 버퍼를
사용하여 다른 스파스 패스가 가능합니다. 샘플은 프레임당 어떤 픽셀이
켜지는지 \'회전\'을 구현합니다. 이것은 TAA와 결합하여 지상 진실에 수렴할
때 유용할 수 있습니다.

마지막으로 샘플은 사후 프로세스로 \'VRS 사각형\'을 제거하는 방법인
\'디블로킹\'을 보여줍니다.

# 구현 참고 사항

화면은 16x16 타일로 나뉘며 각 타일에는 개수(텍스처의 R8 항목)와 타일당
최대 224dwords의 페이로드 데이터가 있습니다. 페이로드 dword는 각각
4비트의 타일 상대 x/y 좌표, 21비트 비표준 깊이 및 조명 계산의 최종
결과를 수평, 수직 또는 대각선으로 복사할지 여부에 대한 3비트로
구성됩니다. 타일의 조명 계산 수가 224보다 크면 wave32가 조기에 종료될 수
없으므로 256픽셀 모두가 기존 방식으로 켜집니다.

모든 픽셀을 비추기 위해 충분한 파동이 파견되며, 픽셀 수 감소로 인해
파동이 타일에서 즉시 조기에 나올 때 승리합니다. 작업이 있는 각 웨이브는
동일한 16x16 타일 내에서 픽셀을 처리합니다. 즉, 조명 목록은 여전히
​​웨이브에 스칼라이며 중요한 최적화입니다.

지연 조명 셰이더는 셰이더 시작 시 SparseLightingPrefix84를 호출하고
셰이더 끝에서 SparseLightingPostfix를 호출하여 희소 조명을 지원하도록
간단하게 수정됩니다.

가장 관심 있는 셰이더는 다음과 같습니다.

1.  GenerateShadingRateCS.hlsl

2.  DepthjDecompressAndBuildSparseBuffersCS.hlsl

3.  SparseLightingCommon.hlsli

4.  LightingShader.hlsli

5.  Deblock.hlsli

6.  SparseLightingShowPixelCopiesCS.hlsl은 디버그 셰이더로 연구하는 것도
    흥미로울 수 있습니다.

샘플은 또한 압축된 reverseZ를 사용하고 선형 순방향 Z를 출력하는 깊이
압축 해제 컴퓨터 셰이더를 구현합니다(DepthDecompress.hlsl 참조).

# 알려진 문제

음영 비율 결정은 어떤 경우에는 일시적으로 불안정하며 VRS 사각형을
제거하기 위한 포스트 디블로킹 프로세스에 의해 더 악화될 수 있습니다.
일반적으로 TAA는 이 약간의 불안정성을 숨기고 실제에 수렴하지만 샘플에는
TAA 구현이 없습니다.

# 업데이트 기록

2021년 6월 최초 출시

다음을 포함하도록 2021년 11월 업데이트됨:

1.  ID 기술로 평가판으로 제공되는 새로운 광도 곡선에 대한 지원 추가

2.  UI 토글로 깊이 불연속 확인 옵션 추가

3.  2x2 픽셀 블록의 픽셀 중 3/4이 덮이는 경우를 포함하여 이제 더 나은
    픽셀 회전이 추가되었으며, CPU에서 복사 코드를 미리 계산하여
    최적화되었습니다.

4.  Sobel을 사용하지 않는 완전히 새로운 에지 감지 필터이므로 Sobel에
    대한 모든 참조를 삭제했습니다.

5.  비결정성 버그 수정

6.  오프닝 장면에서 145us 가치의 최적화

7.  압축된 깊이에서 또는 적용 범위만 사용하는 독립 실행형 셰이더로 희소
    버퍼를 계산하는 셰이더 간에 더 나은 코드 공유가 추가되었습니다.
