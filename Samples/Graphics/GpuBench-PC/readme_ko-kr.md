# GpuBench 샘플

*이 샘플은 Microsoft 게임 개발 키트와 호환됩니다(2022년 3월).*

# 설명

GpuBench는 ATG에서 내부적으로 개발한 GPU 벤치마킹 도구입니다. 샘플은 최대 GPU 속도를 달성하거나 GPU 페널티를 나타내도록 설계된 모듈식 테스트를 실행합니다. GpuBench는 Xbox One 장치 제품군의 모든 하드웨어에서 실행됩니다.

# 샘플 빌드

Xbox Series X|S를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.Scarlett.x64`(으)로 설정합니다.

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.XboxOne.x64`(으)로 설정합니다.

# 구현 참고 사항

각 벤치마크는 일련의 테스트로 구성됩니다. 샘플은 GPU 타임스탬프를 사용하여 지속 시간을 측정하고 몇 가지 GPU 하드웨어 카운터 값을 검색하기 위해 각 테스트를 여러 번 실행합니다. 이 샘플은 전체 동기화 일시 중지 및 캐시 플러시를 통해 각 테스트 실행을 적절히 격리합니다.

벤치마크는 다음과 같은 출력을 생성합니다:

- 구성 가능한 열 세트, 머리글 행 및 테스트당 하나의 결과 행이 포함된 텍스트 테이블입니다. 표가 인쇄됩니다.

   - 화면에 표시

   - 표준 디버거 출력으로

   - GpuBench.txt라는 타이틀 스크래치 드라이브의 텍스트 파일로(예: xbdir /x/title xd:\\GpuBench.txt)

- 각 테스트의 실행을 한 번씩 (예: xbdir /x/title xr:\\Compute.pix3) 포함하는 벤치마크 이름에 따라 명명된 타이틀 퍼시스턴트 스토리지 드라이브에 PIX GPU 캡처

벤치마크는 GPU 카운터를 사용하여 의도에 따라 실제로 GPU를 실행했는지 확인합니다. 예를 들어, 컴퓨팅 벤치마크는 SQ_PERF_SEL_INSTS_VALU 카운터를 사용하여 수행된 하드웨어 산술 연산 수를 확인하고 해당 수치를 예상치와 비교하여 확인합니다. 이 샘플에서는 다양한 수량의 예상 값과 실제 값을 지정하기 위해 ("Bytes API" vs "Bytes GPU"에서와 같이) "API" 및 "GPU" 문자열을 사용하여 열 이름을 지정하는 규칙을 채택합니다.

GpuBench는 GpuCounterSet 클래스에서 GPU 하드웨어 카운터 검색을 위한 래퍼와 지원 클래스를 제공합니다. 이러한 클래스는 기본 D3D11.X GPU 카운터 API의 독립형 예제 용도로도 유용할 수 있습니다. GPU 카운터는 PIX에서도 검색할 수 있지만, 런타임 검색을 사용하면 반복이 더 빠릅니다. 또한 이 샘플은 PIX에서 구현되지 않은 특정 기능을 지원합니다:

- 셰이더 스테이지별로 카운터 제한(예: 버텍스 셰이더가 아닌 픽셀 셰이더에서만 텍스처 페치 횟수 계산)

- 기본값이 아닌 방법으로 카운터 집계(예: 하드웨어 인스턴스 전체의 합계가 아닌 표준 편차 구하기)

타이틀은 개발 빌드에서만 GPU 카운터를 검색할 수 있으며, 출시 빌드에서는 GPU 카운터에 의존해서는 안 됩니다.

# 알려진 문제

일부 벤치마크는 Scorpio급 이상의 하드웨어에서만 사용할 수 있는 GPU 카운터 또는 하드웨어 기능을 필요로 합니다. 이러한 벤치마크는 이전 하드웨어에서 실행되지만 이후 하드웨어에 대한 자세한 정보를 제공합니다.
