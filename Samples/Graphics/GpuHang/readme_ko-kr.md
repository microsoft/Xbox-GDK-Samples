# GpuHang 샘플

*이 샘플은 Microsoft 게임 개발 키트(2022년 3월)와 호환됩니다.*

# 설명

GpuHang 샘플은 일반적으로 발생하는 다양한 GpuHang을 재현하는 테스트베드로, 사후 조사를 위한 xhit 파일 덤프를 생성합니다. 이러한 xhit 파일을 검사하면 자연스럽게 발생하는 중단을 디버그할 때 어디서 정보를 찾을지 알 수 있습니다.

# 샘플 빌드

Xbox Series X|S를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.Scarlett.x64`(으)로 설정합니다.

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.XboxOne.x64`(으)로 설정합니다.

# 구현 참고 사항

왼쪽 목록의 각 선택 영역은 잠재적인 중단 유형을 나타냅니다. 사용자가 'A'를 누를 때까지 선택 영역이 중단 없이 실행됩니다. 이 작업은 중단을 유발하는 샘플 작업에 약간의 변경을 트리거합니다. 이 시점에서 샘플은 대개 종료되고 PIX에서 검사할 수 있는 xhit 파일을 생성합니다.

선택 영역이 중단 모드가 아닌 경우 'X'를 누르면 PIX GPU 캡처가 트리거됩니다. 이 캡처는 중단되지 않는 정상적인 작업 시퀀스를 파악하는 데 유용할 수 있습니다.

ATG는 사용자가 샘플에 자신의 중단을 추가하도록 권장합니다. 새 중단을 추가하려면 Visual Studio 프로젝트에 새 .cpp 파일을 추가만 하면 됩니다. 새 파일에는 Hang에서 파생되고 IHang의 필수 가상 메서드를 구현하는 클래스가 포함되어야 합니다. 기존 중단을 모델로 사용합니다. 프로젝트에 필수 HLSL 파일도 추가합니다.

# 알려진 문제

의도적으로, 샘플은 GPU를 중단시켜 실행 파일을 종료하는 경우가 많습니다.

D3D12 유효성 검사 계층은 이 샘플에서 중단을 유발하는 일부 오류를 감지합니다. 데모 목적으로, 샘플에서는 관련 유효성 검사 기능이 비활성화되어 있습니다. 경우에 따라 유효성 검사를 완전히 비활성화하지 못할 수도 있습니다. 해당 중단은 목록에 '(\~V)' 표기법으로 표시되어 검증된 빌드에서 해당 예제가 제대로 작동하지 않음을 나타냅니다.
