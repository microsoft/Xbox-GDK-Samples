# GpuHang サンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

GPUHang サンプルは、よく発生するさまざまな Gpuhang を再現し、事後調査のために xhit ファイルダンプを生成する試験台です。 これらの xhit ファイルを調べることで、自然に発生するハングのデバッグに関する情報をどこで検索するかが分かります。

# サンプルのビルド

Xbox Series X|S を使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.Scarlett.x64` に設定します。

Xbox One 開発キットを使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.XboxOne.x64` に設定します。

*詳細については、* *GDK ドキュメント*の「__サンプルの実行__」を参照してください。

# 実装メモ

左側の一覧の各選択は、可能性のあるハングの種類を表します。 選択は、ユーザーが 'A' を押すまでハングすることなく実行されます。 このアクションにより、サンプル操作のわずかな変更がトリガーされ、ハングが発生します。 この時点で、サンプルは終了し、PIX で調べることができる xhit ファイルを生成します。

選択がハング モードでない場合は、'X' キーを押すと PIX GPU キャプチャがトリガーされます。 このキャプチャは、通常のハングしない一連の操作を特定する際に役立ちます。

ATG では、ユーザーが独自のハングをサンプルに追加することをお勧めします。 新しいハングを追加するには、新しい .cpp ファイルを Visual Studio プロジェクトに追加するだけです。 新しいファイルには、ハングから派生し、IHang の必要な仮想メソッドを実装するクラスが含まれている必要があります。 既存のハングをモデルとして使用します。 必要な HLSL ファイルもプロジェクトに追加してください。

# 既知の問題

設計上、サンプルは GPU をハングさせます。これにより、多くの場合、実行可能ファイルが終了します。

D3D12 検証レイヤーは、このサンプルでハングする原因となるエラーの一部をキャッチします。 デモンストレーションのために、サンプルでは関連する検証チェックが無効になっています。 場合によっては、検証チェックを完全に無効にできないことがあります。 対応するハングは、検証済みのビルドで例が正しく機能しないことを示すために、"(\~V)" という表記で一覧にマークされます。
