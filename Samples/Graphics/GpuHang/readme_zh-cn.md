# GpuHang 示例

*此示例可用于 Microsoft 游戏开发工具包（2022 年 3 月）*

# 说明

GpuHang 示例是一个试验台，可再现各种常见 GpuHang，从而生成事后检查的 xhit 文件转储。 检查这些 xhit 文件可能会教我们在哪里寻找在调试挂起中自然发生的信息。

# 生成示例

如果使用 Xbox Series X|S，请将活动解决方案平台设置为 `Gaming.Xbox.Scarlett.x64`。

如果使用 Xbox One 开发工具包，请将活动解决方案平台设置为 `Gaming.Xbox.XboxOne.x64`。

*有关详细信息，请参阅*__运行示例__，详见 *GDK 文档中。*

# 实现说明

左侧列表中的每个选择都表示潜在的挂起类型。 在用户按下&ldquo;A&rdquo;之前，所选内容不会挂起。 该操作会在示例操作中触发轻微更改，从而导致挂起。 此时，该示例通常会终止并生成可在 PIX 中检查的 xhit 文件。

当所选内容未处于挂起模式时，按&ldquo;X&rdquo;将触发 PIX GPU 捕获。 此捕获可用于确定正常、非挂起的操作序列。

ATG 鼓励用户将自己的挂起添加到示例。 若要添加新的挂起，只需将新的 .cpp 文件添加到 Visual Studio 项目。 新文件应包含派生自 Hang 的类，该类实现 IHang 所需的虚拟方法。 使用现有的挂起作为模型。 同时向项目添加任何必需的 HLSL 文件。

# 已知问题

根据设计，该示例挂起 GPU，这通常会终止可执行文件。

D3D12 验证层捕获导致此示例中挂起的一些错误。 出于演示目的，示例中禁用了相关的验证检查。 在某些情况下，无法完全禁用验证检查。 相应的挂起在列表中标记为&ldquo;(\~V)&rdquo;，以指示这些示例在经过验证的生成中无法正常工作。
