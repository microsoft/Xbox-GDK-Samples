# AmbientOcclusion のサンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

このサンプルでは、MiniEngine の Screen Space Ambient Occlusion (SSAO) と Intel の Ground Truth Ambient Occlusion (GTAO) という 2 つのアンビエント オクルージョン手法を示します。 このサンプルでは、品質をわずかに犠牲にしてパフォーマンスを向上できる一部のシェーダーの FP16 バージョンも示しています。

# サンプルのビルド

Xbox One 開発キットを使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.XboxOne.x64` に設定します。

Xbox Series X|S を使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.Scarlett.x64` に設定します。

*詳細については、* *GDK ドキュメント*の「__サンプルの実行__」を参照してください。

# サンプルの使用方法

左右のサムスティックを使用して、シーン内でカメラを動かすことができます。 上下の方向パッド ボタンで、使用するオプションを選択します。 左右の方向パッド ボタンで、オプションの値を変更します。 A ボタンで、AO テクスチャとシーンの間で表示を変更します。 B ボタンで、SSAO と GTAO を切り替えます。 Y ボタンで、シーン レンダリングの AO をオンもしくはオフします。 X ボタンで、FP16 シェーダーと FP32 シェーダーを切り替えます (Scarlett のみ)。

| カメラを回転させる | 右サムスティック |

# 実装メモ

このサンプルでは、アンビエント オクルージョンをレンダリングする方法を 2 つ示します。

1. Screen Space Ambient Occlusion (SSAO): SSAO は [MiniEngine](https://github.com/microsoft/DirectX-Graphics-Samples/tree/master/MiniEngine) から実装されています。 この機能では、圧縮された深度バッファーから HTile を使用して直接読み取りを実行し、ダウンサンプリングされたバージョンを作成します。 その後、深度テクスチャをサンプリングし、AO テクスチャを複数の解像度で作成します。 最終パスでは、AO テクスチャから読み取りを実行し、アップサンプリングとぼかしを処理します。

2. Ground Truth Ambient Occlusion (GTAO): GTAO は [Intel](https://github.com/GameTechDev/XeGTAO/tree/master) から実装されています。 この機能は、まず深度バッファーをダウンサンプリングしてミップ チェーンを作成します。 エンジンがまだ法線をエクスポートしていない場合は、深度バッファーから法線を生成するパスを実行します。 その後、深度バッファーからサンプリングするためにメイン パスを実行し、初期 AO テクスチャとエッジ テクスチャを生成します。 最終のパスで、AO テクスチャからノイズを除去します。

どちらのメソッドも、FP32 バージョンと比較してパフォーマンスを向上させるパス用として、 Scarlett の FP16 シェーダーをサポートしています。 通常、FP16 でのパフォーマンスの向上は、占有率を (2 つの値を 1 つのレジスタにパックしたことにより) 向上させたこと、または、少ない (パックされた算術命令の使用による) VALU 演算との組み合わせによって実現しています。
