#   多重采样示例

此示例与 Microsoft 游戏开发工具包预览版（2019 年 11 月）兼容

# 说明

此示例呈现受锯齿影响的几何图形，它允许用户观察该几何图形上所有支持的
MSAA 模式的效果。 一个可调节的缩放矩形将显示一小块屏幕区域的近视图。
提供四种缩放模式：

1.  已解析。 使用点采样将像素绘制成其解析颜色。

2.  最接近的示例。 像素被细分为表示每个示例的影响区域的形状。

3.  单个示例。 使用点采样将像素绘制为所选示例的颜色。

4.  所有示例。 将像素绘制为所有示例值的矩形数组。

选中 MSAA 呈现目标后，PIX 管道视图中也提供类似的可视化效果。

## EQAA

必须采用"质量"设置为 0 的多重采样模式才能使用 Direct3D
标准示例位置，并在所有图形卡上以一致的方式运行。 "质量"设置大于 0
的多重采样模式是特定于硬件的。
它们可以使用非标准示例位置，并且它们可以使用其他计算和/或隐藏的其他示例。
例如，在示例计数为 2，质量设置为 0 的情况下，任何 Direct3D 12 级 GPU
仅沿着两个单色区域之间的一个边缘呈现一个中间色。 但在示例计数为
2，质量设置为 4 的情况下，Xbox One GPU 呈现三种中间色。
在这种情况下，两个单独的示例颜色并不能完全代表硬件用于计算最终像素颜色的信息。

术语 EQAA（增强的质量抗锯齿）指的是 AMD 专有的 MSAA"质量"级别大于 0
的实现。 XFest 2012 演示文稿《[Xbox One 上的颜色压缩和多重采样》描述了
EQAA 的一些详细信息。 对于给定的内存占用，EQAA 表面的质量高于标准 MSAA
表面，但性能的成本也略高。](https://developer.xboxlive.com/en-us/platform/documentlibrary/events/Pages/Xfest2012.aspx)

EQAA 的 Xbox One 实现在以下方面不符合标准 Direct3D：

1.  不支持 ResolveSubresource。 标题必须手动解析一个 EQAA 表面。

2.  不支持通过 D3D12_SRV_DIMENSION_TEXTURE2DMS 类型的视图进行采样。
    标题必须手动解码一个 EQAA 表面。

该示例演示了如何解码和解析 EQAA 表面。
这两个任务都利用辅助的"FMask"表面，它是与压缩后的颜色目标相关联的元数据的一部分。
借助 Xbox One Direct3D，标题可以通过请求内置的非标准
D3D12XBOX_DATA_FORMAT_FMASK\* 格式之一来生成 FMask
表面的着色器资源视图。

"最接近的示例"可视化将区分 API 可见示例（较大的白点）与"额外"EQAA
示例（较小的黑点）。 EQAA
示例可以是"未知的"（意味着它们没有相关的颜色），此类示例标记有交叉影线图案。

# 构建示例

如果使用 Xbox One 开发工具包，请将活动解决方案平台设置为
Gaming.Xbox.XboxOne.x64。

如果使用 Project Scarlett，请将活动解决方案平台设置为
Gaming.Xbox.Scarlett.x64。

有关详细信息，请参阅 GDK 文档中的"运行示例"。

# 使用示例

## 控件

| 操作                                          |  游戏手柄             |
|-----------------------------------------------|----------------------|
| 更改呈现的场景                                |  LB/RB 按钮           |
| 更改 MSAA 示例计数                            |  向左/向右方向键      |

| 重置缩放、相机和光线                          |  R3 按钮              |
| 在手动解析着色器之间循环                      |  L3 按钮              |
