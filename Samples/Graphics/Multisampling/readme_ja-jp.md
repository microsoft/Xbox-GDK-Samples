#   マルチサンプリングのサンプル

*このサンプルは、Microsoft ゲーム開発キットのプレビュー (2019 年 11 月)
に対応しています。*

# 説明

このサンプルでは、エイリアスの対象となるジオメトリをレンダリングします。これにより、ユーザーは、そのジオメトリでサポートされているすべての
MSAA モードの効果を確認できます。 調整可能な四角形のズーム
ツールには、画面の小さな領域の拡大ビューが表示されます。 4 つのズーム
モードがあります。

1.  補正済み。 ピクセルは、ポイント
    サンプリングを使用して、補正済みの色として描画されます。

2.  最も近いサンプル。
    ピクセルは、各サンプルの影響範囲を示す図形に分割されます。

3.  1 つのサンプル。 ピクセルは選択されたサンプルの色として、ポイント
    サンプリングを使用して描画されます。

4.  すべてのサンプル。
    ピクセルは、すべてのサンプル値の四角形配列として描画されます。

同様の視覚エフェクトは、MSAA のレンダリング
ターゲットが選択されている場合、PIX パイプライン
ビューでも使用できます。

## EQAA

Direct3D 標準サンプルの場所を使用し、すべてのグラフィック
カードで一貫した方法で動作させるには、「品質」 設定が 0
のマルチサンプリング モードが必要です。 「品質」設定が 0
より大きいマルチサンプリング モードは、ハードウェア固有です。
標準以外のサンプルの場所を使うことができ、追加の計算や、非表示の追加サンプルを使用できます。
たとえば、サンプル数が 2 で、品質が 0 に設定されている場合、Direct3D 12
クラス GPU は、2 つの単色の領域間のエッジに沿って 1
つの中間色のみをレンダリングします。 ただし、サンプル数が 2 で、品質が 4
に設定されている場合、Xbox One GPU は 3 つの中間色をレンダリングします。
この例では、2 つの個別のサンプル
カラーは、ハードウェアが最終的なピクセル
カラーの計算に使用する情報を完全にはレンダリングしていません。

EQAA (Enhanced Quality Anti-Aliasing) という用語は、 MSAA
の「品質」レベルが 0 より大きい AMD 固有の実装を意味します。 XFest 2012
のプレゼンテーション「[Xbox One
のカラー圧縮およびマルチサンプリング](https://developer.xboxlive.com/en-us/platform/documentlibrary/events/Pages/Xfest2012.aspx)」に
EQAA の詳細がいくつか記載されています。 EQAA
サーフェスは、所定のメモリー フットプリントに対して、標準的な MSAA
の表面よりも品質に優れていますが、パフォーマンスの負荷がやや大きくなります。

Xbox One の EQAA 実装は、次の理由から、標準の Direct3D
に対応していません。

1.  ResolveSubresource がサポートされていない。 タイトルは手動で EQAA
    サーフェスを補正する必要がある。

2.  タイプ D3D12_SRV_DIMENSION_TEXTURE2DMS
    のビューによるサンプリングはサポートされていない。 タイトルは手動で
    EQAA サーフェスをデコードする必要がある。

このサンプルでは、EQAA
のサーフェスをデコードおよび補正する方法を示します。 これらの 2
つの作業では、補助「FMask」サーフェスを使用します。これは、圧縮された色のターゲットに関連付けられているメタ
データの一部です。 Xbox One Direct3D は、組み込みの非標準
D3D12XBOX_DATA_FORMAT_FMASK \* 形式のいずれかを要求することで、FMask
サーフェスのシェーダー リソース ビューを作成することができます。

「最も近いサンプル」の視覚エフェクトは、API が表示されているサンプル
(大きい白色のドット) と「余分の」EQAA サンプル (小さな黒いドット)
を区別します。 EQAA サンプルは、「不明」
(つまり、関連付けられた色がない)
の場合があり、そうしたサンプルには格子パターンが表示されます。

# サンプルの作成

Xbox One の devkit を使用している場合は、アクティブなソリューション
プラットフォームを Gaming.Xbox.XboxOne.x64 に設定します。

Project Scarlett を使用している場合は、アクティブなソリューション
プラットフォームを Gaming.Xbox.Scarlett.x64 に設定します。

*詳細については、GDK ドキュメントの*
「サンプルの実行」*を参照してください。*

# サンプルの使用

## コントロール​​

| 動作                                          |  ゲームパッド         |
|-----------------------------------------------|----------------------|
| レンダリングするシーンを変更する              |  LB/RB ボタン         |
| MSAA のサンプル数を変更する                   |  方向パッドの左/右    |
| MSAA の品質を変更する                         |  方向パッドの上/下    |
| 視覚エフェクト モードを循環する (四角形の埋め込み) |  A ボタン |
| 選択したサンプルを循環する (1 つのサンプル ビジュアライザーの場合) |  B ボタン |
| 選択されているライトを変更する                |  X ボタン             |
| 右スティックの機能を変更する                  |  Y ボタン             |
| ズーム、カメラ、またはライトを調整する        |  右スティック         |
| ズーム、カメラ、ライトをリセットする          |  R3 ボタン            |
| 手動の補正シェーダー間を循環する              |  L3 ボタン            |

# プライバシーに関する声明

サンプルをコンパイルして実行すると、サンプルの使用状況を追跡するため、サンプル実行可能ファイルのファイル名が
Microsoft に送信されます。このデータ収集を無効にするには、「Sample Usage
Telemetry」とラベル付けされた Main.cpp
内のコードのブロックを削除します。

Microsoft のプライバシー方針の詳細については、「[Microsoft プライバシー
ステートメント](https://privacy.microsoft.com/en-us/privacystatement/)」を参照してください。
