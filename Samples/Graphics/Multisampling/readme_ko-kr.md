#   Multisampling 샘플

*이 샘플은 Microsoft 게임 개발 키트 미리 보기(2019년 11월)와
호환됩니다.*

# 설명

이 샘플은 앨리어싱될 수 있는 기하 도형을 렌더링하며 지원되는 모든 MSAA
모드가 해당 기하 도형에 미치는 영향을 사용자가 관찰할 수 있도록 합니다.
조정 가능한 확대/축소 직사각형에는 화면의 작은 영역이 자세히 표시됩니다.
다음과 같은 4가지 확대/축소 모드가 있습니다.

1.  확인됨. 점 샘플링을 사용하여 픽셀을 확인된 색으로 그립니다.

2.  가장 가까운 샘플. 픽셀을 각 샘플의 영향 영역을 나타내는 도형으로
    세분화됩니다.

3.  단일 샘플. 점 샘플링을 사용하여 픽셀을 선택한 샘플의 색으로
    그립니다.

4.  모든 샘플. 픽셀을 모든 샘플 값의 사각형 배열로 그립니다.

MSAA 렌더 대상이 선택된 경우에도 PIX 파이프라인 보기에서 유사한 시각화를
사용할 수 있습니다.

## EQAA

Direct3D 표준 샘플 위치를 사용하고 모든 그래픽 카드에서 일관된 방식으로
작동하려면 다중 샘플링 모드의 \'품질\'을 0으로 설정해야 합니다. \'품질\'
설정이 0보다 큰 다중 샘플링 모드는 하드웨어와 관련이 있습니다. 이러한
모드는 비표준 샘플 위치를 사용하고 추가 계산 및/또는 숨겨진 추가 샘플을
사용할 수 있습니다. 예를 들어, 샘플 수가 2이고 품질 설정 0인 경우 모든
Direct3D 12 클래스 GPU는 두 개의 단색 영역 사이의 가장자리를 따라 1개의
중간 색만 렌더링합니다. 그렇지만 샘플 수가 2이고 품질 설정이 4인 경우
Xbox One GPU는 3개의 중간 색상을 렌더링합니다. 이 경우 2개의 개별 샘플
색상이 하드웨어에서 마지막 픽셀 색상을 계산하는 데 사용하는 정보를
완전히 나타내지는 않습니다.

EQAA(고급 품질 앤티앨리어싱)는 MSAA \"품질\" 수준이 0보다 큰 독자적인
AMD 구현을 나타냅니다. XFest 2012 프레젠테이션 [Color Compression and
Multisampling on Xbox
One](https://developer.xboxlive.com/en-us/platform/documentlibrary/events/Pages/Xfest2012.aspx)에서는
EQAA의 몇 가지 세부 사항을 설명합니다. EQAA 표면은 지정된 메모리 공간에
대해 표준 MSAA 표면보다 더 높은 품질을 나타낼 뿐만 아니라 가격도 약간 더
저렴합니다.

EQAA의 Xbox One 구현은 다음과 같은 방식으로 표준 Direct3D와 호환되지
않습니다.

1.  ResolveSubresource가 지원되지 않습니다. 타이틀은 EQAA 표면을
    수동으로 확인해야 합니다.

2.  D3D12_SRV_DIMENSION_TEXTURE2DMS 유형 보기를 통한 샘플링은 지원되지
    않습니다. 타이틀은 EQAA 표면을 수동으로 디코딩해야 합니다.

이 샘플에서는 EQAA 표면을 디코딩하고 확인하는 방법을 보여 줍니다. 이러한
작업은 모두 압축된 색상 대상에 연결된 메타데이터의 일부인 보조 \"FMask\"
표면을 활용합니다. Xbox One Direct3D를 사용하면 타이틀은 기본 제공된
비표준 D3D12XBOX_DATA_FORMAT_FMASK\* 형식 중 하나를 요청하여 FMask
표면에 대한 셰이더 리소스 보기를 빌드할 수 있습니다.

\"가장 가까운 샘플\" 시각화는 API에 표시되는 샘플(좀 더 큰 흰색 점)과
\"추가\" EQAA 샘플(좀 더 작은 검은색 점) 간을 구분합니다. EQAA 샘플은
\"알 수 없음\"(연결된 색상 없음)일 수 있으며, 이러한 샘플은 크로스해치
패턴으로 표시됩니다.

# 샘플 빌드

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을
Gaming.Xbox.XboxOne.x64로 설정하세요.

Project Scarlett을 사용하는 경우 활성 솔루션 플랫폼을
Gaming.Xbox.Scarlett.x64로 설정하세요.

*자세한 내용은 GDK 문서에서* 샘플 실행하기*를 참조하세요.*

# 샘플 사용

## 컨트롤

| 작업                                          |  게임패드             |
|-----------------------------------------------|----------------------|
| 렌더링할 장면 변경                            |  LB/RB 단추           |
| MSAA 샘플 개수 변경                           |  D-패드 L/R           |
| MSAA 품질 변경                                |  D-패드 U/D           |
| 시각화 모드 순환(직사각형 inset)              |  A 단추               |
| 선택한 샘플 순환(단일 샘플 시각화 도우미용)   |  B 단추               |
| 선택된 라이트 변경                            |  X 단추               |
| 오른쪽 스틱 기능 변경                         |  Y 단추               |
| 확대/축소, 카메라 또는 라이트 조정            |  오른쪽 스틱          |
| 확대/축소, 카메라 및 라이트 재설정            |  R3 단추              |
| 수동 확인 셰이더 순환                         |  L3 단추              |
