# PrimeHTile Sample

*이 샘플은 Microsoft 게임 개발 키트(2022년 3월)와 호환됩니다.*

# 설명

이 샘플은 HTile의 HiZ 부분을 농도 값으로 프라이밍하여 후속 렌더링에서 농도 테스트 사전 픽셀 셰이딩에 실패하도록 하는 방법을 보여줍니다. 특히 오클루전 컬링을 위한 CPU 래스터화 심도 버퍼가 이미 있는 타이틀에서 동일한 데이터를 사용하여 GPU 속도를 높이는 것과 관련이 있습니다. 이 기능은 g-버퍼 레이다운 시 오버드로를 줄이는 데 유용할 수 있지만, 특히 픽셀 오버드로에 대해 더 큰 페널티를 받는 Forward+를 사용하는 타이틀에 유용할 수 있습니다.

이 샘플에서는 CPU 래스터화 깊이를 사용하는 대신 GPU를 사용하여 HTile 해상도로 깊이를 렌더링하고 계속 GPU 시간의 전체적인 절약을 확보합니다.

이 샘플은 큐브의 프랙탈을 렌더링하여 사용자가 픽셀 셰이더 제한과 꼭짓점 셰이더 제한 사이에서 로드를 변경할 수 있도록 합니다. 또한 시차 매핑을 구현하고 사용자가 이 매핑과 범프 매핑을 전환하여 픽셀 셰이딩 비용의 효과를 표시할 수 있습니다.

# 구현 참고 사항

HTile은 8x8 타일당 최소 및 최대 심도를 저장합니다. 사전 픽셀 셰이더 심도 컬링이 활성화되면 각 삼각형은 HTile의 해상도로 거칠게 래스터화됩니다. 원거리 심도를 벗어난 조각은 컬링되고, 근거리 심도보다 가까운 조각은 약간만 허용되며, HTile의 근거리와 원거리 심도 사이의 범위에 있는 조각은 전체 해상도 심도 테스트를 거쳐야 합니다.

이 샘플은 GPU를 사용하여 HTile의 해상도(전체 해상도의 \~1/8)로 오클루전 버퍼를 렌더링하고 이러한 심도를 HTile에 기록합니다. 심도 버퍼와 HTile 스위즐링이 다르기 때문에 HTile 초기화 셰이더에 의해 소프트웨어에서 스위즐링이 수행됩니다. HTile 초기화는 CPU에서 수행할 수 있지만 일반적으로 HTile은 ESRAM에 있어야 하므로 복사 작업이 여전히 필요합니다.

이 기술은 기존 심도 사전 패스와 결합할 수 있습니다. 예:

1. 바인딩 HTile 해상도 심도 버퍼

a.  렌더링 제한된 오클루더 채우기(예: 건물의 슬래브 측면)

2. 전체 해상도 심도 바인딩

a.  오클루전 버퍼를 사용하는 주요 HTile

b.  꼭짓점 제한 오클루더 렌더링(예: 플레이어의 자동차)

미리 생성된 심도 버퍼, 소프트웨어 또는 하드웨어 래스터화된 심도 버퍼는 단일 심도 값만 가지며 범위를 생성하지 않습니다. 따라서 유일한 합리적인 옵션은 HTile의 근거리 및 원거리 심도를 모두 같은 값으로 설정하는 것입니다. 그러나 이 값이 반드시 나중에 렌더링될 도형을 올바르게 나타내는 것은 아닙니다. 이 문제는 샘플링이 부족하면 픽셀이 잘못 거부되는 섀도 아크네와 다소 유사합니다. 샘플은 이 문제를 해결하는 세 가지 방법을 보여 주며, 각 방법은 함께 사용될 수 있습니다:

1. 심도 인코딩에 정수 바이어스 추가

2. 오클루전 기하 도형을 축소하여 비정상으로 만들기

3. HTile 인코딩 중에 최대 3x3 심도 값을 사용합니다. (매우 효과적임)

이러한 방법 중 어느 것도 자체적으로 완벽한 해결책을 제공하지는 않지만 만족스러운 결과를 찾을 수 있습니다. 각 방법마다 성능의 장단점이 있습니다.

HTile 프라이밍은 GPU가 심도 압축을 사용하지 못하게 하지만, 오버드로의 감소는 이러한 손실을 상쇄할 수 있습니다. 참고로, HTile이 프라이밍된 심도 버퍼는 지울 필요가 없으며, 무료로 제공됩니다.

타이틀에서 그래픽 엔진이나 CPU를 사용하여 오클루딩 심도 버퍼를 렌더링하는 대신 비동기식 컴퓨팅을 사용할 수 있습니다. <https://github.com/jbarczak/CSRasterization>을(를) 참조하세요.

이 샘플은 DirectX 12.X 사용을 통해 구현되었습니다. 루트 서명을 제거하는 경우 DirectX 11.X 구현에 동일한 셰이더(PrimeHTileCS.hlsl)를 사용할 수 있습니다.

# 업데이트 기록

샘플의 원래 버전은 XSF 기반 프레임워크를 사용하여 작성되었습니다. DirectX 12를 사용하는 Xbox One X 지원하여 2018년 3월에 ATG 샘플 템플릿을 사용하도록 다시 작성되었습니다.
