# 単純な VRS サンプル

*\* このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

このサンプルの目的は、[階層 2 の画面空間可変レート シェーディング](https://docs.microsoft.com/en-us/windows/win32/direct3d12/vrs#tier-2) (VRS) を使用して、数行のコードで高価なピクセル シェーダーのコストを最小限に抑える方法を簡潔に示すことです。

可変レート シェーディング (VRS) では、ピクセルの最終的な値を近隣の一部 (VRS D3D12 API で指定されたインフルエント領域) にブロードキャストすることで、ピクセル シェーダー呼び出しの合計数を減らします。 これは、均一に網掛けに表示されるシーンや、ピクセル単位の詳細がはるかに少ないシーンの領域に最適です。

このサンプルでは、従来のシンプルな三角形が、移動と半透明のクラウドの壁の背後に導入され、VRS シェーディング レートによって重いピクセル シェーダーワークロードを削減する方法を示すために、人為的に高価なピクセル シェーダーでレンダリングされます。&nbsp;半透明のクラウド ピクセルによって部分的に隠れている三角形のピクセルは、可視性が低下するため、粗い速度でシェーディングされます。&nbsp;パフォーマンスの節約は、生成されたシェーディング レート イメージとレンダリングされたシーンの平均経過時間の測定を使用して強調表示されます。 視覚エフェクト モードは、シーン内でのシェーディング レートの割り当てを示すためにも存在します。

# 実装メモ

この簡単なサンプルの主な目的は、ユーザーが階層 2 VRS を有効にすることに慣れ、VRS 固有のパフォーマンス上の利点に焦点を当てることです。 サンプルの残りの部分では、実装を簡略化するために、潜在的な簡略化と最適化が省略されています。

**SimpleVRS のレンダー パスの概要**

次の手順は、このサンプルの各フレームのレンダリングの概要と貢献を示しています。

1. すべてのレンダー ターゲットをクリアします。

2. 以前に設定した VRS 状態を無効にし、クラウド スプライトのアルファ値を小さなバッファーにレンダリングします。

3. 類似するアルファ値のグループ化に基づいてシェーディング レート イメージを設定し、新しいシェーディング レート マップで VRS を有効にします。

4. 不透明なクラウド スプライトと三角形を、人為的に高価なピクセル シェーダーでレンダリングします。

**重要な VRS API コンポーネントと関数**

サンプルの AllocateShadingRateImage 関数に示されているように、シェーディング レート イメージ GPU リソースは、**D3D12_RESOURCE_STATE_SHADING_RATE_SOURCE** リソース状態で初期化され、計算シェーダーによってシェーディング レート値が設定されます。 [Direct3D 12 VRS](https://microsoft.github.io/DirectX-Specs/d3d/VariableRateShading.html) の仕様で 指定されているように、**DXGI_FORMAT_R8_UINT** イメージ形式で 作成する必要があります。 Scarlett では、タイル サイズは 8x8 です。 つまり、シェーディング レート イメージ内の各シェーディング レート値は、完全解像度フレームバッファーの 64 ピクセルの正方形にマップされます。 画面を完全に覆うために、シェーディング レートイメージの寸法はフレームバッファーの 1/64^^ です。

Render 関数 (VRS.cpp) では、VRS は **RSSetShadingRate** を介して**D3D12_SHADING_RATE_1X1** シェーディング レートを設定することで無効になり、シェーディング レート イメージを完全な解像度で計算およびレンダリングできます。 計算シェーダーがシェーディング レート イメージに適切な値を入力した後、**RSSetShadingRate** と **RSSetShadingRateImage** を使用してシェーディング レート イメージが設定されます。

**シーン レンダリング**

トライアングルとフル解像度のクラウド スプライトがフレームバッファーにレンダリングされる前に、クラウド スプライトのアルファ値は、VRS の画面空間イメージを設定するために計算シェーダーによって処理される小さなオフスクリーン レンダー ターゲットにレンダリングされます。

さらに、ExpensiveShaderFunction (PixelShader.hlsl) が追加され、粗い VRS シェーディング レートを使用することでパフォーマンス上の利点を示すのに十分なコストがかかるシーン トライアングルのピクセル シェーダーが作成されました。

**VRS 画面空間イメージの決定**

シェーディング レートは、ピクセルあたりの水平方向および垂直方向のアルファ グラデーションと、ピクセルがクラウドのアウトラインの一部であるかどうかを判断するための完全に透明なピクセルの存在に基づいて選択されます。 垂直エッジの一部であるピクセルは **D3D12_SHADING_RATE_1X2** シェーディング レートで指定され、水平方向のエッジに属するピクセルは **D3D12_SHADING_RATE_2X1** で割り当てられます。 それ以外の場合、**D3D12_SHADING_RATE_2X2** は、水平方向と垂直方向の交差部分のピクセル数をカウントするために既定で割り当てられます。 クラウドのアウトラインの場合、中心ピクセルは、透明な背景からクラウドを分離する垂直または水平のエッジがあることを意味する可能性がある透明ピクセルに対してさらにチェックされます。 完全に透明なピクセルは、常にフル レート (**D3D12_SHADING_RATE_1X1**) で割り当てられます。 このシェーディング レート計算の例を図 1 に示します。
