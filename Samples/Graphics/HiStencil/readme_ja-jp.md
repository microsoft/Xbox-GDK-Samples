# 高ステンシル サンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

D3D12.X では、高ステンシルが既定でオフになっています。 ただし、タイトルでは、高ステンシルを構成できるというのが朗報です。 タイトルによって設定できる高ステンシル比較状態は 2 つあります。 サンプル レートではなく、タイル レートでステンシル操作を実行できるため、パフォーマンスが向上します。 ステンシル テストを使用するタイトルでは、高ステンシルを手動で設定することによってパフォーマンスが向上する可能性があります。 このサンプルでは、高ステンシル API の使用方法を示します。

このサンプルでは、計算シェーダーを使用して HTile バッファーから高ステンシルの結果を読み取る方法も示します。 この方法では、非同期コンピューティングを使用してステンシル パスを実行できるため、全体的なパフォーマンスが向上する可能性があります。

# 実装に関するメモ

D3D12.X では、高ステンシルが既定でオフになっています。 タイトルによって設定できる高ステンシル比較状態は 2 つあります (State0 と State1)。

```cpp
typedef struct D3D12XBOX_HISTENCIL_COMPARE_STATE
{
    D3D12XBOX_HISTENCIL_COMPARE_FUNCTION CompareFunction : 4;
    UINT CompareValue : 8;
    UINT CompareMask : 12;
    BOOL Enabled : 8;
} D3D12XBOX_HISTENCIL_COMPARE_STATE;

typedef struct D3D12XBOX_HISTENCIL_CONTROL
{
    D3D12XBOX_HISTENCIL_COMPARE_STATE State0;
    D3D12XBOX_HISTENCIL_COMPARE_STATE State1;
} D3D12XBOX_HISTENCIL_CONTROL;
```


これらの高ステンシル比較状態を設定できるように、SetHiStencilStateX API と SetHiStencilControlX API が D3D12.X に追加されています。

- **SetHiStencilStateX** は、深度ステンシル リソースに対する高ステンシル比較テストを設定するために使用され、バインドされると特定のリソースで保持されます。

- **SetHiStencilControlX** は、一時的に状態をグローバルに設定するために使用され、関連付けられた高ステンシル状態を持つ深度ステンシルがパイプラインにバインドされるまで、あらゆるステンシル リソースに使用されます。

```cpp
void D3DAPI SetHiStencilStateX(
    _In_ ID3D12Resource* pResource,
    _In_opt_ const D3D12XBOX_HISTENCIL_CONTROL* pControl);

void D3DAPI SetHiStencilControlX(
    _In_opt_ const D3D12XBOX_HISTENCIL_CONTROL* pControl);
```


比較の結果は HTile バッファーに格納されます。 フレーム内の後のステンシル テストに関連付けられている場合、これらのテストは、個々のサンプルのステンシル値を読み取る代わりに、タイルを拒否する、または受け入れる効果的な方法になる可能性があります。

## HTile バッファー:

HTile バッファーには、深度ステンシル バッファーのピクセルの 8 x 8 ブロックごとに 32 ビットのメタデータが格納されます。

次の場合の HTile ビットの解釈

- ステンシルが存在しない場合 (このサンプルでは扱っていません)

![](./media/image5.png)

- ステンシルが存在する場合

![](./media/image6.png)

- **SMem**: ステンシルのメモリ形式は、タイル内のステンシル値の格納方法を示す 2 ビット値です

| SMem | 説明 |
|---|---|
| 0 | **クリア** -- タイル全体がクリア値を持ちます。 |
| 1 | **単一値** **--** タイル全体が単一のステンシル値を持ちます。 ステンシル バッファー タイルの最初の 8 ビットのデータがタイル全体の値になります |
| 2 | **展開およびクリア** -- 現在 XBox では使用されていません。 ステンシル バッファー内のこのタイルのすべてのサンプルがクリア値を持ちます。 |
| 3 | **展開済み** -- タイルが展開されているため、ステンシル バッファー内の個々のサンプルが正しいステンシル値を持ちます |

- **SR\***: 階層型ステンシルの事前テスト結果。 HTile に格納できる 2 つの独立した比較結果 (SR0 と SR1) があります。 SetHiStencilStateX API と SetHiStencilControlX API を使用して、比較関数、マスク、比較値を設定できます。 SR0 と SR1 には、それぞれ 2 ビットがあります。

   - **ビット 0**: May Fail

   - **ビット 1**: May Pass

> これら 2 ビットによって設定される値の解釈:

| SR\* | 説明 |
|---|---|
| 0 | **クリアされている、または比較されていない** |
| 1 | **May Fail** -- 少なくとも 1 つのサンプルが高ステンシル テストに失敗しています |
| 2 | **May Pass** -- 少なくとも 1 つのサンプルが高ステンシル テストに合格しています |
| 3 | **May Pass または May Fail** - 少なくとも 1 つのサンプルが高ステンシル テストに合格しており、少なくとも 1 つのサンプルが高ステンシル テストに失敗しています。 高ステンシル状態テストがオフになっている場合、またはステンシル パスが ALWAYS あるいは NEVER である場合、または比較マスクが 0 の場合、または処理中のステンシル書き込みがある場合も、ハードウェアはこれら両方のビットを設定することができます。 したがって、そのような場合は、タイルの SR\* の値が 3 であっても、すべてのサンプルが失敗する可能性があります。 |

- **サンプルの高ステンシル状態**

このサンプルでは、SetHiStencilStateX を使用して、ステンシル値 COMPARE_VALUE と (COMPARE_VALUE +1) で描画された 2 個のディスクのテストに合格しています。

```cpp
hiStencilControl.State0.Enabled = TRUE;
hiStencilControl.State0.CompareFunction = D3D12XBOX_HISTENCIL_COMPARE_FUNCTION_LEQUAL;
hiStencilControl.State0.CompareValue = COMPARE_VALUE;
hiStencilControl.State0.CompareMask = 0xFF;
```


SetHiStencilControlX を使用する場合は、ステンシル値 (COMPARE_VALUE_2 + 1) で描画された別のディスクが高ステンシル テストに合格するように、2 番目の比較状態を設定します。

```cpp
hiStencilControl.State1.Enabled = TRUE;
hiStencilControl.State1.CompareFunction = D3D12XBOX_HISTENCIL_COMPARE_FUNCTION_LEQUAL;
hiStencilControl.State1.CompareValue = COMPARE_VALUE_2 + 1;
hiStencilControl.State1.CompareMask = 0xFF;
```

## 計算シェーダー:

HTile バッファーを使用して高ステンシルの事前テストの結果を読み取ることができるため、これらを使用してステンシル テストを計算シェーダーで実装できます。 この方式は通常のピクセル シェーダーの実装よりも遅くなる傾向がありますが、非同期コンピューティングで実行できるため、グラフィックス パイプの時間を短縮できるという利点があります。 このサンプルでは、次の 2 つの計算シェーダーが使用されています。

- **HTile 値の解釈:** このシェーダーは、追加バッファーを使用して、SR\* の "MayPass" ビットが設定されているタイルの座標を格納します。 デバッグ目的で、このシェーダーは "MayFail" ビットが設定されたタイルの数と、単一値 (SMem =1) を持つ May Pass タイルの数をカウントすることもできます。

- **展開されたステンシルの結果の決定:** 2 番目の計算シェーダーは、上記の追加バッファーの値を使用して、ステンシル テストに合格したサンプルを決定し、緑色または青色をターゲットとブレンドします。 このシェーダーは、単一のステンシル値 (SMem = 1) を持つタイルには SGPR を使用し (緑色で出力をブレンド) 、タイルが展開されている場合は各スレッドがステンシル バッファーから個別の値を読み取る必要があるため、VGPR を使用します (青色で出力をブレンド)。

# 結果:

**ピクセル シェーダーを使用してステンシル テストに合格したときのピクセルの書き込み結果:**

| カウンター | Scorpio -- 4K | Durango -- 1080p |
|---|---|---|---|---|
|  | 高ステンシル オフ | 高ステンシル オン | 高ステンシル オフ | 高ステンシル オン |
| EOP 間の間隔 | 0.089 ミリ秒 | 0.062 ミリ秒 | 0.072 ミリ秒 | 0.055 ミリ秒 |
| 拒否された Hi-Z タイルの割合 | 0 | 40% | 0 | 39.8% |
| PreZSamplesPassing (サンプル レートで実行されているステンシル テスト) | 1,235,187 | 23,187 | 308,857 | 12,025 |
| DB_PERF_SEL_DB_SC_S\_TILE_RATE (Scorpio) または DB_PERF_SEL_DB_SC_TILE_TILE_RATE (Durango) (タイル レートで実行されているステンシル テスト) | 0 | 18,939 | 0 | 4,638 |
| タイル レートで実行されている合格サンプルの割合 | 0 | 98.12% | 0 | 96.16% |

高ステンシルを使用すると、Scorpio は **30%** のゲインを示し、Durango は **23%** のゲインを示します。

**ステンシル テストに合格した場合のピクセルへの書き込み:**

| カウンター | Scorpio -- 4K | Durango -- 1080p |
|---|---|---|---|---|
|  | PS | CS | PS | CS |
| ステンシル テストに合格したサンプルの書き込み | 1,235,187 | 308,857 |
| 所要時間 (DRAM 内の DSV+RTV) | 0.062 ミリ秒 | 0.088 ミリ秒 | 0.055 ミリ秒 | 0.103 ミリ秒 |
| 所要時間 (ESRAM 内の DSV+RTV) | \- | \- | 0.027 ミリ秒 | 0.044 ミリ秒 |

ターゲットが ESRAM 内にある場合は、描画呼び出しがピクセル レートによって制限される可能性があるため、計算シェーダーにかかる時間がピクセル シェーダーのタイミングに近づく可能性があります。 ターゲットが DRAM 内にある場合、呼び出しは DRAM の帯域幅によって制限されます。 前述したように、計算シェーダーは実行に時間がかかりますが、非同期で実行することで全体のフレーム時間を短縮できます。
