PlayFabMultiplayerRumble 示例

*此示例兼容于 Microsoft 游戏开发工具包（2022 年 6 月）*

# 说明

此示例演示使用 PlayFab 多人游戏和 PlayFab Party API 构建完整的端到端游戏体验的多人游戏功能。

此示例为以下多人游戏方案提供选项。

- **创建可加入的游戏大厅**

> 创建一个游戏大厅，通过平台 UI 播发为
> 可加入。

- **邀请好友和群成员加入大厅**

> 打开系统 UI 以邀请好友加入大厅。 使用自定义
> 邀请字符串。
>
> 向群成员发送邀请。

- **加入好友正在进行的会话**

> 列举和显示好友正在玩的游戏大厅并直接加入
> 其中。 也可以从 Xbox 主机上的 shell 加入，或者
> 通过好友的玩家卡或活动源从 Windows 上的 Xbox 应用
> 加入，或者从群应用（如果群成员正在游戏会话中）加入。

- **匹配**

> 创建和提交匹配票证。 匹配成功时将返回
> 大厅连接字符串。

- **可用游戏**

> 在所有大厅成员之间发送和接收数据，
> 一次最多可了解 4 个玩家的状态和游戏场景。 在本例中，游戏
> 是一个不可思议的双摇杆射击游戏！

# 生成示例

如果使用 Project Scarlett，请将活动解决方案平台设置为 `Gaming.Xbox.Scarlett.x64`。

如果使用 Xbox One 开发工具包，请将活动解决方案平台设置为 `Gaming.Xbox.XboxOne.x64`。

如果使用 Windows 电脑，请将活动解决方案平台设置为 Gaming.Xbox.x64

*有关更多信息，请参阅*&nbsp;__运行示例__（位于 *GDK&nbsp;文档）中。*

# 使用示例

**Xbox Live 沙盒要求**

- Xbox One 开发工具包：将主机的沙盒设置为 XDKS.1

- Windows 10：使用默认零售沙盒或设置为 XDKS.1 以与 Xbox One 进行交叉游戏（有关如何在 Windows 中更改 Xbox Live 沙盒的说明，请参阅 Xbox One SDK 附带的文档）

- 注意：在 Windows 10 中使用 XDKS.1 时，需要使用在 XDP 中创建的开发人员帐户登录。 可以从游戏菜单或 Windows 上的 Xbox 应用登录到此帐户。

# 已知问题

- 仅当玩家当前正等待游戏在大厅屏幕上启动时才可以加入正在进行的游戏。
