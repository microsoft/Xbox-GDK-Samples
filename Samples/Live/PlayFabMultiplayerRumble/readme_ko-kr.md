PlayFabMultiplayerRumble 샘플

*이 샘플은 Microsoft 게임 개발 키트(2022년 6월)와 호환 가능합니다.*

# 설명

이 샘플은 종합적 게임 환경을 구축하는 PlayFab 멀티플레이어와 PlayFab 파티 API를 사용한 멀티플레이어 기능을 보여줍니다.

이 샘플에서는 다음 멀티 플레이어 시나리오에 대한 옵션을 제공합니다.

- **참여 가능한 로비 만들기**

> 플랫폼 UI를 통해 광고되는 로비를 만들어서
> 누구든지 참가할 수 있게 합니다.

- **로비에 친구 및 파티 구성원 초대**

> 시스템 UI를 열어 로비에 친구를 초대합니다. 사용자 지정
> 초대 문자열을 사용합니다.
>
> 파티 구성원에게 초대를 보냅니다.

- **진행 중인 친구의 세션에 참가**

> 친구가 플레이하는 로비를 열거 및 표시하여
> 직접 참여합니다. Xbox 콘솔의 셸에서 참여할 수도 있고
> 친구의 게이머 카드 또는 활동 피드를 통해 Windows의 Xbox 앱에서 참여하거나
> 파티 구성원이 게임 세션에 있는 경우 파티 앱을 통해서도 참여할 수 있습니다.

- **매치 메이킹**

> 매치 메이킹 티켓을 만들어 제출. 매치 메이킹은
> 성공 시에 로비 연결 문자열을 반환합니다.

- **적극적인 게임 플레이**

> 한 번에 최대 4인용 게임 시나리오와 상태에 관해
> 로비에 있는 모든 구성원들끼리 데이터를 주고받습니다. 이 사례에서의 게임플레이는
> 멋진 트윈 스틱 슈터입니다.

# 샘플 빌드

Project Scarlett을 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.Scarlett.x64`(으)로 설정합니다.

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을 `Gaming.Xbox.XboxOne.x64`(으)로 설정합니다.

Windows PC를 사용하는 경우 활성 솔루션 플랫폼을 Gaming.Xbox.x64로 설정합니다.

*GDK 설명서의* __샘플 실행__에서 *자세한 내용을 알아보세요.*

# 샘플 사용

**Xbox Live 샌드박스 요구 사항**

- Xbox One 개발 키트: 콘솔의 샌드박스를 XDKS.1로 설정

- Windows 10: Xbox One과 교차 플레이하려면 기본 리테일 샌드박스를 사용하거나 XDKS.1로 설정(Windows에서 Xbox Live 샌드박스를 변경하는 방법에 대한 지침은 Xbox One SDK에 포함된 문서 참조)

- 참고: Windows 10 XDKS.1을 사용하는 경우 XDP에서 만든 개발자 계정을 사용하여 로그인해야 합니다. 게임 메뉴 또는 Windows의 Xbox 앱에서 이 계정에 로그인할 수 있습니다.

# 알려진 문제

- 진행 중인 게임에 참가하는 것은 플레이어가 현재 로비 화면에서 게임이 시작되기를 기다리는 경우에만 가능합니다.
