PlayFabMultiplayerRumble

*このサンプルは Microsoft Game Development Kit (2022 年 6 月) と互換性があります*

# 説明

このサンプルでは、PlayFab マルチプレイヤー API と PlayFab パーティー API を使用して完全なエンド ツー エンドのゲーム エクスペリエンスを構築するマルチプレイヤー機能を示します。

このサンプルでは、次のマルチプレイヤー シナリオのオプションを提供します。

- **参加可能なロビーの作成**

> プラットフォーム UI を介してアドバタイズされるロビーを次のように作成します。
> 参加可能。

- **フレンドやパーティー メンバーをロビーに招待する**

> システム UI を開いて、フレンドをロビーに招待します。 カスタムを使用する
> 招待文字列。
>
> パーティー メンバーに招待を送信します。

- **フレンドのセッションへの参加が進行中です**

> フレンドがプレイしているロビーを列挙して表示し、参加させる
> 直接。 参加は、Xbox 本体のシェルから行うことも、
> フレンドのゲーマー カードまたはアクティビティを使用して Windows のXbox アプリから
> フィード、またはパーティー メンバーがゲーム セッションに参加している場合はパーティー アプリから。

- **Matchmaking**

> マッチメイキング チケットの作成と送信。 マッチメイキングは
> 成功した場合にロビー接続文字列を返します。

- **アクティブなゲームプレイ**

> すべてのロビー メンバー間での状態と
> 一度に最大 4 人のプレイヤーを対象にしたゲームプレイ シナリオ。 この場合のゲームプレイ
> これは、ツイン スティック のすばらしいシューティング ゲームです。

# サンプルのビルド

Project Scarlett を使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.Scarlett.x64` に設定します。

Xbox One 開発キットを使用している場合は、アクティブなソリューション プラットフォームを `Gaming.Xbox.XboxOne.x64` に設定します。

Windows PC を使用する場合は、アクティブなソリューション プラットフォームを Gaming.Desktop.x64 に設定します

*詳細については、* *GDK ドキュメント*の「__サンプルの実行__」を参照してください。

# サンプルの使用方法

**サンドボックス要件のXbox Live**

- 開発キット Xbox One: 本体のサンドボックスを XDKS.1 に設定する

- Windows 10: 既定のリテール サンドボックスを使用するか、XDKS.1 に設定して Xbox One とのクロスプレイを行います (Windows で Xbox Live サンドボックスを変更する方法については、Xbox One SDK に含まれているドキュメントを参照してください)

- 注: Windows 10 で XDKS.1 を使用する場合は、XDP で作成された開発者アカウントを使用してサインインする必要があります。 このアカウントには、ゲーム メニューまたは Windows の Xbox アプリからサインインできます。

# 既知の問題

- 進行中のゲームへの参加は、プレイヤーがロビー画面に座っている間にゲームが開始されるのを現在待っている場合にのみ可能です。

# プライバシーにかんするせいめい

サンプルをコンパイルして実行する場合、サンプルの使用状況を追跡するために、サンプルの実行可能ファイルのファイル名が Microsoft に送信されます。 このデータ コレクションからオプトアウトするには、App.cpp の "Sample Usage Telemetry" というラベルの付いたコードのブロックを削除します。

Microsoft のプライバシー ポリシー全般の詳細については、「[Microsoft のプライバシーに関する声明](https://privacy.microsoft.com/en-us/privacystatement/)」を参照してください。
