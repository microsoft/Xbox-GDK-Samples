NetRumble 샘플

*이 샘플은 Microsoft 게임 개발 키트 미리 보기(2019년 11월)와
호환됩니다.*

# 설명

이 샘플에서는 2015 Multiplayer API로 전체 엔드투엔드 게임 환경을
구축하여 멀티플레이어 기능을 보여 줍니다. 이 샘플에서는 현재
Gaming.Xbox.x64만 지원하며,

다음 멀티플레이어 시나리오에 대한 옵션을 제공합니다.

-   **참가 가능한 세션 만들기**

> 플랫폼 UI를 통해 참가 가능으로 광고되는 로비 세션을 만듭니다.
>
> 로비 세션에 연결된 게임 세션을 만듭니다.

-   **친구 및 파티 구성원을 세션에 초대**

> 친구를 세션에 초대하는 시스템 UI를 엽니다. 사용자 지정 초대 문자열을
> 사용합니다.
>
> 파티 구성원에게 초대를 보냅니다.

-   **진행 중인 친구의 세션에 참가**

> 친구가 재생 중인 세션을 열거하여 표시하고 세션에 직접 참가합니다. Xbox
> 콘솔의 셸이나 Windows의 Xbox 앱에서 친구의 게이머 카드 또는 활동
> 피드를 통해 또는 파티 앱(파티 구성원이 게임 세션에 있는 경우)에서
> 참가할 수도 있습니다.

-   **게임 상대 찾기**

> 게임 세션을 만든 후 등록하고 게임 상대 찾기 티켓을 제출합니다. 게임
> 상대 찾기에 성공하면 게임 세션이 반환됩니다.

-   **호스트 마이그레이션 처리\
    **각 세션 유형의 호스트를 설정하고 호스트가 세션에서 나갈 경우
    호스트 임무를 마이그레이션합니다.

-   **활성 게임 플레이**

> 모든 세션 구성원 간에 한 번에 최대 8명의 플레이어에 대한 상태 및 게임
> 플레이 시나리오 관련 데이터를 보내고 받습니다. 이 경우 게임 플레이는
> 매력적인 트윈 스틱 슈터입니다.

# 알려진 문제

-   한 사용자가 로비 화면에서 표시되지 않도록 하는 경합 상태가 있습니다.
    해당 게임 상대를 취소한 후 다시 시도해야 합니다.

-   이 Project Antibes 포트에서는 오디오가 아직 완벽하게 구현되지
    않았습니다.

-   아직 게임 채팅이 구현되지 않았습니다.

# 구현 참고 사항

이 샘플은 Xbox Services API multiplayer_manager 클래스를 사용하여 Xbox
Live 멀티플레이어 게임 플레이를 구현하는 방법을 보여주는 쇼케이스
게임입니다.

새로운 멀티플레이어 API에서는 필수 Xbox One G*ame 파티* 개념이
종료되었습니다. 타이틀에서 세션을 적합하게 보이도록 관리하고, Xbox One
셸에서 참가 가능하거나 보이도록 할 세션을 홍보합니다. 샘플레서
*SetLobbySessionJoinRestrictionAsync*, *SetLobbySessionClosedAsync*,
*AdvertiseGameSessionAsync* 및 *GetGameTransferHandle*을 참조하세요.

*[참고:]{.underline} 게임 파티를 활용하는 이전 XDK를 기반으로 구축된
레거시 타이틀은 여전히 지원되지만 이 샘플에는 표시되지 않습니다.*

이 샘플의 게임 상대 찾기 흐름은 기본 연료통 하나를 포함하고 빈 슬롯을
다시 채우지 않는 매우 간단한 일치 구현입니다. 더 복잡한 게임 상대 찾기
시나리오와 관련하여 도움이 필요한 경우 멀티플레이어 XDK 문서 및
멀티플레이어 2015 개발자 순서도 백서를 참조하세요.

이 샘플에서는 새 멀티플레이어 2015 API *get_activities_for_social_group*
을 사용하여 멀티플레이어 관리자에 포함되지 않은 게임 내 참가 가능한 세션
목록을 렌더링합니다. 이 목록은 *MultiplayerMenuScreen*에서 찾을 수
있습니다.

이 샘플에서는 일치 세션 템플릿을 통한 자동 평가를 사용하여 QoS를
처리합니다. 자세한 내용은 샘플과 함께 제공된 서비스 구성 문서를
참조하세요. 측정되는 세 값은 *BandwidthUp*, *BandwidthDown*,
*LatencyAverage*입니다.

이 샘플에서는 구성원 목록의 슬롯 0에 있는 사용자가 새로운 호스트가 되는
멀티플레이어 2015 개발자 순서도에 설명된 것보다 더 간단한 호스트
마이그레이션 디자인을 구현합니다. 더 완전한 QoS 기반 솔루션은 순서도를
참조하세요.

# 알려진 문제

-   이 샘플과 함께 제공되는 네트워크 메시는 사용자 구현을 위한 기준으로
    사용됩니다. [메시가 프로덕션 환경에 사용할 정도로 탄력적이라고
    생각해서는 안 됩니다.]{.underline}

-   제공된 네트워크 메시에서는 플레이어가 엄격한 NAT 유형에 있거나
    엄격한 호스트로 호스트 마이그레이션이 발생할 수 있는 시나리오를
    제공하지 않습니다. 사용자의 메시에서는 이러한 경우를 처리해야
    합니다.

-   이 샘플에서는 여러 로컬 플레이어를 처리하는 시나리오를 고려하지
    않습니다. 타이틀에서 로컬 멀티플레이어와 온라인 멀티플레이어를
    혼합하려면 세션에 포함된 로컬 플레이어를 캐시해야 합니다.

-   QoS 요구 사항은 자동 평가를 위한 일치 세션 템플릿에 지정되어
    있습니다. 타이틀 평가 QoS는 현재 이 샘플의 범위를 벗어납니다.

-   현재 멀티플레이어 관리자는 정리할 부실 세션을 찾지 않습니다. 개발
    중에 타이틀에서 모든 이전 세션을 찾아서 나가는 것이 좋습니다. 이전
    세션이 있으면 멀티플레이어 게임을 시작할 때 충돌 등으로 인해 게임이
    느려질 수 있습니다.

-   *CheckPrivilegeAsync*는 아직 UWP용 Xbox Live SDK에서 아직 사용할 수
    없으므로, Windows 버전의 샘플을 실행할 때 권한 확인을 건너뜁니다. 이
    기능은 이후 릴리스에서 제공될 예정입니다.
