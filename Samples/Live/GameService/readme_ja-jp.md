# ゲーム サービスのサンプル

# 説明

カスタム Web サービスを Xbox Live 対応タイトルと統合するには、認証とユーザー識別に XSTS トークンを使用する必要があります。 XUserGetTokenAndSignatureUtf16Async() を使用すると、クライアントから X トークンを取得するのは簡単です。ただし、X トークンとの統合と操作は困難な場合があります。 このサンプルは、X トークンの暗号化を解除して検証するためのソース コードの例と、他の Xbox Live サービスに対してユーザー (バックエンドからバックエンドまたは B2B) の代理で認証された呼び出しを行うために必要なサービスとの通信を行う、Xbox Live タイトルの機能する Web サービスです。

これは、X トークンに関する教育の視覚的な例、別の言語で独自のトークン処理を記述するためのリファレンス、またはゲームの Web サービスを構築するための基本フレームワークとして使用できます。

注: このサンプルは教育ツールであるため、Web サービス攻撃に対しては強化されません。また、サンプルのコードを使用する場合は、サービスのセキュリティの一部として、DDOS、タイミング、およびその他の攻撃ベクトルのベスト プラクティスに従うようにしてください。

# 実装メモ

このサンプルには、次の主な機能と設計があります。

- すべてのトークン処理クラスと関数へのソース コード アクセスは、未加工のソース コードを通じて、または一般に公開されているオープン ソース ソフトウェア ソリューション (Newtonsoft.Json、JwT、.NET Core) を使用して行われます。

- Web サービスを作成するための出発点として使用できるサンプル

- C# ASP.NET Core を使用して複数のサーバー OS で実行する機能

   - Windows Server 2016 確認済み

   - Linux (Ubuntu 16.04) 確認済み

- レガシ XSTS トークン (XDP 構成 JWT Draft 7 Asymmetric) と最新の XSTS トークン形式 (JWT RFC 対称キーと非対称キーの構成パートナー センター) の両方のトークン処理と検証

- Xbox Live サーバー間要求に必要なサービス トークンの取得と管理

- ユーザーに代わってサーバー間要求を Xbox Live するために必要な委任された認証 XSTS トークンの取得と使用

- 証明書利用者、ビジネス パートナー証明書、および NSAL セットアップのデベロッパー センターでの詳細な構成手順。

- Xbox Live 発行者証明書の更新とロールオーバーの自動処理

# 既知の問題

- このサンプルでは、現在、Xbox Live サービスに対する調整された呼び出しを監視または処理していません。 サービスを呼び出す頻度が高すぎると、呼び出しは 429 HTTP 状態で返され、次の要求を行えるタイミングに関する情報が返されます。
