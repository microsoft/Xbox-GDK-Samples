# 游戏服务样本

# 说明

若要将自定义 Web 服务与已启用 Xbox Live 的游戏集成，需要使用 XSTS 令牌进行身份验证和用户标识。 使用 XUserGetTokenAndSignatureUtf16Async() 从客户端获取 X 令牌非常简单。但是，与 X 令牌集成和操作可能具有挑战性。 此样本是 Xbox Live 游戏的一个正常运行的 Web 服务，其中包含用于解密和验证 X 令牌的示例源代码，以及与代表用户(后端到后端或 b2b) 对其他 Xbox Live 服务进行身份验证调用所需的服务的通信。

这可以用作有关 X 令牌的教育的可视示例、使用其他语言编写自己的令牌处理的参考，也可以用作构建游戏 Web 服务的基本框架。

注意: 由于该样本是一种教育工具，因此它不会针对 Web 服务攻击进行强化，如果使用样本中的代码，则应确保在服务安全性过程中遵循 DDOS、计时和其他攻击途径的最佳做法。

# 实现说明

此样本具有以下主要功能和设计:

- 通过原始源代码或使用公开的开源软件解决方案 (Newtonsoft.Json、Jose.JWT、.NET Core) 访问所有令牌处理类和函数的源代码

- 能够用作创建 Web 服务的基础的样本

- 能够使用 C# ASP.NET Core 在多个服务器操作系统上运行

   - Windows Server 2016 已验证

   - Linux (Ubuntu 16.04) 已验证

- 旧版 XSTS 令牌的令牌处理和验证 (XDP 配置的 JWT 草稿 7 非对称) 和最新的 XSTS 令牌格式 (合作伙伴中心配置的 JWT RFC 对称密钥和非对称密钥)

- 检索和管理 Xbox Live 服务器到服务器请求所需的服务令牌

- 检索和使用代表用户 Xbox Live 服务器到服务器请求所需的委派身份验证 XSTS 令牌

- 开发人员中心中用于信赖方、业务合作伙伴证书和 NSAL 设置的分步配置说明。

- 自动处理 Xbox Live 证书颁发者证书更新和滚动更新

# 已知问题

- 此样本当前不监视或处理对 Xbox Live 服务的限制调用。 当调用服务过于频繁时，将返回具有 429 HTTP 状态的调用，以及有关何时可以发出下一个请求的信息。
