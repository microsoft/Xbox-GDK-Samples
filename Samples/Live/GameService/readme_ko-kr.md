# 게임 서비스 샘플

# 설명

사용자 지정 웹 서비스를 Xbox Live에서 사용 가능한 타이틀과 통합하려면 인증 및 사용자 식별을 위해 XSTS 토큰을 사용해야 합니다. XUserGetTokenAndSignatureUtf16Async()를 사용하여 클라이언트에서 X 토큰을 가져오는 것은 간단합니다. 하지만 X 토큰과 통합하고 X 토큰을 작동하는 것은 어려울 수 있습니다. 이 샘플은 X 토큰을 해독하고 확인하는 데 필요한 예시 소스 코드를 포함하는 Xbox Live 타이틀용 기능성 웹 서버이자 다른 Xbox Live 서비스에 대해 사용자를 대신하여 인증 호출(백 엔드 투 백 앤드 또는 b2b)을 하는 데 필요한 서비스와 통신하는 기능성 웹 서버입니다.

X 토큰 관련 교육을 위해 보여줄 예시로 사용할 수도 있고 다른 언어로 고유한 토큰 처리를 작성하기 위한 참조로 사용할 수도 있으며 게임의 웹 서비스를 빌드하기 위한 기본 프레임워크로 사용할 수도 있습니다.

참고: 샘플은 교육 도구이므로 웹 서비스 공격에 대비하여 강화되지 않으며 샘플의 코드를 사용하는 경우 서비스 보안의 일부로 DDOS 공격, 타이밍 공격 및 기타 공격 벡터에 대한 모범 사례를 준수하고 있는지 확인해야 합니다.

# 구현 참고 사항

이 샘플의 주요 기능과 디자인은 다음과 같습니다.

- 토큰을 처리하는 모든 클래스와 기능에 대해 원시 소스 코드를 통해서 또는 공개적으로 사용할 수 있는 Open Source Software 솔루션(Newtonsoft.Json, Jose.JWT, .NET Core)을 이용하는 방법을 통한 소스 코드 액세스

- 웹 서비스 제작용 기초로 활용할 수 있는 샘플

- C# ASP.NET Core를 사용하여 다양한 서버 운영 체제에서 실행할 수 있는 기능

   - 확인된 Windows Server 2016

   - 확인된 Linux(Ubuntu 16.04)

- 레거시 XSTS 토큰(XDP 구성된 JWT Draft 7 비대칭 토큰)과 최신 XSTS 토큰 형식(파트너 센터로 구성된 JWT RFC 대칭 및 비대칭 키) 모두에 대한 토큰 처리 및 유효성 검사

- Xbox Live 서버 간 요청에 필요한 서비스 토큰 검색 및 관리

- 사용자 대신 Xbox Live 서버 간 요청을 하는 데 필요한 위임 인증 XSTS 토큰의 검색 및 사용

- 신뢰 당사자, 비즈니스 파트너 인증, NSAL 설정을 위한 개발자 센터의 단계별 구성 지침

- Xbox Live 발급자 인증서 업데이트 및 롤오버 자동 처리

# 알려진 문제

- 샘플에서 현재 Xbox Live 서비스에 대한 제한된 호출을 모니터링하거나 처리하지 않습니다. 서비스를 너무 자주 호출하면 호출이 429 HTTP 상태와 다음 요청을 수행할 수 있는 시기에 대한 정보를 반환합니다.
