# 네트워킹 보안 OpenSSL Linux 서버 샘플

### **참고: 이러한 샘플은 예시적인 참고 자료로만 제공됩니다. Microsoft는 이것이 현재 또는 미래의 네트워킹 보안 목표를 달성하는 데 충분하다고 보장하거나 보증하지 않습니다. 구현을 독립적으로 평가해야 합니다.**

# 설명

이 샘플은 OpenSSL의 DTLS 구현을 사용하여 UDP 트래픽을 보호하기 위한 모범 사례를 보여주며, 네트워킹 보안 OpenSSL 샘플과 함께 작동하도록 설계되었습니다.

# 샘플 빌드

샘플을 생성하는 데 사용된 개발 환경은 다음과 같습니다.

- Windows 10의 v2 Linux용 Windows 하위 시스템

- Ubuntu 20.04 LTS

- Visual Studio Code

기본 설치 외에도, Ubuntu는 다음을 사용하여 추가로 구성되었습니다.

`sudo apt install build-essential clang gcc gdb openssl-dev`

이 샘플에는 로컬 시스템 구성에 맞게 수정해야 할 수 있는 .vscode 디렉터리의 VS 코드 프로젝트 구성이 포함되어 있습니다.

위의 구성을 가정하여 다음과 같이 프로젝트를 빌드할 수도 있습니다.

`clang++ -std=c++17 -g ./\*.cpp -o ./NetworkSecurityOpenSSL_Linux -l ssl -l crypto -pthread`

# 샘플 실행

이 샘플을 실행하려면 네트워크 보안 OpenSSL 샘플도 빌드하고 실행해야 합니다. 서버에는 x509 인증서와 관련 개인 키도 필요합니다.

일반적으로 프로덕션 타이틀은 보안 키 서비스를 사용하여 보안 유효성 검사를 위한 인증서 정보를 교환하지만 샘플의 목적을 위해 이러한 값을 클라이언트와 서버 간에 복사/붙여넣기해야 합니다.

클라이언트를 시작하면 ID 문자열이 생성되고 표시됩니다. 이 값은 서버를 시작하는 데 필요하며, 시작 시 메시지가 표시됩니다. 서버는 ID 문자열도 생성합니다.

클라이언트에서 연결 열기를 선택하면 서버 주소와 ID 문자열을 묻는 메시지가 표시됩니다. 이러한 값이 입력되면 클라이언트는 서버에 연결하는 동안 보안을 위한 모범 사례를 따르고 클라이언트는 임의의 메시지를 서버에 보낼 수 있으며 이를 다시 반향할 수 있습니다.

# 구현 참고 사항

이 샘플의 DTLS 구현은 Linux로 포팅된 네트워크 보안 OpenSSL 샘플의 구현과 동일합니다.

클라이언트 버전과의 차이점은 다음과 같습니다.

- Winsock API가 일반 BSD 소켓으로 대체되었습니다.

- Windows 스레드 풀 및 중첩된 I/O가 std::thread 및 select() 루프로 대체됨

이 샘플에는 휴대성을 위해 STL에 구축된 XAsync 및 XTaskQueue의 구현도 포함되어 있습니다.

마지막으로 프로덕션 코드에서 키 서비스 또는 로비 서비스(예: MPSD)를 사용하여 게임 인스턴스 간에 키 자료를 안전하게 공유해야 합니다.
