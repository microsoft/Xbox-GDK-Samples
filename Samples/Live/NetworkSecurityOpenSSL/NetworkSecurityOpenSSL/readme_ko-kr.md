# 네트워킹 보안 OpenSSL 샘플

*이 샘플은 Microsoft 게임 개발 키트와 호환됩니다(2022년 3월).*

# **참고: 이러한 샘플은 예제 참조로만 제공됩니다. Microsoft는 이것이 현재 또는 미래의 네트워킹 보안 목표를 달성하는 데 충분하다고 보장하거나 보증하지 않습니다. 구현을 독립적으로 평가해야 합니다.**

# 설명

이 샘플은 OpenSSL의 DTLS 구현을 사용하여 UDP 트래픽을 보호하기 위한 모범 사례를 보여 줍니다.

![그래픽 사용자 인터페이스, 텍스트, 웹사이트 설명이 자동으로 생성됨](./media/image3.png)

# 샘플 빌드

이 샘플은 Xbox One, Xbox Series 콘솔 및 GDK 데스크톱을 지원합니다. 드롭다운에서 구성을 선택하여 빌드합니다.

*자세한 내용은* *GDK 설명서의* __샘플 실행을__ 참조하세요.&nbsp;

이 샘플은 미리 컴파일된 버전의 OpenSSL과 함께 제공되지 않습니다. 다음 원본 중 하나에서 최신 버전을 가져오고 프로젝트에 추가해야 합니다.

PC의 경우 다음에서 최신 바이너리를 다운로드할 수 있습니다.

- <https://www.openssl.org/>

- <https://github.com/openssl/openssl>

아니면 [vcpkg](aka.ms/vcpkg) 또는 nuget과 같은 패키지 관리자를 사용할 수 있습니다.

Xbox 콘솔의 경우 Github에서 원본을 획득하고 다음 구성으로 사용자 지정 버전을 빌드해야 합니다.

```perl
perl&nbsp;Configure&nbsp;VC-WIN64A-masm&nbsp;no-ui-console&nbsp;no-dso&nbsp;no-stdio -D"WINAPI_FAMILY=WINAPI_FAMILY_GAMES"&nbsp;-D"_WIN32_WINNT=0x0A00" -DOPENSSL_SYS_WIN_CORE
```


# 샘플 실행

샘플은 클라이언트 또는 호스트로 실행되고 미리 공유된 키 또는 인증서를 사용할 수 있습니다. 샘플은 클라이언트와 호스트 간에 한 번에 하나의 연결만 보여 주도록 빌드됩니다. 호스트로 시작하려면 "연결 수락" 단추를 누릅니다. 미리 공유된 키 또는 인증서를 사용하는 경우 샘플은 인증서의 키 또는 지문을 출력합니다. "수락"을 클릭하면 연결하려는 클라이언트의 IP 주소를 묻는 창 팝업이 표시됩니다. 콘솔에서는 콘솔의 방화벽을 통해 클라이언트의 패킷을 허용하는 데 필요합니다.

![그래픽 사용자 인터페이스 설명 자동으로 생성됨](./media/image4.png)

호스트에 연결하려면 "연결 열기" 단추를 클릭합니다. 첫 번째 팝업 창은 호스트의 IP 주소 및 포트에 대한 것입니다. 두 번째는 호스트에서 사용 중인 지문 또는 미리 공유된 키에 대한 것입니다.

연결이 완료되면 "메시지 보내기"를 누르면 2개의 샘플 인스턴스 간에 보낼 문자열을 입력할 수 있습니다. Wireshark와 같은 도구에서 트래픽을 본 경우 암호화되고 읽을 수 없습니다.

# 구현 참고 사항

이 샘플은 DGRAM BIO가 아닌 OpenSSL의 메모리 BIO를 사용합니다. 이 작업은 여러 연결에 소켓을 다시 사용할 수 있도록 하기 위해 수행되었습니다(이 샘플에서는 보여주지 않음). 이 데이터를 활용하려면 소켓과 BIO 간에 이동해야 하며 DGRAM BIO와 마찬가지로 자동으로 수행되지 않습니다.

기본 UDP 소켓은 Overlapped I/O 및 Windows 스레드 풀을 사용하여 데이터가 OS에서 수신되고 타이틀에 전달되는 사이의 지연을 최소화합니다.

마지막으로 프로덕션 코드에서 키 서비스 또는 로비 서비스(예: MPSD)를 사용하여 게임 인스턴스 간에 키 자료를 안전하게 공유해야 합니다.
