# 네트워킹 보안 CNG(BCrypt) 샘플

*이 샘플은 Microsoft 게임 개발 키트와 호환됩니다(2022년 3월).*

# 설명

이 샘플은 CNG (Crypto Next Generation) API를 사용하는 DTLS 구현을 사용하여 UDP 트래픽을 보호하기 위한 모범 사례를 보여줍니다.

# 샘플 실행

이 샘플을 실행하려면 포함된 DTLSEchoServer 프로젝트도 빌드하고 실행해야 합니다. 서버에는 x509 인증서와 RSA 개인 키도 필요합니다.

일반적으로 프로덕션 타이틀은 보안 키 서비스를 사용하여 보안 유효성 검사를 위한 인증서 정보를 교환하지만 샘플의 목적을 위해 이러한 값을 클라이언트와 서버 간에 복사/붙여넣기해야 합니다.

클라이언트를 시작하면 ID 문자열이 생성되고 표시됩니다. 이 값은 서버를 시작하는 데 필요하며, 시작 시 메시지가 표시됩니다. 서버는 ID 문자열도 생성합니다.

클라이언트에서 연결 열기를 선택하면 서버 주소와 ID 문자열을 묻는 메시지가 표시됩니다. 이러한 값이 입력되면 클라이언트는 서버에 연결하는 동안 보안을 위한 모범 사례를 따르고 클라이언트는 임의의 메시지를 서버에 보낼 수 있으며 이를 다시 반향할 수 있습니다.

# 구현 참고 사항

이 샘플에서는 Microsoft CNG(Crypto: Next Generation) API를 사용하여 미리 공유된 인증서 및 프라이빗 키를 처리하고, 자체 서명된 인증서를 생성하고, TLS_ECDHE_RSA_WITH_AES_256_CBC_SHA384를 사용하여 보안 연결을 구현하는 방법을 보여 줍니다.

기본 UDP 소켓은 Overlapped I/O 및 Windows 스레드 풀을 사용하여 데이터가 OS에서 수신되고 타이틀에 전달되는 사이의 지연을 최소화합니다.

마지막으로 프로덕션 코드에서 키 서비스 또는 로비 서비스(예: MPSD)를 사용하여 게임 인스턴스 간에 키 자료를 안전하게 공유해야 합니다.

# 알려진 문제

샘플은 DTLS 1.2 프로토콜을 부분적으로만 구현하며 프로덕션 준비 DTLS 서버가 아닌 CNG API 사용 샘플로 설계되었습니다. 완전하지 않고 견고하지 않으며 신뢰할 수 있는 UDP 네트워킹 레이어가 아닙니다.
