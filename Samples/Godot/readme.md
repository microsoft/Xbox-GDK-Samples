# Godot

Samples demonstrating Microsoft Game Development Kit (GDK) integration with Godot 4.

These are external samples, built by XBOX, and are maintained in their own repositories rather than in this one. Follow the links below for requirements, build instructions, and full documentation.

## [XBOX Godot Sample](https://github.com/microsoft/XBOX-Godot-Sample)

Reference GDExtension addons that bind the Microsoft GDK, XBOX Services, PlayFab, and GameInput into Godot 4, usable from both GDScript and C#/.NET. Drop the addons into an existing Godot project to build your title for XBOX on PC, and work through the tutorial projects covering sign-in, achievements, leaderboards, Game Saves, lobbies, Party, and controller input.

## [XBOX Godot NetRumble](https://github.com/microsoft/XBOX-Godot-NetRumble)

A complete multiplayer XBOX game built in Godot 4: a 2D top-down space shooter with lobby and Party voice chat, invites from the guide, achievements, and a saved match history. Built on the XBOX Godot Sample addons, it wires each Microsoft GDK and PlayFab service into the place a shipping title would really call it, around a real game loop.
