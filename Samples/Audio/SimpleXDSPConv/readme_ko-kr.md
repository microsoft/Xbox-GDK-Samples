# 실시간 컨볼루션 샘플

*이 샘플은 Microsoft 게임 개발 키트(2022년 3월)와 호환됩니다.*

# 설명

이 샘플에서는 하드웨어 오프로드된 컨볼루션을 수행하는 방법을 보여 줍니다.
| | |
|---|---|
|Xbox Series X|S에서 XDsp API를 사용하는 반향|

# 샘플 빌드

| | |
|---|---|
| Xbox Series X와만 호환됩니다. | S |

*GDK 설명서의* __샘플 실행__에서 *자세한 내용을 알아보세요.*

# 샘플 사용

샘플은 한 쌍의 컨볼루션 반향을 실행하고 사용자 선택에 따라 두 개를 꺼짐, 짧음, 김 사이에서 혼합합니다. Dpad 위쪽/아래쪽 단추를 사용하여 각 반향의 양을 변경합니다.

# 구현 참고 사항

이 샘플에서는 새 XDsp API를 사용하여 하드웨어를 실행하는 방법을 보여 줍니다.
| | |
|---|---|
|Xbox Series X|S 하드웨어에서 실시간으로 오프로드된 컨볼루션 반향.|
