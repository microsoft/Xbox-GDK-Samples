# Real-time Convolution Sample

*This sample is compatible with the Microsoft Game Development Kit
(March 2022)*

# Description

This sample demonstrates how to perform hardware offloaded convolution
reverb using the XDsp API on the Xbox Series X|S

![Background pattern Description automatically generated](./media/image1.png)

# Building the sample

Note this is only compatible with Xbox Series X|S

*For more information, see* __Running samples__, *in the GDK documentation.*

# Using the sample

The sample runs a pair of convolution reverbs and mixes the two based on
the user selection between off, short, and long. Use the Dpad up/down
buttons to change the amount of each reverb.

# Implementation notes

This sample demonstrates how to use the new XDsp API to run hardware
offloaded convolution reverb in real-time on Xbox Series X|S hardware.
