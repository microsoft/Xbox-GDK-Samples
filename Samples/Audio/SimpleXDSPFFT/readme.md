# Real-time FFT Sample

*This sample is compatible with the Microsoft Game Development Kit
(March 2022)*

# Description

This sample demonstrates how to perform hardware offloaded fast Fourier
transforms (FFTs) using the XDsp API on the Xbox Series X|S

![](./media/image1.png)

# Building the sample

Note this is only compatible with Xbox Series X|S

*For more information, see* __Running samples__, *in the GDK documentation.*

# Using the sample

The sample shows an audio visualizer with the currently amplitude of the
playing sound in each frequency range. Pressing Y switches between bar
graph and line graph modes.

# Implementation notes

This sample demonstrates how to use the new XDsp API to run hardware
offloaded FFTs in real-time on Xbox Series X|S hardware.
