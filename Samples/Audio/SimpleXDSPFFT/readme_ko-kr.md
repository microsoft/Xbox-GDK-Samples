# 샘플 사용

샘플은 각 주파수 범위에서 재생되는 소리의 현재 진폭을 가진 오디오 시각화 도우미를 보여 줍니다. Y 키를 누르면 막대 그래프와 선 그래프 모드가 전환됩니다.

# 구현 참고 사항

이 샘플에서는 새 XDsp API를 사용하여 하드웨어를 실행하는 방법을 보여 줍니다.
| | |
|---|---|
|Xbox Series X|S 하드웨어에서 실시간으로 오프로드된 FFT.|
