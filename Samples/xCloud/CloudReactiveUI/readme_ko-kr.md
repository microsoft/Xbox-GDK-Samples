# 클라우드 반응형 UI 샘플

*이 샘플은 Microsoft 게임 개발 키트(2022년 3월)와 호환됩니다.*

# 설명

이 샘플에서는 게임 스트리밍 클라이언트를 검색하고 화면 컨트롤 레이아웃을 변경하여 다양한 입력 및 방향 설정을 처리하는 방법을 보여 줍니다.

![](./media/image1.png)

# 샘플 사용

샘플을 시작하기 전에 게임 스트리밍이 사용하도록 설정되어 있는지 확인합니다. 호환 가능한 클라이언트 앱(예: Xbox 게임 스트리밍 테스트 앱)을 사용하여 샘플을 실행하는 콘솔에 연결합니다. 연결되면 스트리밍 클라이언트의 현재 상태를 반영하도록 샘플을 변경해야 합니다.

게임 패드 또는 오버레이와 함께 방향 패드를 사용하고 A를 눌러 옵션을 선택합니다. &ldquo;방향 변경&rdquo;은 게임을 세로 방향으로 맞춥니다. 클라이언트에서 터치를 사용하는 경우 화면을 터치해서도 메뉴와 상호 작용합니다.

# 구현 참고 사항

이 샘플에서는 xCloud에 클라우드 인식 API를 사용하는 방법을 보여 줍니다.
