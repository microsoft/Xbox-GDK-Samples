# Cloud Reactive UI Sample

*This sample is compatible with the Microsoft Game Development Kit
(March 2022)*

# Description

This sample demonstrates how to detect game streaming clients and change
onscreen control layouts to handle differing input and orientation
setups.

![](./media/image1.png)

# Using the sample

Ensure that Game Streaming is enabled before launching the sample.
Connect to the console running the sample using any compatible client
app (such as the Xbox Game Streaming Test App). Once you are connected,
the sample should change to reflect presence of a streaming client.

Use a D-pad either with a gamepad or the overlay and press A to select
options. "Orientation Change" will align the game for a vertical
orientation. If the client is touch enabled, touch the screen to
interact with the menu as well.

# Implementation notes

This sample demonstrates how to use the cloud aware API for xCloud.
