# Cloud Reactive UI 示例

*此示例可用于 Microsoft 游戏开发工具包 (2022 年 3 月)*

# 说明

此示例演示如何检测游戏流式处理客户端并更改屏幕控件布局，以处理不同的输入和方向设置。

![](./media/image1.png)

# 使用示例

在启动示例之前，请确保已启用游戏流式处理。 使用任何兼容的客户端应用（如 Xbox 游戏流式处理测试应用）连接到运行示例的主机。 连接后，该示例应更改以反映流式处理客户端的存在。

使用带游戏板或叠加层的 D 键盘，然后按 A 选择选项。 &ldquo;方向更改&rdquo;可以将游戏按垂直方向对齐。 如果客户端已启用触摸功能，请触摸屏幕以与菜单交互。

# 实现说明

此示例演示如何使用适用于 xCloud 的云感知 API。
