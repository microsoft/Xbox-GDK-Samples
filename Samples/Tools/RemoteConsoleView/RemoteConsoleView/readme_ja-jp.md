# RemoteConsoleView サンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

このサンプル ツールでは、Xbox One Manager と同様の方法で、WPF アプリから VideoStreamingControl を使用して、PC 上でコンソール コンテンツをリモートで表示する方法を示します。

サンプルを実行するときに、本体の名前 (または IP アドレス) を入力し、[接続] ボタンをクリックすると、コンソールディスプレイがレンダリングされます。

アプリを初めて実行すると、ファイアウォール プロンプトが表示される可能性があります。リモート コンソールにアクセスするには、アプリにネットワーク アクセスが必要です。

独自の WPF プロジェクトでこのコントロールを使用する場合は、次の操作を行います:

- プロジェクトが 64 ビットでビルドされていることを確認します (コントロールは 64 ビット バージョンでのみ使用できます)

- `C:\Program Files (x86)\Microsoft GDK\bin\Microsoft.Xbox.Tools.RemoteVideo.dll` への参照を追加します (GDK インストールに付属)

- このファイルを Project に追加します: `C:\Program Files (x86)\Microsoft GDK\bin\xtfremotevideo.dll` *[出力ディレクトリにコピー]* が *[新しい場合はコピー]* に設定されていることを確認します。 コントロールを機能させるには、このファイルが exe の横に存在する必要があります。

- コントロールに XAML 参照を追加します。詳細については、サンプルを参照してください。

## VideoStreamingControl

コントロールは簡単に使用できます。 *Source* プロパティを本体の名前 (または IP アドレス) に設定すると、接続されるとすぐに開始されます (*自動再生* の既定値は True です)。 *Stop* メソッドがあり、*Volume* プロパティと *IsMuted* プロパティを使用してボリュームを制御できます。 エラーが発生した場合は、*Status* プロパティと *StatusMessage* プロパティをバインドできます。 このコントロールでは、レンダリングに *HWndHost* が使用されていることに注意してください。つまり、その上に他の WPF コントロールをレンダリングすることはできません (空域の問題が原因)。
