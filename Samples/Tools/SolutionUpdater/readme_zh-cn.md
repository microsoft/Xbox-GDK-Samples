# SolutionUpdater 示例

*此示例可用于 Microsoft 游戏开发工具包 (2022 年 3 月)*

# 说明

提供了此示例工具，用于将大量 Visual Studio 项目移动到新的 Game Core 编程模型。 该工具将 Visual Studio 解决方案文件 (.sln）用作输入，并使用它\&ldquo;遍历\&rdquo;关联的项目，即在它进行过程中添加新的所需平台。 该工具用于同时更新仅限电脑、仅限 Xbox 或两个平台。

该工具的默认行为是**覆盖**任何更新的文件（解决方案和项目文件），因此，如果出现任何错误，请确保可以从源代码管理或手动备份恢复原始文件。 该工具确实提供了&ldquo;备份编辑的文件&rdquo;复选框，该复选框将随之创建备份文件，但不应将其作为完整的备份策略来依赖。

运行此工具是将游戏移到 Game Core 的第一步，**不**用于提供用于转换的&ldquo;一键式&rdquo;方法。 请参阅 GDK 文档中的\&ldquo;移植指南\&rdquo;，以获取有关符合新编程模型所需的其他工作的更多详细信息。

# 用法

运行该工具时，会显示简单的 UI，如下所示：

![](./media/image1.png)

点击&ldquo;打开&rdquo;按钮以选择要转换的解决方案文件。 然后选择适用于开发的平台的选项，如果对更新有信心，请取消选择&ldquo;备份&rdquo;选项。

然后，该工具将处理所有必需的文件，并显示成功或失败消息，以及引发的异常信息。

然后，可以在 Visual Studio 中加载新更新的解决方案文件，以查看该工具所做的更改。
