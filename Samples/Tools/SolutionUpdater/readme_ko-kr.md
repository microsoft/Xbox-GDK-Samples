# SolutionUpdater 샘플

*이 샘플은 Microsoft 게임 개발 키트와 호환됩니다(2022년 3월).*

# 설명

이 샘플 도구는 많은 수의 Visual Studio 프로젝트를 새로운 게임 코어 프로그래밍 모델로 이동할 수단을 제공합니다. 이 도구는 Visual Studio 솔루션 파일(.sln)을 입력으로 취하고 이를 사용하여 연결된 프로젝트를 \"walk\"하여 새로 필요한 플랫폼에 추가합니다. 이 도구를 사용하여 PC만, Xbox만 또는 두 플랫폼을 동시에 업데이트할 수 있습니다.

이 도구의 기본 동작은 업데이트된 파일(솔루션 및 프로젝트 파일)을 **덮어쓰** 는 것이므로 오류가 발생하는 경우 원본 제어 또는 수동 백업에서 원본 파일을 복구할 수 있는지 확인하세요. 이 도구는 작업 하면서 백업 파일을 만드는 "편집된 파일 백업\" 확인란을 제공하지만 완전한 백업 전략으로 사용하지 않아야 합니다.

이 도구를 실행하면 타이틀을 Game Core로 이동하는 첫 번째 단계가 제공되며 변환을 위해 \"원클릭\" 메서드를 제공할 수 **없습니다**. 새 프로그래밍 모델을 준수하는 데 필요한 추가 작업에 대한 자세한 내용은 GDK 설명서의 \"포팅 가이드\"를 참조하세요.

# 사용법

도구를 실행하면 아래에 표시된 간단한 UI가 표시됩니다.

![](./media/image1.png)

"열기" 단추를 클릭하여 변환할 솔루션 파일을 선택합니다. 그런 다음, 개발 대상 플랫폼에 적용되는 옵션을 선택하고, 업데이트에 대해 확신하는 경우 "백업" 옵션을 선택 취소합니다.

그런 다음 도구는 필요한 모든 파일을 처리하고 던져진 예외 정보와 함께 성공 또는 실패에 대한 메시지를 표시합니다.

그런 다음 Visual Studio 새로 업데이트된 솔루션 파일을 로드하여 도구가 변경한 내용을 검토할 수 있습니다.
