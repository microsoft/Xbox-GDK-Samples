# SolutionUpdater サンプル

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

このサンプル ツールは、多数の Visual Studio プロジェクトを、新しい Game Core プログラミング モデルに移動するために用意されています。 このツールは、Visual Studio ソリューション ファイル (.sln) を入力として受け取り、これを使用して、関連付けられているプロジェクトを\"進めて\"、新しく必要となるプラットフォームの進行中に追加します。 このツールを使用して、PC のみ、Xbox のみ、または両方のプラットフォームを同時に更新することができます。

ツールの既定の動作では、更新されたファイル (ソリューションファイルとプロジェクトファイル) を**上書き**するため、エラーが発生した場合は、ソース管理または手動バックアップから元のファイルを回復できることを確認してください。 このツールには、バックアップ ファイルを作成する [編集済みファイルのバックアップ\] チェック ボックスが表示されますが、完全なバックアップ戦略として依存することのないようにしてください。

このツールを実行すると、タイトルを Game Core に移動するための最初の手順が提供されます。\"ワンクリック\" の変換方法を提供することは意図されて**いません**。 新しいプログラミング モデルに準拠するために必要な追加作業の詳細については、「GDK ドキュメントの \"移植ガイド\"」を参照してください。

# 使用法

ツールを実行すると、次に示す単純な UI が表示されます。

![](./media/image1.png)

[開く] ボタンをクリックして、変換するソリューション ファイルを選択します。 次に、開発対象のプラットフォームに適用するオプションを選択し、更新について確信がある場合は [バックアップ] オプションの選択を解除します。

その後、ツールは必要なすべてのファイルを処理し、成功または失敗に関するメッセージを送られてきた例外情報と共に表示します。

その後、新しく更新されたソリューション ファイルを Visual Studio に読み込んで、ツールが行った変更を確認できます。
