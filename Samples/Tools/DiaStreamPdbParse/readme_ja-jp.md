# DiaStreamPdbParse Sample

*このサンプルは、Microsoft Game Development Kit と互換性があります (2022 年 3 月)*

# 説明

このサンプルでは、DIA (デバッグ インターフェイス アクセス) SDK を使用して、特に例外中に生成された呼び出し履歴からタイトル内のシンボルを解決する方法を示します。 また、IStream インターフェイスを使用して、ディスクからの PDB データの読み込みを制御する方法についても説明します。 最後に、msdia140-xbox.dll という名前の DIA DLL の Xbox バージョンを提供します。

XBOX バージョンの DIA では、HeapAlloc を使用して、呼び出し元に返される BSTR オブジェクトを作成します。 これらは HeapFree を介して呼び出し元によって解放される必要があります。DIAString という名前のヘルパー クラスが symbolLookup.cpp で提供され、デスクトップとコンソールの両方で正しい処理を行います。 DIAString クラスは、DIA API を使用する場合に BSTR のドロップイン置換として使用できます。

Xbox で BSTR オブジェクトに HeapAlloc/HeapFree を使用するのは、SysAllocString/SysFreeString による標準的な BSTR メモリ管理メソッドがタイトルで使用できないためです。 DIA クエリ関数は SysAllocString を介して割り当てられた BSTR を返しますが、タイトルはそのメモリを解放する方法がありません。

XBOX バージョンの DIA には、本体に存在しない Shwlapi.dll への参照も含まれていません。

注: リテールおよび開発環境でこのサンプルに付属している DIA DLL (msdia140-xbox.dll) のバージョンを自由に使用できます。 ただし、現在、Xbox バージョンはVisual Studio チームではサポートされていません。 問題が発生した場合は、Xbox フォーラムでお問い合わせください。

# サンプルの使用方法

このサンプルでは、現在の呼び出し履歴が自動的にキャプチャされ、各関数のシンボルが解決され、結果が画面に表示されます。

# 実装メモ

symbolLookup.cpp の DumpCallstack 関数は、このサンプルのメイン エントリ ポイントです。 呼び出し履歴が解析するために、特定のスレッドまたはオブジェクトへの `EXCEPTION_POINTERS` 参照を受け取ることができます。

symbolLookup.cpp の上部には、収集するシンボル情報の量と種類を制御するいくつかの定義があります。 特定のシンボル情報は、特に Xbox One ファミリ 本体の回転ドライブで収集するコストが高くなる可能性があります。

PdbMemoryStream.cpp/h には、IStream から派生した IPdbMemoryStream が含まれています。 このクラスは、既定の PDB 読み込みメソッドを置き換えるために DIA に提供されます。 このクラスを使用すると、タイトルへの影響を最小限に抑えるために、使用されるメモリの量と読み取りパターンをさらに細かく制御できます。
