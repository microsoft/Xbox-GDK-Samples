#   インテリジェント配信を使用したストリーミング インストールのサンプル

*このサンプルは、Microsoft ゲーム開発キット (2020 年 2 月)
に対応しています。*

#  

# 説明

このサンプルでは、ストリーミング インストール API
の実例を示します。起動チャンクがインストールされた後で、このサンプルを実行すると、残りのチャンクのインストールの進捗状況を視覚化できます。

また、ローカライズ済みのチャンク、ハードウェア固有のチャンク、カスタム
タグなど、高度なインストール機能の実例も示します。ターゲット
ハードウェア (Xbox One ファミリの Durango/Xbox One X、Project Scarlett
ファミリの Lockhart/Anaconda) のターゲット
SKU、およびコンソールの言語/ロケールの設定に基づいて、各種のコンテンツがインストールされます。

# サンプルのビルド

Xbox One の devkit を使用している場合は、アクティブなソリューション
プラットフォームを Gaming.Xbox.XboxOne.x64 に設定します。

Project Scarlett を使用している場合は、アクティブなソリューション
プラットフォームを Gaming.Xbox.Scarlett.x64 に設定します。

*詳細については、GDK ドキュメントの*
「サンプルの実行」*を参照してください。*

# サンプルの使用

多くの GDK サンプルと異なり、この StreamingInstall サンプルは、Visual
Studio からビルドして展開することを意図したものではありません。Visual
Studio
から直接展開して実行することは可能ですが、そのようにすると、このサンプルでデモを示す予定のインストール
ツールとプロセスは使用されなくなります。このサンプルを使用する手順は次のとおりです。

1)  Visual Studio
    からサンプルをビルドする。ただし、サンプルは**展開せず、実行もしません**

2)  インストール パッケージのコンテンツを生成する

3)  インストール パッケージを作成する

4)  パッケージをインストールしてサンプルを実行する

新しい Project Scarlett コンソールの生成を使用すると、ターゲット
デバイス ファミリに基づいて個別の XVC
パッケージが作成されます。結果として、各 .bat および .config
ファイルには、テストするデバイス ファミリに応じて XboxOne のバージョンと
Scarlett のバージョンの両方が含まれます。デバイス
ファミリに関係なく、XPackage コードは GDK
では変更されません。MicrosoftGame.config ファイルでは、属性
"TargetDeviceFamily=\"\[XboxOne/Scarlett\]\"" がターゲット
ファミリに基づいて指定されます。

このセクションでは、各ステップについて詳しく説明し、ツールやプロセスについて詳しい情報を提供します。最初のステップは、Visual
Studio
からサンプルを単にビルドすることです。これにより、バイナリとディレクトリ
レイアウトが作成されます。これらは、最終的にはパッケージの作成で使用します。サンプルがビルドされた後、コマンドラインから
**CreateInstallPackage\_\[XboxOne/Scarlett\].bat**
を実行します。このバッチ
ファイルによって、インストールの進捗状況をリアルタイムで監視するコンテンツ
ファイルとして機能する、サイズの大きなファイルが複数作成され、ターゲット
デバイス ファミリが設定された適切な MicrosoftGame.config
が用意されます。

バイナリとコンテンツがビルド出力ディレクトリに配置された後に、次のステップとして、XDK
と共にインストールされた **MakePkg** ツールを使用してインストール
パッケージを作成します。**Xbox VS 2017 のゲーム コマンド
プロンプト**を開き、**StreamingInstall.vcxproj**
を格納しているディレクトリに移動します。 開いたコマンド プロンプトから
**CreateXVC\_\[XboxOne/Scarlett\].bat**
を実行できます。次のコマンドを直接実行することもできます。

XboxOne デバイス ファミリ:

> *makepkg.exe pack /v /f Chunks_XboxOne.xml /d
> \".\\Gaming.Xbox.x64\\Layout\\Image\\Loose\" /pd
> \".\\Gaming.Xbox.x64\\Layout\\Image\"*

Scarlett デバイス ファミリ:

> *makepkg.exe pack /v /f Chunks_Scarlett.xml /d
> \".\\Gaming.Scarlett.x64\\Layout\\Image\\Loose\" /pd
> \".\\Gaming.Scarlett.x64\\Layout\\Image\"*

このコマンドで使用されるオプションは次のとおりです。

| オ プ シ ョ ン |  詳細 |
|-----|----------------------------------------------------------------|
| /v  |  エラー報告の詳細出力を指定します。                             |
| /f  |  インストール パッケージの作成に使用するレイアウト ファイルを指定します。このサンプル (**Chunks\_\[XboxOne/Scarlett\].xml**) に含まれているレイアウト ファイル の詳細については、このセクションの後半部分を参照してください。 |
| /d  |  パッケージのコンテンツのソース ディレクトリを指定します。      |
| /pd  |  インストール パッケージ ファイルの出力ディレクトリを指定します。                       |

このパッケージには数ギガバイトのフィラー
コンテンツが含まれているため、実行には数分かかることがあります。実行が完了すると、**/pd**
オプションの後に指定した場所 (この例では
**\".\\Gaming.\[Xbox/Scarlett\].x64\\Layout\\Image\"** ディレクトリ)
に複数のファイルが作成されます。実際のインストール パッケージ
ファイルには、パッケージの**パッケージ ファミリ名**
(ファイル拡張子ではない) が名前として付与されます。

最後のステップは、開発コンソールにパッケージをインストールすることです。多数のオプションがあり、どのシナリオをテストするかに応じて、どのコンテンツをインストールするか決定します。ストリーミング
インストールの実装をテストする場合は、次のコマンドを使用できます。

> xbapp install \[/l\] \[/w\] \<パッケージ名\>

| オプション     |  詳細                                                |
|----------------|-----------------------------------------------------|
| \< パッケージ名\> |  MakePkg コマンドから作成されたインストール パッケージ。                                        |
| /l  |  起動チャンクのみをイン ストールするように指定します。起動チャンクがインス トールされた後、ゲームを実行できますが、レイアウト ファイルで \"Launch\" とマークされたチ ャンクに列挙されているコンテンツのみ使用できます。  |
| /w  |  インス トールでパイプが開いたままになるように指定します。 これにより、初期インストールされないオンデマンド チャンクおよび追加 の言語チャンクの動的インストールをテストできます。  |
| \<完全 パッケージ名\>  |  コンソールに インストールされた後のゲームの名前です。パッケージ ファミリ名と混同しないようにしてください。コマンド プロンプトから **xbapp list** コマンドを実行することで、インストールされ ているパッケージの一覧をコンソールに表示できます。  |

/l および /w
を使用して、ゲームのインストールのさまざまなシナリオをテストできます。/l
のみを使用すると、最初のチャンクのみがインストールされます。/l および /w
を使用すると、最初のチャンクがインストールされ、残りのチャンクはアプリケーションを起動した後にインストールされます。これらのフラグをどちらも指定しないと、オンデマンド
チャンクと既定以外の言語チャンクを除く基本パッケージ全体がインストールされます。

一部のチャンクは、ユーザーのシステムと言語に基づいて自動的にインストールされます。たとえば、言語が
\"en-US\" に設定された XboxOne ファミリ パッケージを Durango
コンソールに展開した場合、言語 \"fr\" またはデバイス \"Xbox-Scorpio\"
がタグとして付けられたチャンクはインストールされません。Scarlett
ファミリ パッケージでは、ターゲット デバイス (または devkit
のデバッグ設定) に基づいて、Lockhart または Anaconda
のいずれかのコンテンツがインストールされます。

コマンドに渡すことができるオプションの引数を指定した **xbapp install**
を使用して、他のチャンクを強制的にインストールできます。

| オ プション |  詳細 |
|----------|-----------------------------------------------------------|
| /L anguages  |  インストールする言語 を、セミコロンで区切られた言語のリストで指定します。これ を使用すると、コンソールの設定を変更した後にインストール コマンドを再実行しなくても、複 数の言語にローカライズされたコンテンツをテストできます。  |
| /Devices  |  インストールするハードウェア固 有のチャンクを指定します。これは、組み込む各ハードウェア SKU をセミコロンで区切ったリストです。                    |
| /A llChunks |  コンソールのハードウェアや設定に関係な く、すべてのチャンクをインストールすることを指定します。  |

これは、**xbapp install**
コマンドで使用できるすべてのオプションを網羅したリストではありません。オプションの全リストについては、GDK
のドキュメントを参照してください。

このサンプルでは、次のコントロールを使用します。

| 操作                               |  コントローラーのコントロール   |    |
|------------------------------------|--------------------------------|---|
| グリッド メニューを操作する        |  方向パッド                     |    |
| グリッド メニューからアイテムを選択する。 不足してい るチャンクのインストールを試行する (可能な場合)。 複数のグリッド アイテムが保 留になっている場合、現在のグリッド アイテムを最初にインストールする。 |  A  |  |
| 開 いているアイテムを閉じて、グリッド メニューに戻る |  B  |  |
| 選択したオプショ ンのチャンクをアンインストールする (可能な場合) |  X  |  |
| サンプルを終了する                 |  表示                           |    |

# 更新履歴

2019 年 4 月、サンプルの最初のリリース。

ファミリの構成を分離するためにサンプルを更新。

# プライバシーに関する声明

サンプルをコンパイルして実行すると、サンプルの使用状況を追跡するため、サンプルの実行可能ファイルのファイル名が
Microsoft に送信されます。このデータ収集を無効にするには、「Sample Usage
Telemetry」とラベル付けされた Main.cpp
内のコードのブロックを削除します。

Microsoft のプライバシーに関する声明の詳細については、「[Microsoft
プライバシー
ステートメント](https://privacy.microsoft.com/en-us/privacystatement/)」を参照してください。
