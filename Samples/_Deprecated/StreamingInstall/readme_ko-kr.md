#   지능형 배달 기능으로 스트리밍 설치 샘플

*이 샘플은 Microsoft 게임 개발 키트(2020년 2월)와 호환됩니다.*

#  

# 설명

이 샘플에서는 스트리밍 설치 API를 보여 줍니다. 시작 청크가 설치되면
샘플을 실행하여 나머지 청크의 설치 진행률을 시각화할 수 있습니다.

또한 지역화된 청크, 하드웨어 관련 청크 및 사용자 지정 태그를 비롯한
지능적인 설치 기능도 보여 줍니다. 대상 하드웨어(Xbox One 제품군용
Durango/Xbox One X, Project Scarlett 제품군용 Lockhart/Anaconda)의 대상
SKU 및 콘솔의 언어/로캘 설정에 따라 다양한 콘텐츠가 설치됩니다.

# 샘플 빌드

Xbox One 개발 키트를 사용하는 경우 활성 솔루션 플랫폼을
Gaming.Xbox.XboxOne.x64로 설정하세요.

Project Scarlett을 사용하는 경우 활성 솔루션 플랫폼을
Gaming.Xbox.Scarlett.x64로 설정하세요.

*자세한 내용은 GDK 문서에서* 샘플 실행하기*를 참조하세요.*

# 샘플 사용

대부분의 GDK 샘플과 달리 StreamingInstall 샘플은 Visual Studio에서 빌드
및 배포할 수 없습니다. Visual Studio에서 바로 배포 및 실행할 수 있지만,
이렇게 하면 이 샘플이 보여 주려고 하는 설치 도구 및 프로세스가 사용되지
않게 됩니다. 이 예제를 사용하는 단계는 다음과 같습니다.

1)  배포 및 실행하지 **않고** Visual Studio에서 샘플 빌드

2)  설치 패키지에 대한 콘텐츠 생성

3)  설치 패키지 만들기

4)  패키지 설치 및 샘플 실행

새 Project Scarlett 콘솔 세대를 사용할 경우 대상 장치 제품군에 따라
별도의 XVC 패키지가 만들어집니다. 따라서, 사용자가 테스트하는 장치
제품군에 따라, 여러 다른 .bat 및 .config 파일의 XboxOne 버전과 Scarlett
버전 둘 다로 제공됩니다. 장치 제품군에 관계없이, XPackage 코드는 GDK에서
변경되지 않은 상태로 유지됩니다. MicrosoftGame.config 파일에서
"TargetDeviceFamily=\"\[XboxOne/Scarlett\]\"" 특성은 대상 패밀리를
기준으로 지정됩니다.

이 섹션에서는 도구와 프로세스에 대한 자세한 정보를 제공하는 각 단계에
대해 자세히 설명합니다. 첫 번째 단계는 단순히 Visual Studio에서 샘플을
빌드하는 것입니다. 이렇게 하면 결과적으로 패키지를 만드는 데 사용되는
이진 및 디렉터리 레이아웃이 만들어집니다. 일단 샘플이 빌드되면
명령줄에서 **CreateInstallPackage\_\[XboxOne/Scarlett\].bat**을
실행합니다. 이 배치 파일은 실시간으로 설치 진행 상태를 모니터링하고 대상
장치 제품군 집합을 사용하여 적절한 MicrosoftGame.config를 스테이징하기
위한 콘텐츠 파일로 사용할 여러 개의 대형 파일을 만듭니다.

이진 파일과 콘텐츠가 빌드 출력 디렉터리에 준비되면, 다음 단계는 XDK와
함께 설치된 **MakePkg**를 사용하여 설치 패키지를 만드는 것입니다. **Xbox
VS 2017 Gaming 명령 프롬프트**를 열고 **StreamingInstall.vcxproj**가
포함된 디렉터리로 이동합니다. 열어 놓은 명령 프롬프트에서
**CreateXVC\_\[XboxOne/Scarlett\].bat**을 실행하거나 명령을 직접
실행합니다.

XboxOne 장치 제품군:

> *makepkg.exe pack /v /f Chunks_XboxOne.xml /d
> \".\\Gaming.Xbox.x64\\Layout\\Image\\Loose\" /pd
> \".\\Gaming.Xbox.x64\\Layout\\Image\"*

Scarlett 장치 제품군:

> *makepkg.exe pack /v /f Chunks_Scarlett.xml /d
> \".\\Gaming.Scarlett.x64\\Layout\\Image\\Loose\" /pd
> \".\\Gaming.Scarlett.x64\\Layout\\Image\"*

이 명령에 사용되는 옵션은 다음과 같습니다.

| 옵 션 |  세부 정보 |
|-----|----------------------------------------------------------------|
| /v  |  오류 보고에 대한 자세한 정보 출력을 지정합니다.                |
| /f  |  설치 패키지를 만드는 데 사용할 레이아웃 파일을 지정합니다. 이 샘플에 포함된 레이아웃 파일 **Chunks\_\[XboxOne/Scarlett\].xml**에 대한 세부 정보는 이섹션의 아래에서 찾을 수 있습니다.                              |
| /d  | 패키지의 콘텐츠에 대한 소스 디렉터리를 지정합니다.             |
| /pd | 설치 패키지 파일에 대한 출력 디렉터리를 지정합니다.            |

패키지는 기가바이트 단위의 필러 콘텐츠로 채워지므로 실행하는 데 최대 몇
분 정도 걸릴 수 있습니다. 실행이 완료되면 **/pd** 옵션 다음에 지정된
위치(이 경우 **".\\Gaming.\[Xbox/Scarlett\].x64\\Layout\\Image"**
디렉터리)에 여러 개의 파일이 생성됩니다. 실제 설치 패키지 파일에는 파일
확장명이 아니라 패키지의 **패키지 제품군 이름**이 지정됩니다.

마지막 단계는 패키지를 개발 콘솔에 설치하는 것입니다. 테스트하려는
시나리오에 따라, 설치하려는 콘텐츠를 결정하기 위한 다양한 옵션이
제공됩니다. 스트리밍 설치 구현을 테스트하려는 경우 다음 명령을 사용할 수
있습니다.

> xbapp install \[/l\] \[/w\] \<패키지 이름\>

| 옵션           |  세부 정보                                           |
|----------------|-----------------------------------------------------|
| \<패키지 이름\> |  설치 패키지가 MakePkg 명령에서 만들어집니다. |
| /l  |  시작 청크에만 설치하도록 지정합니다. 시작 청크가 설치되면 게임을 실행할 수 있지만 레이아웃 파일에서 \"Launch\"로 표시된 청크에 열거된 콘텐츠만 사용할 수 있습니다.                                        |
| /w  |  설치 시 파이프를 열린 상태로 유지하도록 지정합니다. 이렇게 하면 처음에는 설치되지 않는 요청 시 및 추가 언어 청크의 동적 설치를 테스트할 수 있습니다.       |
| \<전체 패키지 이름\>  |  콘솔에 설치한 게임의 이름입니다. 패키지 제품군 이름과 혼동해서는 안 됩니다. 명령 프롬프트에서 **xbapp list** 명령을 실행하여 설치된 패키지 목록을 콘솔에 표시할 수 있습니다.                          |

/l과 /w를 사용하여 다양한 게임 설치 시나리오를 테스트할 수 있습니다.
/l만 사용하면 시스템에서 초기 청크만 설치됩니다. /l과 /w를 사용하는 경우
초기 청크가 시스템에서 설치되고 응용 프로그램을 시작한 후 나머지가
설치됩니다. 이러한 플래그를 둘 다 지정하지 않으면 요청 시 및 비기본 언어
청크를 제외한 전체 기본 패키지가 설치됩니다.

일부 청크는 사용자의 시스템 및 언어에 따라 자동으로 설치됩니다. 예를
들어, 언어가 \"en-US\"로 설정된 경우 XboxOne 제품군 패키지가 있는
Durango 콘솔에 배포하면 언어 \"fr\" 또는 장치 \"Xbox-Scorpio\"가 태그로
지정된 청크는 설치되지 않습니다. Scarlett 패밀리 패키지를 사용하는 경우
Lockhart 또는 Anaconda 콘텐츠가 대상 장치(또는 devkit의 디버그 설정)에
따라 설치됩니다.

명령에 전달될 수 있는 몇 가지 선택적 인수와 함께 **xbapp install**을
사용하여 다른 청크를 강제로 설치할 수 있습니다.

| 옵션     |  세부 정보                                                 |
|----------|-----------------------------------------------------------|
| /L anguages  |  설치할 언어를 세미콜론으로 구분된 언어 목록으로 지정합니다. 이 옵션은 콘솔 설정을 변경한 후 설치 명령을 다시 실행할 필요가 없이 여러 언어의 지역화된 콘텐츠를 테스트하는 데 사용할 수 있습니다.                         |
| /Devices  |  설치해야 하는 하드웨어 관련 청크를 지정합니다. 포함할 다양한 하드웨어 SKU의 세미콜론으로 구분된 목록입니다.     |
| /A llChunks |  콘솔 하드웨어 또는 설정에 관계없이 모든 청크가 설치되도록 지정합니다.                                               |

**xbapp install** 명령에 사용할 수 있는 옵션의 전체 목록이 표시되는 것은
아닙니다. 전체 옵션 목록은 GDK 설명서를 참조하세요.

이 샘플은 다음 컨트롤을 사용 합니다.

| 작업                               |  게임 패드 컨트롤               |    |
|------------------------------------|--------------------------------|---|
| 표 메뉴 탐색                       |  D-패드                         |    |
| 표 메뉴에서 항목 선택. 사용 가능한 누락된 청크의 설치를 시도합니다. 여러 항목이 보류 중인 경우 현재 표 항목을 먼저 설치합니다. |  A  |  |
| 열린 항목 닫기 및 표 메뉴로 돌아가기 |  B  |  |
| 가능한 경우 선택한 선택적 청크 제거 |  X  |  |
| 샘플 종료                          |  보기                           |    |
