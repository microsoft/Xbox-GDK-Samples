#   可変レート シェーディング (VRS) のサンプル

*このサンプルは、Microsoft ゲーム開発キットのプレビュー (2019 年 11 月)
に対応しています。*

# 

# 説明

Anaconda (Xbox Series X) と Lockhart はどちらも、Tier2.x の可変レート
シェーディング (VRS) をサポートしています。こちらで Tier2 VRS
の網羅的なドキュメントをご覧になれます:
<https://microsoft.github.io/DirectX-Specs/d3d/VariableRateShading.html>

VRS では、1 ピクセルあたりのピクセル シェーダーによる処理回数を 1
回未満に減らし、1
つのピクセルに対する処理結果を複数のピクセルに使用することで、ピクセル
シェーダーの負担を減らします。VRS
は、半透明のオブジェクトの描画を含めて、特にフォワード
レンダリングで大きな効果を発揮しますが、ディファード
レンダリングでも役立ちます。

このサンプルでは、まったく同じシーンをフレームごとに 2
回レンダリングし、タイミングを合わせて、VRS の効果を報告します。 VRS
を使用してレンダリングしたシーンは、グランド トゥルースからではなく、VRS
を使用してレンダリングした前のフレームから、シェーディングレートを計算します。デバッグ
モードが用意されており、このモードではグラウンド トゥルース、VRS
を使用してレンダリングしたシーン、絶対差、使用されたシェーディングレートが表示されます。

レイマーチで得た陰と AO
を使用し、ピクセルシェーダーが効果的な処理を実施できるよう指示します。

#  サンプルのビルド

Project Scarlett を使用している場合は、アクティブなソリューション
プラットフォームを Gaming.Xbox.Scarlett.x64 に設定します。

このサンプルは、Xbox One をサポートしていません。

*詳細については、GDK
ドキュメント*の「サンプルの実行」を*参照してください*。

# サンプルの使用

| 動作                             |  コントローラー                    |
|----------------------------------|-----------------------------------|
| デバッグ モードを変更する        |  方向パッドの左/右                 |
| 太陽を操作する                   |  Y ボタンとショルダー ボタン       |
| シェーディング レートの許容範囲を変更する |  トリガー ボタン |
| カメラ                           |  スティックと方向パッドの上/下     |
| 可視化方法を変更する             |  X ボタン                          |
| シェーディング レート生成シェーダーを切り替える |  B ボタン |
| 終了                             |  ビュー ボタン                     |

# 実装に関する注意事項

VRS の API サーフェスはとても小さいです。重要な機能を下に挙げます。

Terrain::RenderVRS -- RSSetShadingRate と RSSetShadingRateImage
を呼び出します

Terrain::CalculateShadingRat -- 前のフレームからシェーディング
レートを算出する計算シェーダーを発行します

HLSL では、GenerateShadingRate.hlsl の BuildShadingRate 関数。

BuildShadingRate 関数には wave32 と wave64 に対し合計 4
つのバリエーションが存在し、フル解像度からハーフ解像度のデータにまで対応しています。弊社での実験によると、wave64
の方が処理が速いです。また、場合によってはハーフ解像度を選ぶ方がいい場合があります。

# プライバシーに関する声明

サンプルをコンパイルして実行すると、サンプルの使用状況を追跡するため、サンプル実行可能ファイルのファイル名が
Microsoft に送信されます。このデータ収集を無効にするには、「Sample Usage
Telemetry」とラベル付けされた Main.cpp
内のコードのブロックを削除します。

Microsoft のプライバシー方針の詳細については、「[Microsoft
プライバシーに関する声明](https://privacy.microsoft.com/en-us/privacystatement/)」を参照してください。
